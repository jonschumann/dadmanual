# Capítulo 7 — Integración de software de DADman

> **Producto:** Digital Audio Denmark AX32  
> **SKU:** AX32-BASE2

---

## 7.1 Resumen

El AX32 está completamente gestionado por DADman. Todo enrutamiento, control de ganancias, relojamiento y configuración de tarjetas de expansión se realiza a través de la interfaz de software DADman. La unidad se descubre automáticamente en la red local cuando se conecta a través de Ethernet.
