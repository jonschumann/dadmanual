# Capítulo 4 — Conexiones de señal

> **Producto:** Digital Audio Denmark AX32  
> **SKU:** AX32-BASE2

---

## 4.1 Thunderbolt 3 Host Connection

Conecte el AX32 al ordenador anfitrión mediante un cable Thunderbolt 3. La unidad aparece en DADman como un dispositivo de audio Thunderbolt.

> **NOTA:** Usa solo cables de Thunderbolt 3. Los cables estándar USB-C no proporcionarán un funcionamiento fiable.

---

## 4.2 Conexiones analógicas (a través de tarjetas de expansión)

La E/S analógica se proporciona mediante tarjetas de expansión instaladas (CARD-L8, CARD-M8, CARD-DA8). Cada tarjeta proporciona un conector DB25 de 8 canales usando el estándar de pinout de Tascam.

Para detalles de pinout del conector, vea:

- [ARCHIVO-L8 — Pinida de entrada DB25](../../expansion-cards/card-l8#db25-input-pinout-tascam)
- [CARD-M8 — Pinida de entrada DB25](../../expansion-cards/card-m8#db25-input-pinout-tascam)
- [CARD-DA8 — Piné de salida DB25](../../expansion-cards/card-da8#db25-output-pinout-tascam)
