# Capítulo 2 — Controla la referencia

> **Producto:** Digital Audio Dinamarca MOM (Monitoring Operating Module)

> **Cómo usar este capítulo:** Este capítulo identifica cada control en la cara frontal de MOM. El MOM no contiene circuitos de audio — las señales de audio no son enrutadas a través de él. Para los procedimientos de configuración vea [Ch. 6 — Operación](ch06-operation).

---

> **NOTICE — Perfiles de MOM y Monitorizadores:** Las funciones de los botones de Spkr., C., C., y Capa están determinadas por el perfil de los supervisores cargado en DADman. Configurar Perfiles de seguimiento antes de usar el MOM en una sesión. Ver [Ch. 8 — Características avanzadas, Sección 8.1 — Monitoreo de Perfiles].

> **NOTICE — Conectividad MOM:** El MOM se conecta al Centro AX o al AX 64 vía USB-C en la parte trasera de la unidad anfitrión. No se conecta directamente al puerto USB del ordenador. DADman debe estar corriendo para que el MOM funcione.

## 2.3 referencia de estado LED

### LEDs estado MOM

| Stat. LED                 | Comenzando                                                          |
| ----------------------------------------- | ------------------------------------------------------------------- |
| Verde estable                             | MOM está conectado y comunicándose con el centro AX de host / AX 64 |
| Parpadeo lento (verde) | MOM está inicializando o esperando a que DADman responda            |
| Apagado                                   | MOM no está conectado, o la unidad host está apagada                |

> **NOTA:** Los estados de iluminación del botón MOM (Cortar = rojo, Dim = ámbar, Spkr./► c./Capa = blanco) se describen en [Ch. 6 — Operación].
