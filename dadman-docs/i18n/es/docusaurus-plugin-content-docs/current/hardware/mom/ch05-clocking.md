# Capítulo 5 — Bloqueo y sincronización

> **Producto:** Digital Audio Dinamarca MOM

El MOM no contiene circuitos de audio y no tiene función de reloj. El bloqueo es realizado por el centro AX del anfitrión o AX64. Vea el **AX Center Hardware Manual** o el **AX64 Hardware Manual** para obtener información de reloj.
