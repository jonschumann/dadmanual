## Instrucciones de seguridad

### Seguridad eléctrica

**ADVERTENCIA — choque eléctrico.** Esta unidad opera con energía eléctrica. No remueva la portada. No hay partes que puedan ser utilizadas por el usuario. Consulte todos los servicios a personal de servicio cualificado.

- Lea todas las instrucciones antes de operar el equipo.
- Mantener este manual para referencia futura.
- Observe todas las advertencias en el equipo y en este manual.
- No utilice este equipo cerca del agua.
- No bloquee las aberturas de deslizamiento. Instalar de acuerdo con las instrucciones del fabricante.
- No instale cerca de fuentes de calor como radiadores o amplificadores.
- Protege el cable de alimentación de ser caminado o pellizcado.
- Sólo utilizar archivos adjuntos y accesorios especificados por el fabricante.
- Desenchufe este aparato durante las tormentas de iluminación o cuando no se utiliza durante largos períodos.
- Consulte todos los servicios a personal de servicio cualificado. La reparación es necesaria cuando el aparato ha sido dañado de alguna manera.

### Precauciones ESD

> **CAUCIÓN — Descarga eléctrica.** Maneja con cuidado la unidad y cualquier tarjeta de expansión. La descarga electrostática puede dañar los componentes internos. Suele antes de manejar componentes internos o tarjetas de expansión.

### Montaje de Rack

> **CAUCIÓN: estabilidad del rack.** Asegúrate de que el rack o el recinto sean estables antes de instalar la unidad. La sobrecarga de un estante puede hacer que la propina. Siga las instrucciones del fabricante de rack para el montaje seguro y la distribución de la carga.

### Cable Trueno

> **NOTA:** Usa solo cables de Thunderbolt 3 o Thunderbolt 4 con esta unidad. Los cables estándar USB-C no están clasificados para las velocidades de Thunderbolt 3 y no proporcionan una operación fiable. Utilice el cable suministrado o un reemplazo certificado.

### Etiquetado del conector

Las etiquetas del conector en este manual coinciden con las etiquetas de la unidad física. Donde se proporciona un diagrama de panel, números de llamada (1, 2, 3…) en el texto corresponde a las llamadas numeradas en el diagrama.
