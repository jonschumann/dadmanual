## 7.1 Cómo aparece el Centro AX en DADman

_[Marcador de posición — describe lo que el usuario ve en la lista de dispositivos de DADman cuando el centro AX está conectado. Incluye marcador de posición de captura de pantalla.]_

Cuando el centro AX está conectado y encendido, aparece en el panel **Lista de dispositivos** de DADman. DADman lo identifica por su tipo de dispositivo y número de serie. El usuario asigna una etiqueta que persiste a través de sesiones.

La entrada Lista de Dispositivos para el Centro AX mostra:

| Campo                 | Contenido                                 |
| --------------------- | ----------------------------------------- |
| Tipo de dispositivo   | Centro AX                                 |
| Número de serie       | Identificador único de unidad             |
| Estado de la conexión | En línea / Desconectado                   |
| Versión del firmware  | Revisión actual del firmware              |
| Estado del reloj      | Bloquear estado y referencia seleccionada |
| Mapa del canal de E/S | Rangos de canales asignados               |
