# Manual del usuario de DADman

**Versión del software:** DADman v5.8.2 build 2  
**Publicado:** Junio 2026  
**Mantenido por:** NTP Technology A/S / Digital Audio Denmark

---

Este manual cubre la instalación, configuración y funcionamiento completos del **software de control de DADman** para todo el hardware de tecnología DAD y NTP, compatible incluyendo las series AX Center, Core 256, AX64, AX32, DX32R, MOM y Penta.

## Cómo utilizar este manual

- \*\*¿Nuevo en DADman? \* Comience con [Capítulo 3 — Instalación](/installation) para instalar el software, luego sigue [Capítulo 6 — Empezando](/getting-started) para un paseo paso a paso por primera sesión.
- **¿Buscando una característica específica?** Utilice la barra lateral o búsqueda (presione **Ctrl+K** / \*\* \*\* K\*\*).
- **¿Solución de problemas a un problema?** Ve directamente al [Capítulo 9 — Resolución de problemas](/troubleshooting).
- **¿Buscando un término?** Ver [Apéndice G — Glosario](/appendices#appendix-g--glossary).

## Hardware compatible

DADman v5.8.2 controla el siguiente hardware:

| Hardware                          | Familia                                |
| --------------------------------- | -------------------------------------- |
| Centro DAD AX · Núcleo 256 · AX64 | Núcleo (Familiar 2) |
| DAD AX32 · DX32R · MOM            | Familia 1                              |
| NTP Penta 720 · Penta 721s        | Familia 1                              |
| Avid MTRX · MTRX II               | Familia 1 / 2                          |
| Estudio MTRX Avid                 | Familia 3                              |
| Dynaudio Control 01 / 02          | Accesorio                              |
