## 5.2 Available Sync Sources

| Source             | Connector    | Notes                                                         |
| ------------------ | ------------ | ------------------------------------------------------------- |
| Internal           | —            | AX32 acts as sync master                                      |
| Word Clock         | BNC WC IN    | External word clock input                                     |
| MADI               | BNC MADI IN  | Sync from incoming MADI stream                                |
| Thunderbolt        | Via TB3 host | Sync via DAD Thunderbolt driver                               |
