# DADman User Manual

**Software version:** DADman v5.8.2 build 2  
**Published:** June 2026  
**Maintained by:** NTP Technology A/S / Digital Audio Denmark

---

This manual covers the complete installation, configuration, and operation of the **DADman control software** for all compatible DAD and NTP Technology hardware, including the AX Center, Core 256, AX64, AX32, DX32R, MOM, and Penta series.

## How to use this manual

- **New to DADman?** Start with [Chapter 3 — Installation](/installation) to get the software installed, then follow [Chapter 6 — Getting Started](/getting-started) for a step-by-step first-session walkthrough.
- **Looking for a specific feature?** Use the sidebar or search (press **Ctrl+K** / **⌘K**).
- **Troubleshooting a problem?** Go directly to [Chapter 9 — Troubleshooting](/troubleshooting).
- **Looking up a term?** See [Appendix G — Glossary](/appendices#appendix-g--glossary).

## Compatible hardware

DADman v5.8.2 controls the following hardware:

| Hardware                        | Family                                      |
| ------------------------------- | ------------------------------------------- |
| DAD AX Center · Core 256 · AX64 | Thunder\|Core (Family 2) |
| DAD AX32 · DX32R · MOM          | Family 1                                    |
| NTP Penta 720 · Penta 721s      | Family 1                                    |
| Avid MTRX · MTRX II             | Family 1 / 2                                |
| Avid MTRX Studio                | Family 3                                    |
| Dynaudio Control 01 / 02        | Accessory                                   |
