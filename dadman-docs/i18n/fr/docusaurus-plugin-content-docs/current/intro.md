# Manuel de l'utilisateur DADman

**Version du logiciel:** DADman v5.8.2 build 2  
**Publié :** Juin 2026  
**Maintenu par:** NTP Technology A/S / Digital Audio Danemark

---

Ce manuel couvre l'installation, la configuration et le fonctionnement complet du **logiciel de contrôle DADman** pour tout le matériel DAD et NTP Technology compatible, y compris les séries AX Center, Core 256, AX64, AX32, DX32R, MOM, et Penta.

## Comment utiliser ce manuel

- \*\*Nouveau chez DADman ? \* Commencez avec [Chapitre 3 — Installation](/installation) pour installer le logiciel, suivez ensuite [Chapitre 6 — Démarrer](/getting-started) pour une première session étape par étape.
- **Vous cherchez une fonctionnalité spécifique ?** Utilisez la barre latérale ou la recherche (appuyez sur **Ctrl+K** / **文K**).
- **Résoudre un problème ?** Aller directement au [Chapitre 9 — Dépannage](/troubleshooting).
- **Vous cherchez un terme ?** Voir [Annexe G — glossaire](/appendices#appendix-g--glossary).

## Matériel compatible

DADman v5.8.2 contrôle le matériel suivant :

| Matériel                        | Famille                                      |
| ------------------------------- | -------------------------------------------- |
| DAD AX Center · Core 256 · AX64 | Thunder\|Noyau (Family 2) |
| DAD AX32 · DX32R · MOM          | Famille 1                                    |
| NTP Penta 720 · Penta 721s      | Famille 1                                    |
| Avid MTRX · MTRX II             | Famille 1 / 2                                |
| Avid MTRX Studio                | Famille 3                                    |
| Dynaudio Control 01 / 02        | Accessoire                                   |
