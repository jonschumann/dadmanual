## 9.4 Contacter le support

Si le problème n'est pas résolu par les étapes ci-dessus, contactez votre distributeur local d'Audio Audio Danemark ou le support DAD. Fournir :

- Numéro de série de l'unité (étiquette du panneau arrière)
- Version du firmware (affiché dans DADman)
- Version DADman
- Une description du symptôme et des mesures déjà prises
