# Chapitre 7 — Intégration du logiciel DADman

> **Produit :** Digital Audio Danemark AX32  
> **REF :** AX32-BASE2

---

## 6.1 Aperçu

L'AX32 est entièrement géré par DADman. Tous les routages, le contrôle des gains, l'horloge et la configuration des cartes d'extension sont effectués via l'interface logicielle DADman. L'unité est découverte automatiquement sur le réseau local lorsqu'elle est connectée via Ethernet.
