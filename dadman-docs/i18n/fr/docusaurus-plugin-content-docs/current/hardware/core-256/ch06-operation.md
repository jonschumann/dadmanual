# Chapitre 6 — Opération

---

## 6.1 Marche/Arrêt

_[Placeholder — procédure de mise sous tension et d'arrêt via le bouton d'alimentation du panneau avant.]_

### Mise sous tension normale

1. Assurez-vous que tous les câbles de signal sont connectés.
2. Appuyez sur le bouton **Power** du panneau avant.
3. L'unité exécutera une séquence de démarrage — comptez 30 secondes pour la complétion.
4. La LED **Int.** s'allume lorsque l'unité est prête.

### Arrêt normal

1. En DADman, fermez la session et déconnectez l'unité.
2. Appuyez sur le bouton **Power** du panneau avant.
3. Le bouton ralentira l'impulsion pendant la séquence d'arrêt.
4. Ne retirez pas l'alimentation lorsque le bouton clignote.

> **PRÉCAUTION :** Ne pas faire de cycle d'alimentation de l'unité pendant une mise à jour du firmware. Le bouton Marche/Arrêt ralentira lors de la mise à jour; attendez que la mise à jour soit terminée.
