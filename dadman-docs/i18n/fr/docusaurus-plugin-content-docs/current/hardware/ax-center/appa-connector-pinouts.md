## A.1 BNC (MADI, Horloge de mot)

Les connecteurs BNC sont déséquilibrés de 75 €), coaxiaux. Le signal est porté sur la broche centrale; bouclier sur la coque externe. Aucune table de broche supplémentaire n'est requise au-delà du standard du connecteur.

---

## A.2 DB25 — E/S analogique (Tascam Pinout)

L'unité de base AX Center ne comprend pas de connecteurs DB25. Les connexions DB25 sont fournies par des cartes d'extension optionnelles (CARD-L8, CARD-M8, CARD-DA8) installées dans les deux emplacements d'extension.

Pour plus de détails sur l'épinglage DB25, consultez la page de référence de la carte d'extension pertinente :

- [CARD-L8 — Ligne AD 8 canaux Entrée ](../../expansion-cards/card-l8#db25-input-pinout-tascam)
- [CARD-M8 — 8 canaux AD Mic/Line Input](../../expansion-cards/card-m8#db25-input-pinout-tascam)
- [CARD-DA8 — sortie DA 8-canaux ](../../expansion-cards/card-da8#db25-output-pinout-tascam)

## A.3 XLR — Entrée micro/ligne

| Épingler | Signal                       |
| -------- | ---------------------------- |
| 1        | Sol / Bouclier               |
| 2        | Chaud (+) |
| 3        | Froid (-) |

---

## A.4 TOSLINK (ADAT / MADI optique)

Les connecteurs TOSLINK transportent de l'audio numérique optique. Pas d'affectation de broches — observer l'orientation de transmission (Tx) / réception (Rx) marquée sur le panneau.

---

## A.5 RJ45 (Ethernet)
