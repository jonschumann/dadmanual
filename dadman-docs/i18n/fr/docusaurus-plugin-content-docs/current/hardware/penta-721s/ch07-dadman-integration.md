## 7.1 Comment le Penta 721s apparaît dans DADman

_[Placeholder — décrit ce que l'utilisateur voit dans la liste des périphériques DADman lorsque le Penta 721 est connecté. Inclure le placeholder de la capture d'écran.]_

Lorsque le Penta 721 est connecté et allumé, il apparaît dans le panneau **Liste des Périphériques** de DADman. DADman l'identifie par son type de périphérique et son numéro de série. L'utilisateur assigne une étiquette qui persiste entre les sessions.

L'entrée de liste de périphériques pour le Penta 721 montre :

| Champ                  | Contenus                                        |
| ---------------------- | ----------------------------------------------- |
| Type d'appareil        | Penta 721s                                      |
| Numéro de série        | Identifiant unique de l'unité                   |
| Statut de la connexion | En ligne / hors ligne                           |
| Version du firmware    | Révision actuelle du firmware                   |
| État de l'horloge      | Verrouiller l'état et la référence sélectionnée |
| Carte des canaux d'E/S | Plages de canaux assignés                       |
