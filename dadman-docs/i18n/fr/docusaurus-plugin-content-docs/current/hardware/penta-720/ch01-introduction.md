# Chapitre 1 — Introduction

> **Produit :** Penta 720 Digital Audio Danemark

---

## Aperçu du produit 1.1

Le Penta 720 est une interface audio modulaire en rackmount 2U et une plate-forme de conversion de format de la technologie NTP. Il se connecte à l'ordinateur uniquement par Ethernet et est géré par DADman pour le routage et la configuration. Il est utilisé pour les conversions de format AES/EBU et MADI I/O, ainsi que pour la distribution audio en réseau.

**Connexion à l'hôte :** Ethernet (sans Thunderbolt)
**Facteur de formation:** 2U rackmount (châssis modulaire)
**Canaux audio:** Jusqu'à 720 canaux (dépendants)

---

## 1.2 Fonctionnalités clés

![Penta 720 — front panel](/img/panel-penta720-clean.png)
_Penta 720 — front panel_

- **Facteur de forme:** 2U rackmount, 19"; baies d'accès frontal
- **Extension :** 8 emplacements de carte d'extension de la prise chaude — jusqu'à 1,024×1,024 canaux d'E/S
- **MADI:** MADI / O coaxial intégré — 64 canaux à 48 kHz
- **AES3:** I/O AES3 intégré — 16 canaux via 2 × DB25 (Tascam pinout)
- **Dante (facultatif) :** Via le module MOD-DANTE-BK3 — 64 canaux à 48 kHz
- **DADlink (facultatif) :** Via le module MOD-MADI-DADLNK + SFP — jusqu'à 256×256 canaux
- **Synchronisation :** E/S d'horloge Word (BNC, 75 €), Entrée de rafale noire vidéo, entrée AES11
- **Routage :** Matrice 1,424×1,424 ; processeur de somme 256×32 ; virgule flottante 28 bits
- **Latence:** 7 échantillons de retard interne, 3–31 échantillons réglables; toutes les sorties alignées sur le temps et la phase
- **Contrôle :** Logiciel DADman (macOS et Windows); Compatible Avid EuCon ; Gigabit Ethernet
- **Power:** Dual PSU ; double entrées réseau
- **Refroidissement:** 2 × ventilateurs internes
- **Poids / profondeur:** 5.0 kg / 11.0 lbs; profondeur de châssis 35 cm / 13.8"
