## 7.1 How the Penta 720 Appears in DADman

_[Placeholder — describe what the user sees in the DADman Device List when the Penta 720 is connected. Include screenshot placeholder.]_

When the Penta 720 is connected and powered on, it appears in the **Device List** panel in DADman. DADman identifies it by its device type and serial number. The user assigns a label that persists across sessions.

The Device List entry for the Penta 720 shows:

| Field             | Content                           |
| ----------------- | --------------------------------- |
| Device type       | Penta 720                         |
| Serial number     | Unique unit identifier            |
| Connection status | Online / Offline                  |
| Firmware version  | Current firmware revision         |
| Clock status      | Lock state and selected reference |
| I/O channel map   | Assigned channel ranges           |
