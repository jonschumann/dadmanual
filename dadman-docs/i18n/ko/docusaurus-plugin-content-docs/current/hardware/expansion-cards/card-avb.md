## Overview

The CARD-AVB will provide Audio Video Bridging (AVB) and Milan network audio connectivity for compatible DAD chassis. AVB is an IEEE 802.1Q-based deterministic networking standard widely used in installed sound and live production applications.

---

## Anticipated Features

_The following information is indicative only and subject to change before release._

- IEEE 802.1Qav (Credit-Based Shaper) and IEEE 802.1Qat (Stream Reservation Protocol) compliant
- Milan interoperability for plug-and-play network audio
- 2 × RJ45 network ports
- Compatible with standard Gigabit Ethernet switches supporting AVB/Milan
