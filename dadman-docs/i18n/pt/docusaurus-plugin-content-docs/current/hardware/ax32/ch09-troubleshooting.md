## 9.4 Suporte de contato

Se o problema não for resolvido pelos passos acima, entre em contato com seu distribuidor digital de áudio dinamarquês ou suporte DAD. Provide:

- Número de série da unidade (etiqueta do painel traseiro)
- Versão de firmware (mostrado no DADman)
- Versão do DADman
- Uma descrição do sintoma e dos passos já dados
