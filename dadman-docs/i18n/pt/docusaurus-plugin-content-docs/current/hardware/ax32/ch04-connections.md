# Capítulo 4 — Conexões de Sinal

> **Produto:** Dinamarca de Áudio Digital AX32  
> **SKU:** AX32-BASE2

---

## 4.1 Conexão de host do Thunderbolt 3

Conecte o AX32 ao computador host usando um cabo classificado por Thunderbolt 3. A unidade aparece no DADman como um dispositivo de áudio do Thunderbolt.

> **NOTA:** Use apenas os cabos avaliados pelo Thunderbolt 3. Cabos USB-C padrão não proporcionarão operação fiável.

---

## 4.2 Conexões Análogas (via Cartões de Expansão)

O analógico I/O é fornecido por cartões de expansão instalados (CARD-L8, CARD-M8, CARD-DA8). Cada carta fornece um conector DB25 de 8 canais usando o padrão Tascam.

Para detalhes do conector, consulte:

- [CARD-L8 — DB25 Input Pinout](../../expansion-cards/card-l8#db25-input-pinout-tascam)
- [CARD-M8 — DB25 Input Pinout](../../expansion-cards/card-m8#db25-input-pinout-tascam)
- [CARD-DA8 — Pinça de saída DB25](../../expansion-cards/card-da8#db25-output-pinout-tascam)
