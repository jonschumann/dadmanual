## 7.1 - Visão geral

O AX32 é totalmente gerenciado por DADman. Todos os roteamentos, ganho controle, relógio e configuração de cartões de expansão são executados através da interface de software DADman. A unidade é descoberta automaticamente na rede local quando conectada via Ethernet.
