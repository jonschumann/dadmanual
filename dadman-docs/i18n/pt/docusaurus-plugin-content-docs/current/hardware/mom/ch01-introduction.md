# Capítulo 1 — Introdução

> **Produto:** MOM da Dinamarca de Áudio Digital

---

## 1.1 Resumo do Produto

O MOM (Monitor Operacional Module) é um controlador de monitor físico que se conecta a qualquer unidade de DAD via Ethernet e é ligado sobre essa mesma conexão usando PoE (Power over Ethernet) - nenhuma fonte de alimentação separada é necessária. Proporciona controles de acesso directo para a selecção de alto-falantes, seleção de fonte, nível mestre, escurecer, cortar, talkback e nível de referência. O MOM não contém circuitos de áudio; todo o processamento de sinal ocorre na unidade do host DAD.

**Conexão com o host:** Gigabit Ethernet; PoE-power (IEEE 802. af, Class 0)
**Fator de formulário:** Área de trabalho (rackmountable com colchete opcional)
**Canais de áudio:** Apenas superfície de controle — sem circuito de áudio em unidade

---

## 1.2 Características Chave

![MOM — Visão geral](/img/panel-mom-clean.png)
_MOM — visão geral_

- **Fator de formulário:** Desktop; rackmountable com colchete opcional
- **Controle de volume:** Codificador rotativo no formato grande com toque de 27-LED — resolução de 0.5 dB
- **Chaves:** 10 chaves de acesso direto × 4 camadas = 40 funções atribuíveis
- **Controle Monitor:** 3 conjuntos de alto-falantes; 3 fontes; falar; escurecer; cortar; nível de referência
- **Conexão:** Gigabit Ethernet (RJ45) — alimentado via PoE (IEEE 802.3af, Class 0); não é necessário um PSU separado
- **Entrada do FootSwitch:** jack TRS de 3.5 mm
- **Consumo de energia:** máximo de 5 W
- **Nenhum circuito de áudio** — todo o processamento de sinal é tratado pela unidade DAD conectada
- **Integração de DADman:** Configurado e operado via software DADman
- **Peso / dimensões:** 1,0 kg / 2,2 lbs; 17,2 × 11,0 × 5,0 cm (W × D × H)
