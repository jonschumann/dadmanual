# Capítulo 2 — Referência de Controles

> **Produto:** MOM da Dinamarca de Áudio Digital (Monitorar Módulo Operacional)

> **Como usar este capítulo:** Este capítulo identifica todos os controles na parte frontal do MOM. O MOM não contém circuitos de áudio — sinais de áudio não são encaminhados através dele. Para os procedimentos de configuração, veja [Ch. 6 — Operação](ch06-operation).

---

> **NOTICE — conectividade MOM:** O MOM se conecta ao AX Center ou AX 64 via USB-C na parte traseira da unidade host. Ele não se conecta diretamente à porta USB do computador. O DADman deve estar em execução para que o MOM funcione.

## Referência da Fortaleza LED 2.3

### LEDs de Status MOM

| Situação LED                           | Significado                                                 |
| -------------------------------------- | ----------------------------------------------------------- |
| Verde estável                          | MOM está conectado e se comunicando com o AX Center / AX 64 |
| Flash lento (verde) | MOM está inicializando ou aguardando o DADman responder     |
| Desligado                              | MOM não está conectado, ou a unidade do host está desligada |

> **NOTA:** estados do botão de iluminação do MOM (Corte = vermelho, Dim = âmbar, Spkr./Src./Layer = branco) estão descritos em [Ch. 6 — Operação].
