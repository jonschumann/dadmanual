## 7.1 Como o Penta 721s aparece no DADman

_[Marcador — descreva o que o usuário vê na Lista de Dispositivos DADman quando o Penta 721s é conectado. Incluir placeholder.]_

Quando o Penta 721s está conectado e ligado, ele aparece no painel **Lista de dispositivos** do DADman. DADman o identifica pelo tipo de dispositivo e número de série. O usuário atribui uma etiqueta que persiste nas sessões.

O registro da lista de dispositivos para o Penta 721s mostra:

| Campo               | Conteúdo                                    |
| ------------------- | ------------------------------------------- |
| Tipo de dispositivo | Penta 721s                                  |
| Número de série     | Identificador exclusivo de unidade          |
| Estado da conexão   | Online / Offline                            |
| Versão de firmware  | Revisão atual do firmware                   |
| Status do relógio   | Bloqueio de estado e referência selecionada |
| Mapa do canal I/O   | Intervalos de canais atribuídos             |
