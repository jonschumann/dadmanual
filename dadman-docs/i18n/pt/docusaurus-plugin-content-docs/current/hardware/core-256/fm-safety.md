## Instruções de Segurança

### Segurança Elétrica

**ATENÇÃO — Risco elétrico elétrico.** Esta unidade opera de energia principal. Não remova a capa. Não há peças utilizáveis dentro dela. Consulte todos os serviços de serviço qualificados.

- Leia todas as instruções antes de operar o equipamento.
- Guarde este manual para futuras referências.
- Observe todos os avisos nos equipamentos e neste manual.
- Não use este equipamento perto da água.
- Não bloquear as aberturas de ventilação. Instale de acordo com as instruções do fabricante.
- Não instale perto de fontes de calor como radiadores ou amplificadores.
- Proteja o cabo de alimentação para que não seja ligado ou fixado.
- Use apenas conexões e acessórios especificados pelo fabricante.
- Desconecte este aparelho durante tempestades elétricas ou quando não for utilizado por períodos longos.
- Consulte todos os serviços de serviço qualificados. O serviço é necessário quando o aparelho está danificado de alguma forma.

### Precauções ESD

> **CAUTÃO — Corrida elétrica.** Gerencie a unidade e quaisquer cartões de expansão com cuidado. Desvio elétrico pode danificar componentes internos. Solte-se antes de manipular componentes internos ou cartões de expansão.

### Montar Rack

> **ATENÇÃO — Rack stability.** Certifique-se de que o rack ou invólucro está estável antes de instalar a unidade. Sobrecarregar um rack pode fazer com que ele dê gorjeta. Siga as instruções do fabricante de rack para a montagem segura e distribuição de carga.

### Cabo Trovejante

> **NOTA:** Use somente o Thunderbolt 3 ou o Thunderbolt 4 cabos classificados com esta unidade. Cabos USB-C padrão não são classificados para velocidades de Thunderbolt 3 e não proporcionarão operação confiável. Utilize o cabo fornecido ou uma substituição certificada.

Etiquetas do conector neste manual coincidem com as etiquetas da seda na unidade física. Onde um diagrama de painel é fornecido, números de callout (1, 2, 3…) no texto corresponde aos callouts numerados no diagrama.
