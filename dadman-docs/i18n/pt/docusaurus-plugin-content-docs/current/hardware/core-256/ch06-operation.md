## 6.1 Liga/Desliga

_[Placeholder — procedimento de alimentação e desligamento via botão de energia do front-painel.]_

### Ligação Normal Ligado

1. Certifique-se de que todos os cabos de sinal estejam conectados.
2. Pressione o painel frontal **Ligar** botão.
3. A unidade realizará uma sequência inicial - dê 30 segundos para conclusão.
4. O **Int.** O LED ilumina quando a unidade está pronta.

### Encerramento normal

1. Em DADman, feche a sessão e desconecte a unidade.
2. Pressione o painel frontal **Ligar** botão.
3. O botão irá desacelerar durante a sequência de encerramento.
4. Não remova a energia enquanto o botão estiver pulsando.

> **ATENÇÃO:** Não coloque energia na unidade durante uma atualização de firmware. O botão Liga/Desliga irá usar o pulso lento durante a atualização; aguarde a atualização ser concluída.
