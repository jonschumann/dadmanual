## 7.1 Como o Centro AX aparece no DADman

_[Marcador — descreva o que o usuário vê na lista de dispositivos DADman quando o Centro AX está conectado. Incluir placeholder.]_

Quando o Centro AX estiver conectado e ligado, ele aparecerá no painel **Lista de Dispositivos** do DADman. DADman o identifica pelo tipo de dispositivo e número de série. O usuário atribui uma etiqueta que persiste nas sessões.

O registro da Lista de Dispositivos do Centro AX mostra:

| Campo               | Conteúdo                                    |
| ------------------- | ------------------------------------------- |
| Tipo de dispositivo | AX Centro                                   |
| Número de série     | Identificador exclusivo de unidade          |
| Estado da conexão   | Online / Offline                            |
| Versão de firmware  | Revisão atual do firmware                   |
| Status do relógio   | Bloqueio de estado e referência selecionada |
| Mapa do canal I/O   | Intervalos de canais atribuídos             |
