# Manual de Usuário DADman

**Versão do software:** DADman v5.8.2 build 2  
**Publicado:** Junho 2026  
**Mantida por:** NTP Technology A/S / Digital Audio Denmark

---

Este manual cobre a instalação completa, configuração e operação do **software de controle do DADman** para todos os equipamentos de tecnologia DD e NTP compatíveis, incluindo as séries AX Center, Core 256, AX64, AX32, DX32R, MAM e Penta

## Como usar este manual

- \*\*Novo no DADman? \* Comece com [Capítulo 3 — Instalação](/installation) para instalar o software, em seguida, siga [Capítulo 6 — Primeiros passos](/getting-started) para uma primeira sessão passo a passo.
- **Procurando por uma característica específica?** Use a barra lateral ou a pesquisa (pressione **Ctrl+K** / **⌘K**).
- **Solucionar problemas com problemas?** Vá diretamente para o [Capítulo 9 — Solução de problemas](/troubleshooting).
- **Procurando um termo?** Veja [Apêndice G — Glossário](/appendices#appendix-g--glossary).

## Hardware compatível

O DADman v5.8.2 controla o seguinte hardware:

| Hardware                          | Familiares                                       |
| --------------------------------- | ------------------------------------------------ |
| DAD AX Center · Núcleo 256 · AX64 | Núcleo do Trovão\➲ (Grátis 2) |
| DAD AX32 · DX32R · MOM            | Família 1                                        |
| NTP Penta 720 · Penta 721s        | Família 1                                        |
| Avid MTRX · MTRX II               | Família 1 / 2                                    |
| Studio MTRX Avid                  | Família 3                                        |
| Dynaudio Control 01 / 02          | Acessório                                        |
