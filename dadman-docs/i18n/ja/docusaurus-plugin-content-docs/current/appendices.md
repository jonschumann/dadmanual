## 付録 A — 技術仕様

この付録は、現在のアクティブ製品ラインナップにおけるすべてのDADman制御ハードウェアの完全な技術仕様を提供します。 仕様は公式のDAD製品ドキュメントから提供されています。 すべてのチャネル数は、記載されているサンプルレートの最大数を反映します。実際の数は、インストールされている拡張カードに依存します。

> **注意:** AX32 (BASE1/BASE2) はもはやアクティブな生産ではなく、ここには含まれていません。 レガシー仕様については、AX32ハードウェアマニュアルを参照してください。

### A.1 AXセンター (AXCNTR-BASE)

**製品概要:** コンパクト1U、2スロットモジュラーオーディオインターフェース、ネイティブアナログI/Oを使用。 録音、モニターコントロール、没入型オーディオアプリケーションに最適です。 オンボードのThunderbolt 3、ダンテ、MADI、およびADATには、追加のI/O用の2つの拡張カードスロットが含まれています。

### A.6 ジュニアコントロール\|パックコントローラ (JUNIOR-BASE)

**製品概要:** DADman Control|ルーティングプリセットとバケットをパックするためのPoE搭載のコンパクトコントロールユニット。 イーサネット経由で任意のサンダー\|コアユニットに直接接続します。 CORE256-BASE、AXCNTR-BASE、AX64-BASEと互換性があります。 一度設定された DADman ソフトウェアとは独立して動作します。

#### 特徴

- 6 RGB LED点灯ボタン
- 6 RGB status LEDs
- 6文字のOLED表示/ボタン
- サンダー\|コアユニットへの直接IP接続

## 付録 C — サポートされているオーディオフォーマットとプロトコル

この付録は、各サンプルレートでのチャンネルカウントを含む、DADman-controlled ハードウェアでサポートされているオーディオフォーマットとプロトコルをまとめたものです。 すべての数字は最大です; 実際のチャネル数は、各ユニットにインストールされている特定の拡張カードに依存します。

> **注意:** チャンネルはチャンネルごとに帯域幅が消費されるため、サンプルレートが高くなっているため、時分割多重化されたインターフェイス(MADI、ADAT、DADLink)をカウントします。 DanteとAES67チャンネル数は、ネットワーク設定とDanteコントローラの設定によって異なります。

---

### C.1 MADI (AES10)

MADIは拡張カードオプションとしてすべてのDAD/NTPテクノロジハードウェアファミリでサポートされています(デュアルMADIカード)。 MADI モジュール)または選択ユニットに組み込まれています。

**MADI ポートあたりのチャネル容量:**

| サンプルレート                         | 従来モード (56-chフレーム) | ハイスピードモード (64-chフレーム) |
| ------------------------------- | ------------------------------------ | ---------------------------------------- |
| 44.1 / 48 kHz   | 56チャンネル                              | 64 チャンネル                                 |
| 88.2 / 96 kHz   | 28 チャンネル                             | 32 チャンネル                                 |
| 176.4 / 192 kHz | 14チャンネル                              | 16 チャンネル                                 |

**標準:** AES10-2008 (MADIシリアル)とAES10-2003 (MADI-E拡張)。

**物理インターフェース:**

- 同軸BNC(75Ω) — 最大ケーブル長約100m(標準同軸)
- Optical SFP — SFPモジュールタイプに応じたマルチモードまたはシングルモードファイバー。シングルモードSFPを搭載した数キロメートルまで。

**フレームレートモード:**

- **レガシーモード:** 48kHzのフレームサイズでフレーム長を固定しました。 88.2/96 kHzでは、隣接するチャネルペアは時間多重化(S/MUX2)され、チャネルカウントの半分になります。 176.4/192 kHzでは、4つのチャネルのグループが多重化されます(S/MUX4)。 MADI機器の大部分と互換性があります。
- **高速モード：** フレーム長は実際のサンプルレートに沿っており、88.2kHz以上のレイテンシを低減します。 MADIリンクの両端は同じモードに設定する必要があります。

> **重要：** MADI接続の両端には、同じフレームレートモードとフレームサイズ設定が必要です。 ミスマッチはオーディオやクロックエラーを引き起こしません。 接続されている両方のデバイスの Conf タブで設定を確認します。

---

### C.2 ADAT (S/PDIF Optical, ADAT Lightpipe)

ADAT光インタフェースは、選択されたDADハードウェア拡張カードでサポートされています。 ADATはS/MUX(サンプル多重化)を使用して、より高いサンプルレートでオーディオを搬送します。

| サンプルレート                         | チャンネル (ADATポートあたり) | モード      |
| ------------------------------- | ------------------------------------- | -------- |
| 44.1 / 48 kHz   | 8チャンネル                                | 標準的なADAT |
| 88.2 / 96 kHz   | 4 チャンネル                               | S/MUX2   |
| 176.4 / 192 kHz | 2 チャンネル                               | S/MUX4   |

**物理インターフェース:** TOSLINK 光コネクタ。

**Standard:** Alesis ADAT光学プロトコル。

> **注意:** ADATは元の標準では96kHz以上には定義されていません。 S/MUX4は176.4/192 kHzでサポートされているため、接続された両方のデバイスがこの拡張をサポートする必要があります。 接続された機器との互換性を確認します。

---

### C.3 AES3 (AES/EBU)

AES3デジタルオーディオはケーブルペアごとに2つのチャンネル(1つのステレオペア)を持ちます。 DADハードウェアは通常、DB25ブレークアウトコネクタを介してAES3 I/Oを提供し、それぞれ8つのステレオペア(16チャネル)を搭載しています。

| サンプルレート                         | AES3ペアごとのチャンネル                            | DB25ごとのチャンネル (8ペア) |
| ------------------------------- | ----------------------------------------- | ------------------------------------- |
| 44.1 / 48 kHz   | 2                                         | 16                                    |
| 88.2 / 96 kHz   | 2 _(ダブルワイヤー/デュアルワイヤー)_ | 16                                    |
| 176.4 / 192 kHz | 2 _(クワッドワイヤー)_         | 16                                    |

**Standard:** AES3-2009.

**物理インターフェース:**

- バランスの取れたXLR (プロフェッショナル — 標準AES3)
- DB25ブレークアウト(業界標準のTASCAMまたはヤマハのピンアウト配線経由)

**高サンプルレート操作** 88.2/96 kHzでは、AES3の一部の実装では**ダブルワイヤー**を使用しています(チャンネルあたり2つのAES3ペアで帯域幅を増やすことができます)。 176.4/192 kHzでは、**クワッドワイヤー**はチャネルごとに4つのペアを使用します。 DADman の AES3 実装の詳細は、ハードウェアモデルに依存します。特定のユニットのハードウェアインストールガイドを参照してください。

---

### C.4 ダンテ (オーディネート)

Danteはオーディオ・オーバーIPプロトコルで、標準のイーサネット・インフラストラクチャ上でオーディオを伝送します。 DADmanユニットは、拡張カードと統合モジュールを介してDanteをサポートしています。

**Dante実装によるチャネル容量**

| 実装                                                                                                        | 最大チャンネル (Tx + Rx)          | 典型的なハードウェア                                             |
| --------------------------------------------------------------------------------------------------------- | --------------------------------------------- | ------------------------------------------------------ |
| ダンテ拡張カード（Brooklyn2/3）                                                                                     | 128 Tx + 128 Rx (per card) | AX32 · DX32R · Penta 720 · Penta 721s · MTRX · MTRX II |
| ダンテ64チャンネルモジュール                                                                                           | 64 Tx + 64 Rx                                 | AX32 · Penta 720 · Penta 721s · MTRX                   |
| Dante 256 IPCore _(v5.8.1.6 firmware)_ | 256 Tx + 256 Rx                               | AX64 · AXセンター · Core 256 · MTRX II                     |
| ダンテカード\*(スタンドアロン)\*                                                                    | 512 Tx + 512 Rx                               | ファミリー1ユニットを選択                                          |

**チャンネル数はサンプルレートに依存しません** — ダンテチャンネルはサンプルレートが高くなると減少しません。 代わりに、サンプルレートが高いほどチャネルあたりのネットワーク帯域幅が増えます。 ネットワーク容量はそれに応じてサイズを設定する必要があります。

**ネットワーク要件:**

- ダンテのすべてのインストールに推奨されるギガビット イーサネット
- オーディオトラフィックに推奨する専用ネットワークスイッチ
- スイッチはマルチキャストをサポートしている必要があります (IGMP スヌーピング推奨)
- ダンテのすべてのデバイス間のクロック同期に使用されるPTP(IEEE 1588)

**プロトコルと標準:**

- Dante native protocol(Audinate独自)
- AES67 相互運用モード（チャンネル数を AES67 制限に減らす）
- ST 2110-30 _(v1.1.2.4からDDMを介して; Brooklyn 3 without DDM from v1.1.0.3)_

### C.5 DADLink

DADLinkは、SFP光トランシーバを備えたミニMADIモジュールスロットを使用したDAD独自の光インターコネクトです。 このデバイスは、超低遅延の直接ユニット間の相互接続を提供します。

| サンプルレート                         | DADLink接続ごとのチャンネル |
| ------------------------------- | ----------------- |
| 44.1 / 48 kHz   | 128               |
| 88.2 / 96 kHz   | 64                |
| 176.4 / 192 kHz | 32                |

**緯度:** 約1マイクロ秒(事実上ゼロ、DADLinkに接続されたユニット間のすべての入力と出力は、クロックが正しい場合に位相整列されます)。

**物理インターフェース:** Optical SFP — 両端に必要な互換性のあるSFPトランシーバモジュール。

**互換ハードウェア:** AX64・AXセンター・コア256・MTRX II · DX32R・ペンタ720・ペンタ721s\*(ファームウェアv2からファミリー1。 .1.2)\*

**同期要件:** DADLink接続ユニットは共通のクロックを共有する必要があります。 ユニット間の同期元としてDADLinkまたはWordクロックを使用します。

### C.6 Thunderbolt 3 (サンダー\|コア)

Thunderbolt 3 オーディオ I/O は、Thunderbolt 3 ドライバ経由でのみサポートされています。|コア生成ハードウェア(AX64、AX センター、Core 256)は、DAD Thunderbolt 3 ドライバを介してのみサポートされています。

| ハードウェア        | Thunderbolt 3 チャンネル | メモ                            |
| ------------- | ------------------- | ----------------------------- |
| **AX64**      | 64 Tx + 64 Rx       | 44.1 / 48 kHz |
| **AX Center** | 128 Tx + 128 Rx     | 44.1 / 48 kHz |
| **コア256**     | 256 Tx + 256 Rx     | 44.1 / 48 kHz |

**サンプルレートが高い** Thunderbolt 3 チャンネル数は比例して減少します。 88.2/96 kHzで半分、176.4/192 kHzで四半期となります。

**ドライバー:**

- macOS: Core Audio driverSetup(DADDriverSetup) — 現在のバージョン v1.2.2
- Windows: ASIO ドライバ — 現在のバージョン v1.1.2

**ケーブル:** Thunderbolt 3 認証済みの最低20Gbpsケーブルです。 パッシブケーブルは約0.5mまでサポートします。アクティブ光ケーブルは長寿命をサポートします。

### C.7 AES67とST 2110-30

AES67とST 2110-30は、互換性のあるDADハードウェア上でDanteとRavennaインターフェースを介してサポートされているIPオーディオ規格です。

## Appendix G — Glossary

用語はアルファベット順にリストされています。 用語に共通の略語がある場合、項目は省略名が記されたフルフォームの下に表示されます。 相互参照は略語のアルファベット順に置かれます DAD製品名と商標用語は、製品またはDADmanに表示されます。

---

**AD tab**
DADman の _Analogue to Digital_ タブ。 接続されているハードウェアユニット上のすべてのアナログ入力チャンネルのチャンネルストリップを表示します。 マイク/ライン入力ゲイン、ミュート、位相反転、ファントム出力(+48 V)、およびチャネルラベルのコントロールを提供します。 各入力のメーターはこのタブに表示されます。 こちらも参照してください: _DA タブ_

**ADAT** (Alesis Digital Audio Tape 光学インターフェイス)
光学デジタルオーディオインターフェイス標準で、最大 8 チャンネルのオーディオを44で送信します。 48kHzまたは4チャンネルの場合は88.2または96kHzの場合は、1本のTOSLINK Fibre-光ケーブルを介してください。 選択したDADハードウェアでI/Oオプションとしてサポートされています。 ダブルサンプリングレートでは、チャンネル数は半分になります。これは_S/MUX_と呼ばれます。 _S/MUX_も参照してください。

**AES3** (AES/EBU)
オーディオエンジニアリング協会(AES)と欧州放送連合(EBU)によって定義された、プロのバランスの取れたデジタルオーディオインターフェース規格。 1つのバランスの取れたXLRケーブルを介して2つのPCMオーディオチャネルを運びます。 一般にAES/EBUと呼ばれます。 DADハードウェア上でディスクリートI/O形式としてサポートされており、通常は複数のAES3ペアを搭載したDB25ブレークアウトコネクタを介しています。 _AES67_も参照してください。

**AES67**
Audio Engineering Societyによって定義されたAoIP(AoIP)の相互運用性標準です。 AES67は、Dante、Ravenna、WNEU、およびその他のAoIP実装がオーディオストリームの交換を可能にする共通のトランスポート層を定義しています。 DanteまたはRavennaインタフェースを備えたDADハードウェアは、AES67モード用に設定できます。 も参照してください: _ダンテ_、_Ravenna_、_ST 2110-30_。

**ASIO** (Audio Stream Input/Output)
Steinbergが開発したWindows用の低遅延オーディオドライバアーキテクチャ。 DAD Thunderbolt 3 ASIO ドライバーは、Thunderbolt 3 ASIO デバイスとして Thunderbird\|Core インターフェース (AX64、AX Center、Core 256) をWindows DAW で公開します。 DAD ASIOドライバコントロールパネルを介して構成され、バッファサイズ、サンプルレート、およびチャネルカウント設定を提供します。

**Autoboot**

**AX32**

**dBFS** (フルスケールに対するデシベル)

**dBu**

DADハードウェアとソフトウェア製品を開発・製造するデンマークの会社(NTP Technology A/S, コペンハーゲン)。 以前はNTP/NEVEテクノロジーとして知られていました。 また、NTPペンタブランドの下でオーディオ製品を開発しています。 DADは消費者向けのブランド名で、NTPテクノロジーA/Sは法人です。 _DAD_も参照してください。

**出力セット**
DADman Monitor Profileでは、スピーカーの構成を表す名前付きの物理出力チャンネルのグループ、例えば、`Near Field`、`5。 囲まれた`、または`85 dB SPL`。 複数の出力セットは、異なる物理出力または異なるトリムレベルを持つ同じ出力を使用して定義でき、複数のリファレンスレベルプリセットを作成できます。 _チャプター8.1.4_を参照してください。 _リファレンスレベル_、_トリム_も参照してください。

**Penta 720 / Penta 721s**
NTPテクノロジーA/Sオーディオルータとコンバータ製品。 家族1ハードウェアグループのメンバー。 AX32と同じ拡張カードオプションを備えています。 DADman経由で制御されます。 NTPテクノロジーA/S製;NTPペンタブランドの下で配布。

**PCIe** (Peripheral Component Interconnect Express)
CPU、RAM、周辺機器間の通信のためにコンピュータ内で使用される高速コンピュータバス規格。 Thunderbolt 3はPCIe帯域幅を外部から公開しています。これは、Thunderbolt 3 がホストコンピュータと通信する方法であり、コアデバイスのレイテンシはゼロ近くになります。

**PoE** (Power over Ethernet)
A標準 (IEEE 802. af/at) ネットワークスイッチは、データに使用される同じイーサネットケーブルを介して接続されたデバイスに電力を供給することができます。 MOMモニタコントローラと一部のDADアクセサリはPoEをサポートしているため、別個の電源が不要です。

**PRE Emulation**
Pro ToolsがMIDI経由でDADman接続されたプリアンプゲインをコントロールし、ハードウェアを_Avid PRE_プリアンプユニットとして扱うことができるDADman機能。 Pro ToolsのI/Oセットアップまたは接続されたコントロールサーフェスから、DADmanに切り替えることなくマイクゲインを調整できます。 _チャプター8、セクション8.15_を参照してください。

**PRO\|MON**
基本的なモニタープロファイル機能セットを超えてモニター制御システムを拡張するオプションのDADmanソフトウェアライセンス。 高度なモニターのルーティング、トークバック、キューバス、複雑なスタジオや放送監視環境の統合機能を追加しました。 主にAX32、DX32R、Penta 720、MTRX Studioで使用されます。 _完全なドキュメントが保留中 — DADエンジニアリング入力が必要です。 参照：第8章、保留中のドキュメント。_

**PTP** (Precision Time Protocol, IEEE 1588)
ローカルエリアネットワーク上のクロックをサブマイクロ秒の精度で同期させるネットワークプロトコル。 DanteとRavennaネットワークで、専用のワードクロックケーブルを必要とせずに、さまざまなネットワークデバイスからのオーディオストリームを整列させるために使用されます。 _Dante_、_Ravenna_も参照してください。

**Ravenna**
ALC NetworXが開発したオーディオ-over-IPトランスポートプロトコル。 ハイエンドの放送および専門的なオーディオアプリケーションで使用されます。 AES67と相互運用可能。 DAD Ravenna カード(DADman v5.8.2 ビルド 2からサポート)は Ravenna/AES67 / ST 2110-30 を互換性のある Thunderbird\|コア ユニットに追加します。 _AES67_、_ST 2110-30_も参照してください。

**Ready LED**
すべてのDAD / NTPテクノロジーハードウェアユニットに搭載されているフロントパネル状態インジケータ。 しっかりとした緑色の場合、ユニットは電源をオンにし、起動し、正常に通信します。 点滅または緑でない Ready LED は、進行中の起動、ファームウェアのアップデート、または障害状態を示します。

**リファレンスレベル**
DADman Monitor Profileでは、テストトーンとSPLメーターで確立された、特定の出力セット用のキャリブレーションされた出力レベルです。 一度定義したら、Monタブの**Ref**ボタンを押すとモニターフェーダーがこのレベルまでロックされ、クリティカルリッスン中に誤って音量が変化するのを防ぎます。 _チャプター8.1.5_を参照してください。

**ルーティングマトリックス**
DADman制御ハードウェアユニットの信号ルーティングエンジン。任意の入力を任意の出力に接続することができます。 ルーティング マトリクスは、クロスポイントのグリッドとして DADman **Con** タブで表示され、編集されます。 DADハードウェアは、最大1,500×1500クロスポイント(モデルに依存)の行列をサポートします。 も参照してください: _Conタブ_、_Crosspoint_。

**ルーティングプリセット**
Control\|Packでは、プリセットによってどの出力チャンネルが制御され、どのソースバケットがスイッチングに使用できるかを定義する名前付き設定です。 サンダー\|コアユニットごとに最大32個のルーティングプリセットを設定できます。 参照: _Control\|Pack_、_Bucket_。 _チャプター8、セクション8.4_を参照してください。

**RoHS** (危険物質の制限)
EU指令2011/65/EU特定有害物質の使用を制限する (鉛, 電気・電子機器の水銀、カドミウム、ヘキサベントクロム、難燃剤などです DAD / NTPテクノロジハードウェアはRoHSに準拠しています。 _付録F_を参照してください。

**Sample Rate**
1秒あたりの音声サンプル数。kHzで表されます。 標準レート：44.1kHz、48kHz (標準定義);88.2kHz、96kHz (高解像度);176.4kHz、192kHz (超高解像度)。 サンプルレートが高いほど、時間多重化インタフェース(MADI、ADAT、DADLink)におけるチャネルカウントが低減されます。 サンプルレートは、DADman **Conf** タブでユニットごとに設定されます。

**SFP** (Small Form-factor Pluggable)
MADIおよびDADLink接続で使用されるコンパクトでホットスワップ可能な光または電気トランシーバモジュール。 SFPモジュールは、マルチモードまたはシングルモードファイバ、または同軸MADI用のさまざまな構成で利用できます。 SFPタイプは、ケーブルの種類と最大伝送距離を決定します。

**S/MUX** (Sample Multiplexing)
一つのチャンネルのデータを複数のADATチャンネルで運ぶことで、ADAT上でより高いサンプルレートのオーディオを送信する手法。 88.2/96 kHzでは、S/MUXはADATチャンネル数を4チャンネル(S/MUX2)に半分にします。 176.4/192 kHzでは、S/MUX4はさらにカウントを2チャンネルに低減します。 _ADAT_ も参照してください。

**Source** _(monitor)_
DADman Monitor Profileでは、モニター選択用の名前付き入力信号パスが利用できます。 ソースはハードウェアユニット(analogue、Dante、MADI、AES3など)の特定の入力チャンネルに割り当てられます。 をクリックすると、選択可能なオプションとして表示されます。 例: `Pro Tools` 、 `DVS` 、 `Dante Player` 、 `Guest` 。 _チャプター8、セクション8.1.3_をご覧ください。 _モニタープロファイル_も参照してください。

**SPQ** (シグナル処理カード)
アナログモニタ出力にチャネルごとのパラメトリックEQを提供する、互換性のあるDADハードウェア(AX32バリアント)用のオプションのDSP拡張カード。 スピーカーと部屋の修正に使用されます。 SPQフィルタのデータは通常、Room EQ ウィザード(または同様のツール)で行った音響測定から生成され、format@@0タブを介してDADmanにインポートされます。 _チャプター8、セクション8.12_を参照してください。

**SRC** (Sample Rate Converter)
異なるサンプルレート間でデジタルオーディオを変換するハードウェアまたはソフトウェアコンポーネント。 信号経路にSRCを挿入すると、元のサンプルクロックと位相コヒーレント関係が崩されます。 これは、LTCやAE6パイロットトーンなどの時間センシティブ信号を腐敗させる可能性があります。 DADman ユニットは、Confタブで設定すると、選択したI/OインターフェイスでSRCをサポートします。

**ST 2110-30**
AES67 規格から派生した IP ネットワーク上で非圧縮オーディオをトランスポートするための SMPTE 規格 (SMPTE ST 2110-30) です。 プロの放送環境で使用されます。 DAD DanteとRavennaのファームウェアv1.1.2.4(2026年1月)でサポートされています。 Brooklyn 3モジュールは、ファームウェアv1.1.0.3からDDMなしでST 2110-30をサポートします。 も参照してください: _AES67_、_Ravenna_、_DDM_。

**Thunderbird\|Core**
AX64, AX Center, Core 256 ハードウェアユニットに統合された Thunderbolt 3 インターフェイス技術の DAD 用語。 Thunderbolt 3 ケーブルを介してハードウェアユニットとホストコンピュータとの間の超低遅延のオーディオI/Oを提供し、標準的なイーサネットベースの DADman 制御に加えて、Thunderbolt 3 ケーブルを介して実現します。

**Thunderbolt 3**
インテルの高速ペリフェラルインターフェース規格は、USB-C コネクタで最大 40 Gbps の帯域幅を提供します。 ホストコンピュータへのオーディオ I/O のための DAD サンダー\|コア ユニットで使用されます。 DAD Thunderbolt 3 ドライバが必要です (macOS の場合は以下のオーディオ、Windows の場合は ASIO )。 正しい動作のための最小ケーブル仕様は、20 Gbpsに定格されたThunderbolt 3認定ケーブルです。 _チャプター3、セクション3.2_、_チャプター9、セクション9.4_を参照。

**Trim**
DADman Monitor Profileの出力セットでは、メインモニターフェーダーに対する出力セットに適用される固定レベルオフセットが設定されています。 ハードウェアを追加することなく、同じ物理出力に複数のリファレンスレベルプリセットを作成します。 例えば、 1次セットと同じスピーカーを指す2番目の出力セットで-10dBトリムすると、10dBのリファレンスレベルシフトが瞬時に得られます。 _出力セット_、_リファレンスレベル_も参照してください。

**トリガー**
Control\|Packルーティングプリセットでは、_trigger_はBucketのソースが有効であるかどうかを決定するBucketに割り当てられた検出条件です。 トリガーの種類:信号レベル(-40dBFSしきい値を超えるオーディオ信号)、AE6(AE6デジタルパイロットトーンの整合性)、ポート(物理ポートの接続状態)。 _チャプター8.4.4_を参照してください。 参照: _バケット_、_コントロール\|パック_。

**Up-Match**

**WEEE** (Waste Electrical and Electronic Equipment)
EU Directive 2012/19/EU 電気・電子機器の回収、リサイクル、廃棄を管理します。 DAD / NTP技術ハードウェアはWEEEシンボル(ホイールバイ)を搭載しており、未分類の家庭廃棄物で処理してはならないことを示しています。 _チャプター10、セクション10.8_、_フロントマター、セクションFM.8_を参照してください。

**Word Clock**
ディジタルオーディオ機器をフェーズロックし、共有サンプルレートリファレンスに使用する正方形波同期信号。 ワードクロックは、動作するサンプルレート(例えば、48 kHz)75ΩのBNCケーブルで分配されます。 DADハードウェアは、施設同期システムに統合するためのワードクロックの入出力をサポートしています。 ワードクロック接続では、チェーン内の最終デバイスで75Ωの終端が必要です。 _第9章9.5_を参照してください。
