# DADman ユーザーマニュアル

**ソフトウェアバージョン:** DADman v5.8.2 build 2  
**公開:** 2026  
**メンテナンス:** NTPテクノロジーA/S / Digital Audio Denmark

---

このマニュアルでは、互換性のあるすべてのDADおよびNTPテクノロジハードウェア用の**DADman制御ソフトウェア**のインストール、構成、および動作について説明します。 AXセンター、コア256、AX64、AX32、DX32R、MOM、ペンタシリーズを含む。

## このマニュアルの使い方

- \*\*DADmanを初めてですか？ \* [Chapter 3 — インストール](/installation) から始めると、ソフトウェアがインストールされます。 次に、[Chapter 6 — Getting Started](/getting-started) に従って、ステップバイステップの最初のセッションのウォークスルーを行ってください。
- **特定の機能をお探しですか？** サイドバーまたは検索を使用してください（**Ctrl+K** / **⌘K**を押してください）
- **問題を解決しますか？** 直接[チャプター 9 — トラブルシューティング](/troubleshooting)に行きましょう。
- **用語を調べますか？** [Appendix G — Glossary](/appendices#appendix-g--glossary) を参照してください。

## 互換性のあるハードウェア

DADman v5.8.2 は以下のハードウェアを制御します。

| ハードウェア                     | 家族                                   |
| -------------------------- | ------------------------------------ |
| DADAXセンター・コア256 · AX64     | サンダー\|コア (ファミリー2) |
| DAD AX32 · DX32R · MOM     | ファミリー 1                              |
| NTP Penta 720 · Penta 721s | ファミリー 1                              |
| Avid MTRX · MTRX II        | ファミリー 1 / 2                          |
| Avid MTRX Studio           | ファミリー 3                              |
| Dynaudio Control 01 / 02   | アクセサリー                               |
