## 4.1 AX Center

### 4.1.1 概要

AXセンターは、Thunderbolt製品ファミリの1UラックマウントThunderboltオーディオインターフェースです。 フロントパネルには、2つのマイク/ライン/インストゥルメント入力とステレオモニタ出力を直接提供します。 MADI、ADAT、ワードクロック、アナログ拡張スロット、および背面にデュアルThunderbolt 3ポートを搭載。 すべてのルーティング、ゲイン、監視、および構成は、イーサネット経由で DADman 経由で実行されます。 AXセンターは、デスクトップモニタコントローラシステムとして使用すると、MOM(モニタ動作モジュール)もホストします。MOMはUSB-C経由でAXセンターに接続します。

## 4.2コア256

### 4.2.1 概要

Core 256 は、Thunderbolt オーディオインターフェースの Thunderbolt オーディオインターフェースです。 同じリアパネルコネクタがAXセンターとして補完されますが、フロントパネルのマイク/楽器入力とヘッドフォン出力は省略されます。 これは、コンパクトでラックマウント可能なThunderbolt オーディオコアがフロントパネルの入出力なしに必要な場合に使用できるように設計されています。 コア256は、外部12 V DC電源によって給電されます。

> **注意 — Core 256:** Racking the Core 256 はラック幅の半分単位です。 標準の19インチラックにマウントするには、専用の1UラックシェルフまたはCore 256ラックハードウェアアクセサリが必要です。 ラックオプションについては、[第 2 章 — システム要件]を参照してください。

## 4.4 MOM — オペレーティングモジュールの監視

### 4.4.1 概要

MOM(Monitor Operating Module)は、USB-C経由でAXセンターまたはAX64に接続するデスクトップモニタコントローラです。 モニタースピーカーの選択、ソース選択、マスターレベル、dimを物理的に制御します。 DADman ソフトウェアウィンドウとの相互作用を必要とせずに、切り取り、トークバック、および参照レベルを指定します。 MOMはホストのAXセンターまたはAX64とUSBを介して通信し、独自のオーディオ回路を含んでいません - それは制御面のみです。 オーディオ信号はMOM経由でルーティングされません。

> **注意:** MOMはAXセンターまたはAX64の背面にあるUSB-Cポートを介してDADmanを実行しているコンピュータに接続します。 コンピュータのUSBポートに直接接続されません。 DDman は、MOM が機能するために実行する必要があります。

## 4.6 Penta 720 / 721s

### 4.6.1 概要

Penta 720とPenta 721は、NTPテクノロジーのモジュラーオーディオインターフェイスと信号変換プラットフォームです。 サンダー\|コア製品 (AX Center, AX 64, Core 256) とは異なり、Pentaユニットはイーサネット経由でコンピュータに接続します。Thunderbolt接続はありません。 DADmanは、ルーティング、フォーマット変換、および設定のための制御ネットワーク上でPentaユニットと通信します。 ペンタユニットは、通常、放送およびポストプロダクション環境における高チャネル数のAES/EBUおよびMADI I/O、フォーマット変換、およびネットワークオーディオ配信に使用されます。

ペンタ720は2Uラックマウントシャーシで、内部スロットで拡張カードを受け付けています。 ペンタ721はスリムな1U品種です。 後部パネルコネクタの補数は、接続されている拡張カードによって異なります。 .3は、スロット1のDante/AES67 I/Oカードを使用した典型的な構成を反映しています。
