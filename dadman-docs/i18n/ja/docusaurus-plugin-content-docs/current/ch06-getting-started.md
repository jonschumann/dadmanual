## 目的

この章では、最初の打ち上げから確認されたオーディオまで、可能な限り最短の方法で、完全に動作する DADman のセットアップについて説明します。 お使いのコンピューターに DADman がインストールされていることを前提としています。 そうでない場合は、最初に[チャプター3—インストール]を完了してください。

それぞれのステップでは、何をすべきか、何をすべきか、何をすべきか、そしてより詳細に必要なときに完全な参照を見つけるための場所が示されています。

**推定時間:** 1つのユニットで初めてのセットアップのための15-20分。

## 始める前

起動前に以下を確認してください:

| 要件                                                                                               | チェック                                                                                                             |
| ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| DADman v5.8.2 build 2 (またはそれ以降) がインストールされています | [第3章セクション3.4]                                |
| ハードウェアユニットの電源はオンです                                                                               | ハードウェアインストールガイドを参照してください                                                                                         |
| ハードウェアユニットはコンピュータと同じイーサネットネットワークに接続されています                                                        | ダイレクトケーブルまたは共有スイッチ                                                                                               |
| Thunderbolt 3 オーディオを使用している場合: TB3 ドライバがインストールされ、Thunderbolt を介してユニットが接続されています    | [Chapter 3, Section 3.5–3.6] |
| ユニットの現在のIPアドレスに注意しました(フロントパネルの表示を確認してください)                                    | —                                                                                                                |

> **注 — macOS Sequoia (v15) ユーザー:** macOS Sequoia で最初に起動した場合、DADman がネットワーク上のユニットを発見できないことがあります。 30秒後に単位が表示されない場合は、macOSアカウントからログアウトして再度ログインしてください。 これは既知の OS レベルの問題です。Thunderbolt 接続は影響を受けません。 完全な回避方法については、[第3章、セクション3.7]を参照してください。

## DADman Interface at a Glance

DADmanが開くと、メインウィンドウには、**デバイスリスト** 領域で左から右に配置されたすべての接続されたハードウェアユニットが表示されます。 各ユニットは、チャンネルストリップの列として表示され、ユニットに割り当てられた色に隣接して表示されます。 5つのタブで様々な制御領域にアクセスできます

### 5つのタブ

| Tab      | フルネーム       | 何をコントロールするか                                                                            |
| -------- | ----------- | -------------------------------------------------------------------------------------- |
| **AD**   | アナログからデジタルへ | アナログ入力チャンネル — マイク/ラインゲイン、+48 V ファントムパワー、位相反転(Ø)、ミュート、ピーク計測、チャンネルラベル |
| **DA**   | デジタルからアナログへ | アナログ出力チャンネル — 出力レベルフェーダー、ミュート、信号/クリップメーター、チャンネルラベル                                     |
| **Con**  | コネクション      | 完全な信号ルーティングマトリクス — クロスポイントをクリックすると任意の入力が任意の出力に接続されるグリッド                                |
| **Conf** | 設定          | ユニット単位設定 — クロックソース、サンプルレート、アダプトトト、MADIフレームレート、ダンテ構成、ポートレベルオプション                        |
| **Mon**  | モニター        | モニターコントローラ — モニタープロファイルからロードされ、ソース選択、スピーカーセットボタン、レベルフェーダー、Ref/Dim/Cut コントロールを表示します。    |

> **注意:** Mon\*\* タブには、Monitorプロファイル(`.dmprof`ファイル)がロードされた時のみアクティブなコントロールが表示されます。 ロードまたは作成方法については、ステップ9を参照してください。

セクションヘッダーボタンをクリックすると、セクションが折りたたまれたり展開されたりします\*(v5.7.2以降)。 これは、小さな画面や複数のユニットを同時に使用する場合に便利です。

_[Placeholder: annotated screenshot — DADman main window show all 5 tabs, Device List, and unit border color]_

### デバイス リスト

デバイスリストを開くには、**設定 > デバイス リスト** または **⌘ L** (macOS) / **Ctrl+Shift+L** (Windows) を使用します。 デバイスリストには、DADmanがネットワーク上で発見したすべてのユニットが表示され、名前、ユニット ID、IPアドレス、およびファームウェアのバージョンが表示されます。 デバイスリストでユニットを右クリックすると、ネットワーク設定、更新ファームウェア、ファクトリーリセット、クローン、切断にアクセスできます。

### ファイルタイプ

DADman は以下の 2 つのファイルタイプを使用します:

| エクステンション  | 名前                   | ストア                                          |
| --------- | -------------------- | -------------------------------------------- |
| `.dms`    | DADman 設定ファイル        | すべての単位設定 — ルーティング、ゲイン、ラベル、Confタブパラメータ        |
| `.dmprof` | DADman Monitorプロフィール | コントローラの構成をモニターする — ソース、スピーカーセット、折りたたみ、トークバック |

これらのファイルは独立している。 一方を保存すると、他方を自動的に保存しません。 両方を保存し、バックアップする必要があります。

## ステップバイステップのウォークスルー

### ステップ 1 : DADman を起動

アプリケーションフォルダ(macOS)またはスタートメニュー(Windows)から**DADman**を開きます。

**期待される結果:** DADman のメインウィンドウが開きます。 すぐにユニットが見つからない場合は、**デバイスリスト** ウィンドウが自動的に開きます。

> **注意:** DADman v5.7.0 から、アプリケーションは継続的にユニットへの接続を再試行します。タイムアウトはありません。 ユニットの電源がオンになっていて、ネットワーク上に到達できる場合は、デバイスリストに手動操作が不要になります。

\*[Placeholder: screenshot — DADman mainwindow at launch with empty Device List] \*

### ステップ 2 — デバイスの検出を確認

最大 30 秒待機します。 AXセンター（またはその他の接続ユニット）は**デバイスリスト**に色付きの境界線を持つ行として表示されます。

**期待される結果:** ユニット行にはユニット名、ユニットID番号、ファームウェアバージョンが表示されます。 接続インジケーターがアクティブです (グレーアウトではありません)。

_[Placeholder: screenshot — 色付き接続されたAXセンターを表示するデバイス一覧]_

30秒後に単位が表示されない場合:

- ユニットの電源が入っていることを確認し、フロントパネルの **Ready** LED が緑色です。
- イーサネットケーブルがユニットとコンピューター(またはスイッチ)の間で接続されていることを確認します。
- ユニットのIPアドレスがコンピュータのネットワークインターフェイスと同じサブネットにあることを確認します。 ユニットのフロントパネルで確認できます。
- Windowsでは、ファイアウォールがDADmanをブロックしていないことを確認します。 必要に応じてファイアウォール例外を追加します。
- 診断テーブル全体については、[第 9 章 — トラブルシューティング、第 9.2 節 — ネットワークと接続の問題] を参照してください。

> **ヒント:** **設定 > デバイス リスト** または **⌘ L** (macOS) / **Ctrl+Shift+L** (Windows) を使用して、デバイスリストが表示されていない場合は、デバイスリストを直接開きます。

---

### ステップ 3 : ユニットに名前を付ける

デバイスリストでユニットの**名前フィールド**をクリックし、説明名を入力します。たとえば、`AX Center - Studio A` などです。

**期待される結果:** 名前はすぐに更新され、ユニット自体に格納されます。 フロントパネルディスプレイ付きのユニットに表示され、どのコンピュータ上でもDADmanセッション全体に表示されます。

> **注意:** ユニット名はハードウェアユニットに保存されます。 ステップ5で割り当てられたチャンネルラベルは、コンピュータの設定ファイル`.dms`に保存されます。

---

### ステップ 4 — 時計のソースとサンプルレートを設定する

> **このステップはパッチを適用する前に完了する必要があります。** システム内のすべてのデジタルオーディオデバイスは、共通のサンプルクロックを共有する必要があります。 クロック設定を確認する前にルーティングを設定すると、事実の後で診断が困難なクリック、ポップ、またはサイレンスが発生する可能性があります。

1. **Conf** タブをクリックします。
2. **同期**セクションで、システムに合わせて**ソース**を設定してください：

| システム構成                      | ソース設定                                                         |
| --------------------------- | ------------------------------------------------------------- |
| このユニットはシステムクロックマスターです       | **内部**                                                        |
| ワードクロック信号からのクロック            | **Word Clock**                                                |
| Danteネットワークからのクロック          | **Dante**                                                     |
| 接続されたDAWのサンプルレートを自動的に一致させます | **適応** → **Thunderbolt 3** (または関連するデジタル入力) |

3. セッションに合わせて**サンプリングレート**を設定してください — 通常、放送やポストプロダクションでは**48kHz**、音楽では**44.1 kHz**です。
4. ワードクロック入力を使用する場合は、**同期終了**を**75 Ω**に設定してください。

**期待される結果:** **Conf** タブに表示されているサンプルレートは、ご希望のレートと一致します。 **Adapt To** が外部ソースに設定されている場合、表示されたレートは検出された外部レートに合わせて自動的に更新されます。

_[Placeholder: screenshot — Confタブに表示されるソースと設定済みサンプルレート]_

> **ヒント:** AXセンターがあなたのシステムで唯一のデジタルデバイスである場合は、**ソース**を**内部**に設定し、手動でサンプルレートを選択してください。 これにより、外部クロックに依存しない完全な制御が可能になります。

完全な参照: [第 7章, セクション 7.3 — 時計と同期]

### ステップ 5 : ラベルとアナログ入力の構成

1. **AD** タブをクリックします。
2. 有効な各入力チャンネル:
   - **channel label** フィールドをクリックし、名前を入力します (例: `Kick`, `OH L`, `Room`)。
   - 入力タイプを選択: **MIC** または **LINE** 。
   - コンデンサーマイクの場合：**+48V**ファントム電源を有効にします。 製造業者が互換性を確認しない限り、リボンマイクでファントム電源を有効にしないでください。
   - **MICゲイン**スライダーを保守的な開始レベルに設定します。 サウンドチェック中は上向きに調整してください。
   - 必要に応じて**Ø** (位相反転) を有効にします。

**期待される結果:** 音声が-42 dBFSを超えると**信号** LED(緑)が点灯します。 **クリップ** LEDは通常の信号レベルでは点灯しないでください。

\*[Placeholder: screenshot — 2つのマイクチャンネルを設定したAD タブ、Signal LED lit] \*

> **ヒント:** チャンネルが選択されている場合は、\*\*Default/ \*\* 矢印キーを使用して、0.1dB 単位でゲインを調整します。 **Shift**を追加することで、解像度を上げることができます。 これは、マウスドラッグ(0.5dBステップ)よりも正確です。

完全な参照: [チャプター7, セクション 7.4 — ゲインとレベル管理]

### ステップ6 — 出力への入力ルートを設定する

1. **Con** タブをクリックします。
2. ルーティングマトリクスは、**入力は行として**、**出力は列として**上部に表示されます。
3. 入力行の交差点でクロスポイントをクリックし、出力列を接続します。 **塗りつぶされた青い正方形**が接続を確認します。

| アクション          | ショートカット                     |
| -------------- | --------------------------- |
| 1つのチャンネルを接続する  | シングルクリック                    |
| ステレオペアを接続する    | **Shift** + クリックして最初のチャンネル  |
| 同じ番号のI/Oを斜めに接続 | **Ctrl/Cmd** + クリック         |
| 接続を解除          | もう一度塗りつぶされた青い正方形をクリックしてください |

**期待される結果** 接続されているクロスポイントに青い四角が表示されます。 出力列ヘッダーには、出力がパッチされていることを確認する青色のインジケータが表示されます。

_[Placeholder: screenshot — オーバービューと詳細マトリクスを表示するクロスポイントが接続されたConタブ ]_

> **注意:** マトリクスに表示される入出力の数はハードウェア構成と現在のサンプルレートを反映します。 より高いサンプリングレートでは、いくつかのフォーマット(MADI、ADAT)では、より少ないチャネルを運ぶことができます。

完全な参照: [第 7章, セクション 7.2 — I/O 設定とパッチ]

### ステップ 7 — 出力レベルを設定

1. **DA** タブをクリックします。
2. アクティブな出力チャンネルごとに**出力レベルフェーダー**を設定し、下流機器の入力仕様に合わせて設定します。

フェーダーの値は、ボリュームコントロールではなく、0dBFSデジタルフルスケールに対応するdBuの\*\*アナログ出力レベルです。 一般設定:

| 下流機器                                         | 標準出力レベルの設定       |
| -------------------------------------------- | ---------------- |
| プロのパワーアンプ(+4 dBu nominal) | **+18 dBu**      |
| 放送装置（EBU R68 アライメント）                         | **+18 dBu**      |
| セミプロ・プローマー装備(-10dBVノミナル)  | **+4 to +8 dBu** |

> **注意:** 下流機器の最大入力を超える出力レベルを設定すると、DADman 信号が過負荷を示さない場合でも、その機器がクリップされます。 出力レベルが下流デバイスの最大入力仕様を超えないことを常に確認してください。

\*[Placeholder: screenshot — DAタブと出力レベルフェーダーセット付き] \*

完全な参照: [チャプター7, セクション 7.4 — ゲインとレベル管理]

### ステップ 8 — オーディオのエンドツーエンドの確認

入力に信号がある場合、システムにオーディオが流れていることを確認します。

1. **AD タブ:** アクティブな入力で信号LED (緑)を点灯します。
2. **Conタブ:** 詳細行列の左側にステータスインジケータを入力すると緑色（有効な信号）が表示されます。 黄色は同期/クロックの不一致を示します — ステップ4に戻ります。
3. **DA タブ:** 信号LED はアクティブな出力で点灯します。
4. **目的地:** スピーカー、レコーダー、メーターシステムでは、オーディオは可聴または測定可能です。

**信号の LED が緑色で、オーディオが出力に達していない場合:**

- **Con**タブでルーティングクロスポートを確認します。
- **ミュート**が関連するADチャンネルまたはDAチャンネルに反映されていないことを確認してください。
- **Conf** タブの **Source** クロック設定が正しいことを確認してください — Conf\*\* の黄色の状態は時計の問題を示します。

**クリップLEDが点灯した場合:**

- **AD** タブの **MIC ゲイン** を減らします。
- 下流機器がクリッピングされている場合は、**DA** タブの出力レベルフェーダーを減らします。

### ステップ 9 — モニタープロファイルをロードまたは作成

DADmanのモニターコントローラー(PRO\|MON)を使用している場合は、アクティブなコントロールが表示される**Mon**タブの前にモニタープロファイルが必要です。

**既存のプロファイルをロードするには:**

1. **File > Open Profile…** (macOS: ** ⌘O** / Windows: **Ctrl+Alt+O**)
2. `.dmprof`ファイルを選択します。

**新しいプロファイルを作成するには**

1. **設定 > モニタープロファイル** エディターを開きます。
2. **ソース** → **新しいソースを追加** → ルーティングから入力を割り当てます。
3. **出力** → **出力セットを追加** → スピーカー設定ごとにアナログ出力を割り当てます。
4. **File > Save Profile As…** (macOS: **⌥⌘⇧S** / Windows: **Ctrl+Alt+Shift+S**)

**期待される結果:** **モン** タブにはソースセレクター、スピーカー出力ボタン、メインレベルフェーダー、**Ref**、**Dim**、**Cut** コントロールが表示されます。

\*[Placeholder: screenshot — モニタープロファイルがロードされた月タブ] \*

完全な参照: [チャプター8, セクション8.1 — プロファイルの監視]

### ステップ 10 : 参照レベルを設定します(オプション)

あなたの部屋が音響的に校正されている場合:

1. テストトーンと較正済みのSPLメーターを使用する メインレベルフェーダーを **Mon** タブに設定し、ターゲットリファレンスの SPL (85 dB SPL はほとんどの放送およびポストプロダクション環境で標準) に設定します。
2. **Settings > Monitor Profile**では、アクティブなスピーカーセットの**Reference Level**としてこのレベルを記録します。
3. セッション中、**Mon** タブの **Ref** を押すと、即座にキャリブレーションされたレベルに戻ります。

> **ヒント:** 複数のスピーカー出力セットは同じ物理的な出力を共有できますが、異なるトリムオフセットを持っています — 「85 dB SPL」と「75 dB SPL」プリセットを作成すると、再キャリブレーションせずに切り替えることができます。

---

### ステップ 11 — 設定を保存

> **注意:** ユニットの設定はハードウェアに保存されます。 工場出荷時のリセットまたはファームウェアのアップデートでそれらが消去されます。 コンピュータの`.dms`ファイルは唯一のバックアップです。

1. **File > Save As…** (macOS: **⌘⇧S** / Windows: **Ctrl+Shift+S**)
2. 記述的なファイル名を使用してください: `StudioA_AXCenter_2026-06.dms`
3. 定期的にバックアップされた場所に保存します。

Monitorプロファイルをお持ちの場合は、別途保存してください:
**File > Save Profile As…** (macOS: ** ⌘ S** / Windows: **Ctrl+Alt+Shift+S**)

> **ヒント:** 起動時に**DADman > Preferences** (macOS) または **Settings > Options** (Windows) を有効にして、起動時にこの設定を自動的に復元します。 永久的なインストールに推奨されます。

---

### ステップ 12 — リロードの確認

1. DADmanを閉じます。
2. DADman を再開します。
3. 設定の再読み込みを確認してください — すべてのルーティング、ゲイン設定、およびチャンネルラベルは保存と同じように正確に復元されます。

**期待される結果:** `.dms`ファイルがロードされるとすぐにオンラインにアップデートされます。 format@@0タブには、プロファイルでも「起動時に最後のファイルを開く」が有効になっている場合に保存されたモニタープロファイルが表示されます。

## セットアップ完了

これで、DADmanシステムが動作します。

- ユニットが発見され、接続され、名前が付けられました。
- クロックソースとサンプルレートが確認されました
- 出力にラベル付け、ゲイン、パッチ適用された入力
- 下流機器に合わせた出力レベル
- オーディオ検証済みのエンドツーエンド
- 設定が保存され、再読み込みが確認されました

## キーボードとマウスの参照

### スライダー修飾キー

DADman のすべてのゲイン、レベル、フェーダースライダーは、次の修飾キーをサポートします。

| Modifier                                                                              | 効果                                                   |
| ------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| **ドラッグ** (修飾なし)                                                    | 通常の解像度 — 1ピクセルあたり約 0.5 dB            |
| **Shift + ドラッグ**                                                                      | 精度の向上 — 1ピクセルあたり約 0.1dB              |
| ** /  矢印キー** (スライダーにフォーカス)                               | 0.1dBステップ                            |
