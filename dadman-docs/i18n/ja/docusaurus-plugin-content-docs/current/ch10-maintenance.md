## 10.1 DADman ソフトウェアの更新

DADman アップデートは完全なインストーラパッケージとして配布されており、増分パッチではありません。 新しいバージョンをインストールすると、既存のインストールが置き換わります。

### 10.1.1 アップデート前

- インストールする前に、新しいバージョンの **リリースノート** を確認してください。 リリースノートでは、テスト済みの OS バージョン、ファームウェアの互換性要件、動作の変更、および新しい OS リリースに関する既知の問題について説明しています。 リリースノートは [digitalaudiosupport.com](https://www.digitalaudiosupport.com) のダウンロードセンターで入手できます。
- 新しいDADmanバージョンでサポートされているオペレーティングシステムがリストされていることを確認します。 すべてのDADmanバージョンがすべてのOSバージョンをサポートしているわけではありません。

### 10.1.2 DADman の更新 — macOS

1. 新しいDADmanインストーラ(`.pkg`)をDADサポートポータルまたはAvid Masterアカウントからダウンロードします。
2. 実行中の場合はDADmanを終了します。
3. インストーラをダブルクリックし、画面の指示に従います。 新しいバージョンは、既存のインストールを自動的に置き換えます。
4. インストール後、DADman を起動し、**DADman > About DADman** でバージョン番号を確認します。

### 10.1.3 DADman の更新 — Windows

1. DADサポートポータルから新しいDADmanインストーラ(`.exe`または`.msi`)をダウンロードします。
2. 実行中の場合は、DADman を閉じます。
3. インストーラをダブルクリックし、画面の指示に従います。 ユーザーアカウント制御プロンプトが表示されたら、**はい** をクリックします。
4. インストール後、**ヘルプ > DADmanについて**でバージョン番号を確認してください。

> **注意:** DADman を更新しても、ハードウェアファームウェアは更新されません。 これらは別々の手順を必要とする別々の操作です。 DADman のアップデートが推奨するか、対応するファームウェアのアップデートが必要かを判断するには、リリースノートを常に確認してください。

## 10.2 ハードウェアファームウェアの更新

### 10.2.1 クリティカル: 更新前に設定を保存

> **警告: 設定は失われます**  
> \*\*ファームウェアアップデートはハードウェアユニットに保存されているすべての設定を工場出荷時のデフォルト値にリセットします。 \* ルーティング構成、ゲイン設定、チャンネルラベル、モニタープロファイル、ルーティングプリセット、その他すべての保存されているパラメーターはファームウェアのアップデート中に永久に消去されます。 これらの設定を復元する唯一の方法は、以前に保存したDADman Settings File (`.dms`)を再読み込みすることです。

**ハードウェアファームウェアをアップデートする前に:**

1. DADman を開き、更新するユニットが接続され、デバイス リストに表示されていることを確認します。
2. Go to **File > Save As…** and save the current settings to a `.dms` file with a clear filename (e.g., `StudioA_AXCenter_pre-update_2026-06.dms`).
3. If a Monitor Profile is loaded, save it separately: **File > Save Profile As…**
4. 両方のファイルがバックアップされている場所に保存されていることを確認します。

> **ヒント:** DADman \*(v5.7.2以降)\*のファームウェアアップデート警告ダイアログには、設定をバックアップするためのリマインダーが含まれています。 バックアップが完了していることを確認せずにこのダイアログを閉じないでください。

### 10.2.2 ファームウェアファイルの取得

Firmware files for all DAD and NTP Technology hardware are available in the Download Centre at [digitalaudiosupport.com](https://www.digitalaudiosupport.com). 無料アカウントが必要です。

特定のハードウェアモデルのファームウェアファイルをダウンロードします。 別のモデルで1つのモデルからファームウェアを使用しないでください — ファームウェアはハードウェアファミリ間で互換性がありません。

### 10.2.3 DADman経由でファームウェアアップデートを実行する

1. DADmanを開きます。 更新するユニットが接続されていることを確認し、デバイス リストに表示されます。
2. デバイスリストでユニット(Windows)を右クリックするか、アクションボタン(macOS)を使用します。
3. **ファームウェアを更新**を選択します。
4. バックアップリマインダーダイアログが表示されたら(バックアップが完了したことを確認した後)format@@0またはformat@@1をクリックします。
5. ダウンロードしたファームウェアファイルを参照して選択します。
6. ファームウェアのアップデートが開始されます。 進行状況インジケーターに更新ステータスが表示されます。
7. ユニットへの電源を中断したり、更新中にDADmanを閉じたりしないでください。 中断されたファームウェアの更新により、ユニットが起動できなくなり、工場出荷時の復旧が必要になる可能性があります。
8. アップデートが完了すると、ユニットは自動的に再起動します。 デバイス リストには、ユニットの切断と再接続が表示されます。 **準備完了** LED が緑色に戻るのを待ちます（最大 60 秒）。
9. デバイスリストで新しいファームウェアのバージョンを確認します。 Reload your `.dms` settings file via **File > Open…**.

> **注意:** ファームウェアアップデート中にハードウェアユニットへの電源を中断しないでください。 アップデート中に停電が発生した場合は、ユニットの電源を入れる前に support@ntp.dk までお問い合わせください。

## 10.3 Danteファームウェアの更新

ダンテファームウェア(DADユニットのダンテモジュールおよびIPCoreハードウェア用)は、メインボードファームウェアとは別に更新されます。 **ダンテコントローラ** 内の **ダンテアップデーター** ツールを使用する — DADman 経由ではありません。

### 10.3.1 要件

- **ダンテコントローラ**はコンピュータにインストールする必要があります。 [audinate.com](https://www.audinate.com) からダウンロードします。
- DADユニットはダンテネットワークに接続し、ダンテコントローラに表示する必要があります。
- DADサポートポータルから適切なDanteファームウェアファイル(`.dnt`)をダウンロードしてください。 Danteファームウェアファイルは、各DADmanソフトウェアリリースにバンドルされています。

### 10.3.2 Dante ファームウェア更新手順

1. **ダンテコントローラ**を開きます。
2. **Device > Dante Updater** に移動し、Dante Updaterツールを開きます。
3. Dante Updater **Advanced Settings**で、**Allow Imported ファームウェア**を有効にします。 これは、DAD 提供のファームウェアファイルをロードするために必要です。
4. Dante Updaterで**Library**タブを選択し、**Imported Files**をクリックします。
5. **インポート**をクリックして、DADサポートポータルからダウンロードした`.dnt`ファームウェアファイルをインポートします。
6. Dante Updater **Home**タブに戻り、ファームウェアソースセレクタから**インポートされたファームウェアファイル**を選択します。
7. デバイスリストから更新するDADユニットを選択します。
8. 画面の指示に従って更新を開始します。
9. 更新が完了するまで待ちます。 ダンテモジュールは自動的に再起動します。

> **注意:** Brooklyn 3 Danteモジュールユーザー: v1.1.0.3 (2026年1月リリース) から、Brooklyn 3 は DDM (Dante Domain Manager) なしで**ST 2110** プロトコルをサポートします。 これには、最新のDanteファームウェアと最新のDanteコントローラの両方が必要です。 詳細はリリースノートを参照してください。

## 10.4 Thunderbolt 3 ドライバの更新

_AX64、AX センター、Core 256 ユーザーのみに適用されます。 イーサネット専用ハードウェアでスキップします。_

DAD Thunderbolt 3 ドライバ(DADDriverSetup)は、DADman とは別に更新されます。 Thunderbolt機能の改善が含まれると、ドライバのアップデートとともにファームウェアのアップデートがリリースされます。

### 10.4.1 macOS — ドライバの更新手順

> **注意:** macOSでは、新しいバージョンをインストールする前に古いドライバを削除する必要があります。 既存のドライバを最初に削除せずにインストールすると、macOS Sequoia 以降のドライバが正しく機能しません。

1. 新しい Thunderbolt 3 ドライバインストーラ(`.pkg`)を [digitalaudiosupport.com](https://www.digitalaudiosupport.com) からダウンロードします。
2. アプリケーションフォルダの**DADDriverSetup.app**を探します。
3. ゴミ箱に移動します（**右クリック>ゴミ箱に移動**） macOS はシステム拡張が削除されるという警告を表示します。続行することを確認します。
4. 新しいドライバインストーラを実行します。ダウンロードした`.pkg`をダブルクリックし、画面上のプロンプトに従います。
5. プロンプトが表示されたら、**システム設定 > プライバシーとセキュリティ**で新しいシステム拡張を承認してください。
6. プロンプトが表示されたらコンピュータを再起動します。
7. 再起動後、Applicationsから**DADDriverSetup**を開き、バージョン番号を確認します。
8. サンダー\|コアハードウェアを接続し、**オーディオ MIDI 設定**に表示されていることを確認してください。

### 10.4.2 Windows — ドライバの更新手順

1. 新しいASIOドライバインストーラ(`.msi`)を [digitalaudiosupport.com](https://www.digitalaudiosupport.com)からダウンロードします。
2. ASIOドライバを使用してオーディオアプリケーションを終了します。
3. **Settings > Apps** (または **Control Panel > Programs** ) を開き、既存の DAD Thunderbolt 3 ASIO ドライバーをアンインストールします。
4. コンピュータを再起動します。
5. 新しいドライバインストーラ(`.msi`)を実行し、画面上のプロンプトに従います。
6. オーディオアプリケーションを開き、更新されたドライババージョンが ASIO デバイス設定で表示されていることを確認します。

### 10.4.3 現在のドライバーのバージョン

| ------------------------------------------------------------ | -------- | -------------------------------------- |

## 10.6 クリーンアップ

**クリーニング材料:** すべてのDADハードウェアのフロントパネルとリアパネルとエンクロージャをきれいにするために、柔らかく乾燥した布のみを使用してください。 使用しない:

- 液体クリーナー、溶剤、または任意の種類のスプレークリーナー。
- 磨耗性の布またはパッド
- 換気口またはコネクタ開口部に向けられた圧縮空気。

**コネクタ:** コネクタの開口部にオブジェクトを挿入しないでください。 コネクタが汚染されている場合は、資格のあるサービス担当者に相談してください。

> **注意:** クリーンアップする前に電源からユニットを取り外します。 換気口またはコネクタ開口部を介して液体がエンクロージャーに入ることを許可しないでください。

**スクリーンとディスプレイ:** フロントパネル液晶ディスプレイ(AXセンター、MTRXスタジオ)のユニットは、柔らかく乾燥した布で清掃することができます。 スクリーンクリーニング液を使用しないでください。

**頻度:** 定期的なメンテナンススケジュールの一部として、フロントパネルと換気開口部を検査してきれいにします。 きれいなスタジオ環境で年に一度行われています 高められた塵レベルの環境でより頻繁に使用されています

## 10.7 ストレージ

ハードウェアユニットを長期間(数週間以上)保存する場合は、次の条件を維持する必要があります。

| パラメータ         | 条件                                                                                 |
| ------------- | ---------------------------------------------------------------------------------- |
| **温度**        | -20°C ~ +60°C (-4°F ~ +140°F)   |
| **湿度**        | 相対湿度が10~80%、結露しないこと。                                               |
| **パッケージング**   | 利用可能な場合は、元の包装に保管してください。 元のパッケージが使用できない場合は、露出された回路ボードまたはコネクタインターフェイスに静的包装を使用してください。 |
| **オリエンテーション** | フロントパネルを上向きにして、ラックマウントユニットを水平に保管する                                                 |
| **パワー**       | ストレージの前に電源から切断する                                                                   |

> **注意:** 冷たい状態で保管した後に電源を入れる前に、ユニットが室温に達することを許可します。 暖かい環境で冷たいユニットに給電すると、内部部品に結露が生じる可能性があります。
