## 5.1 イーサネットベースの制御アーキテクチャ

DADmanはTCP/IPプロトコルを使用して、イーサネット経由ですべての接続されたハードウェアユニットと通信します。 これはサポートされているすべてのハードウェア(Thunderbolt 3 経由でも接続されているユニットを含む)に適用されます。 イーサネット接続は制御データ (設定変更、ステータスモニタリング、メーター) のみを運びます。 オーディオはハードウェアに応じて、MADI、ダンテ、AES3、Thunderbolt 3 によって別々に伝送されます。

DADman は標準的なイーサネットネットワークを使用しているため、DADman を実行している単一のコンピュータが複数のユニットを同時に制御でき、すべてのユニットが同じネットワーク上に到達できるようになります。 ユニットは、ユニットID番号によって順序付けられた、DADman **デバイス一覧**の左から右に表示されます。

\*[プレースホルダー: システム トポロジー図 — ネットワークスイッチに接続された DADman を実行しているコンピュータ。複数の DAD ハードウェアユニットは同じイーサネットサブネット上にあります。 Thunderbolt ケーブルは別途使用して表示されます。|コアユニット] \*

### 5.1.1 Thunderbird用デュアル通信パス|コアハードウェア

A Thunderbird\|コンピュータに接続されたコアユニットは、2つの同時独立した通信パスを使用します:

| パス                | Protocol  | 目的                                               |
| ----------------- | --------- | ------------------------------------------------ |
| **イーサネット**        | TCP/IP    | DADman control — ルーティング、ゲイン、構成                   |
| **Thunderbolt 3** | TB3上のPCIe | オーディオ転送 — コアオーディオまたは ASIO 経由で DAW に表示されるインターフェイス |

イーサネット専用ハードウェア(AX32, DX32R, Pentaシリーズ)はイーサネットパスのみを使用します。 これらのユニットには Thunderbolt 3 ドライバは存在せず、オーディオインターフェースとしてコンピュータに表示されません。 これらのユニットからのオーディオは、MADI、ダンテ、またはAES3上で輸送されます。

\*[Placeholder: コンピュータとThunderbird\|コアユニット間の並列パスとして DADman と TB3 ドライバを示す図 — イーサネット上で通信する DADman Thunderbolt 3と通信しているTB3ドライバ イーサネット・パスのみを示すイーサネット・ユニットと対照されています。

## 5.2 デバイス リスト

デバイスリストは、すべての検出および接続されたユニットを表示するDADmanのトップレベルビューです。 各ユニットは、視覚的に識別し、隣接ユニットのユニットとそのコントロールを分離する色付きの境界線で表示されます。

DADmanが起動すると、前回のセッションで見つかったユニットに再接続しようとします。 起動時にDADman Settings File (`.dms`)が自動的にロードされるように設定されている場合、接続されたユニットに適用されます。 起動時に設定ファイルがロードされていない場合は、デバイス リスト内のユニットへの接続を手動で確立する必要があります。

デバイスリストの完全な参照については、[第7章7.3節:デバイスリスト]を参照してください。

## 5.3 ネットワークの推奨事項

> **注意:** 信頼性の高い制御のために、DADは一般的なスタジオや施設のネットワークとは別のDADman専用のイーサネットネットワークを使用することを強くお勧めします。 詳細なトポロジーガイドについては、[第3章、セクション3.7:ネットワーク接続の設定]を参照してください。

DADmanコントロールトラフィックは軽量です。 ただし、制御ネットワークをAudio over IP(Dante, AES67)と共有する場合は、EuControlを使用します。 あるいは一般的なインターネットトラフィックは断続的な接続を引き起こし リアルタイムのパラメータ更新を妨害します 専用のギガビットイーサネットスイッチ、またはコンピュータとユニット間の直接ケーブル接続が、すべてのプロフェッショナルな設置に推奨されるトポロジです。

## 5.4 IP アドレス

各ハードウェアユニットには、DADman を実行しているコンピュータと同じサブネット上に固有の IP アドレスが必要です。 ユニットは、静的なIPアドレス(専用の制御ネットワークに推奨)またはDHCP割り当てられたアドレスで構成できます。

IPアドレスは、Webブラウザインターフェースを介して、または初期接続後のDADman経由で、ユニットのフロントパネルディスプレイを介して設定されます。 初回IP割り当て手順については、特定のハードウェアモデルのインストールガイドを参照してください。

## 5.5 クロックとサンプリングレートの概要

クロックは、システム内のすべてのオーディオが動作するサンプルレートを決定します。 DADマン制御ハードウェアは、通常、より大きなオーディオインフラストラクチャの中心に位置しているため、複数のソースからのオーディオの受信とルーティングを行うことが、システムセットアップの最も重要な側面の1つです。

### 5.5.1 時計の階層構造

接続されたシステム内のすべてのデジタルオーディオデバイスは、クリックを避けるために共通のサンプルクロックを共有する必要があります。 サンプルレートのミスマッチによるオーディオアーティファクトです 1つのデバイスは**クロックマスター**として機能します。他のデバイスはすべて同期する**クロックスレーブ**です。

DADman制御されたハードウェアは、マスタまたはスレーブのいずれかとして機能し、複数のソースからクロックを生成することができます。

| クロックソース           | 説明                                                                             |
| ----------------- | ------------------------------------------------------------------------------ |
| **内部**            | このユニットは、選択したサンプルレートで独自のクロックを生成します。ユニットがシステムクロックマスターである場合に使用します。                |
| **ワードクロック**       | BNCワードクロック入力上の外部ワードクロック信号                                                      |
| **MADI**          | 受信するMADIストリームから抽出された時計                                                         |
| **Dante**         | ダンテオーディオネットワーク(PTPベース)から得られた時計                              |
| **AES3**          | 着信AES3信号から抽出された時計                                                              |
| **Thunderbolt 3** | 接続されたコンピュータ\*(サンダー\|コアハードウェア)\*から得られた時計                     |
| **アダプター**         | DADman は入力されたデジタル信号のサンプルレートと自動的に一致します — Pro Toolsやその他のDAWサンプルレートの変更に適応するのに便利です |

\*[プレースホルダ: クロックマスターを表示するクロック階層図 → ワードクロックバス→ クロックスレーブ; ダンテPTPを代替参照] \*

クロックソースとサンプルレートは、DADman の **Conf** タブで設定します。 完全なリファレンスは [チャプター7, セクション 7.5 — クロックと構成] を参照してください。

## 5.6 サンプルレートとチャンネル容量

一部のオーディオフォーマットでは、より高いサンプルレートでより少ないチャンネルを運ぶことができます。 以下の表は、DADハードウェアの最も一般的なフォーマットで、サンプルレートでチャネル容量がどのように変化するかを示しています。

| 書式                                                                                               | チャンネル44.1 / 48 kHz | チャンネル88.2 / 96 kHz | 176.4 / 192 kHz のチャンネル |
| ------------------------------------------------------------------------------------------------ | ---------------------------------- | ---------------------------------- | -------------------------------------- |
| MADI (standard)                                                               | 64                                 | 32 (S/MUX 2)    | 16 (S/MUX 4)        |
| MADI (高速)                                                                     | 64                                 | 64                                 | 32                                     |
| ダンテ (標準)                                                                      | 64                                 | 32                                 | 16                                     |
| Dante 256 IPCore _(v5.8.1.6)_ | 256                                | 128                                | 64                                     |
| ADATライトパイプ                                                                                       | 8                                  | 4 (S/MUX 2)     | —                                      |
| Thunderbolt 3 (DADドライバ)                                                       | 最大 256                             | 最大 256                             | 最大 256                                 |

> **注意:** 上の表のチャネル容量値は典型的です。実際の値は特定のハードウェアモデルとファームウェアのバージョンによって異なります。 付録Aの技術仕様書に記載されているユニットの容量を確認してください。
