## 7.1 セッション管理

### 7.1.1 設定ファイルと監視プロファイル

DADmanはシステム状態を保存および復元するために2つの異なるファイルタイプを使用します。 それらの違いを理解することは、セッション管理に不可欠です。

#### DADman 設定ファイル (.dms)

**DADman Settings File** (file extension `.dms`) は、保存時に接続されているすべてのユニットのすべての設定のスナップショットを保存します。 これには以下が含まれます：

- アナログ入力ゲイン、ファントムパワー、パッド、位相、チャネルラベル (AD セクション)
- アナログ出力レベル、ミュート、およびチャンネルラベル(DAセクション)
- ルーティングマトリクス状態を完了します(コンセクション)
- クロックソース、サンプルレート、フォーマットの設定 (Confセクション)
- ネットワーク構成とユニットIDの割り当て
- Control\|Packルーティングプリセット設定\*(v5.8.0以降)\*

設定ファイルは、\*\*ファイル > 保存 \*\* または **ファイル > 名前を付けて保存** で保存され、コンピュータに保存されます。 これらはロードされるまで直接ユニットには影響しません — DADman がネットワークを介して接続されたユニットに保存された設定を適用します。

> **注意:** ファームウェアアップデートは、ユニットに保存されているすべての設定を工場出荷時のデフォルトにリセットします。 ファームウェアの更新を実行する前に、必ず`.dms`ファイルを保存してください。 [第 10 章, 第 10.1 節 — ファームウェアの更新]をご覧ください。

#### DADman Monitor Profile File (.dmprof)

**モニタープロファイルファイル** (ファイル拡張子`.dmprof`)は、モニターコントローラーの構成をユニット設定とは独立して保存します。 モニタープロファイルの定義:

- モニターソース (モニターコントローラーに割り当てられた入力)
- スピーカー出力セット (モノラル、ステレオ、サラウンド、没入型 — 最大 64 チャンネル)
- 折りたたみ行列（例：5.1からステレオ、カスタムアップマッチプリセット）
- 出力セットごとの遅延設定
- Talkback ルーティングとレベル
- リファレンスレベルの設定

モニタープロファイルは**設定 > モニタープロファイル**で管理され、`.dms`設定ファイルとは別のファイルとして保存されます。 この分離により、同じ物理的ルーティングとゲイン構成を異なる監視設定で使用できます。

デフォルトのステレオモニタープロファイルは、DADサポートポータルからダウンロードできます。

#### 2つのファイルタイプ間の関係

|                            | 設定ファイル (.dms) | モニタープロファイル (.dmprof) |
| -------------------------- | ------------------------------------------------ | ------------------------------------------------------- |
| **ストア**                    | すべてのハードウェア設定（ゲイン、ルーティング、クロック）                    | コントローラー構成のモニターのみ                                        |
| **スコープ**                   | すべての接続ユニット                                       | 一度に 1 つのモニタープロファイル                                      |
| **Load via**               | ファイル > 開く                                        | 設定 > モニタープロファイル > 読み込み                                  |
| **Auto-load on startup**   | 省略可能                                             | 省略可能                                                    |
| **ファームウェアのアップデートに影響を受けます** | はい — ユニットリセットは設定をクリアします                          | いいえ — コンピュータにのみ保存されています                                 |

### 7.1.2 Startup and Auto-Load

起動時に最後に使用した設定ファイルを\*\*自動的に読み込むようにDADmanが設定できます。 このオプションが有効になっている場合、DADman は手動操作を必要とせずに起動時に接続されたユニットに保存された設定を適用します。

> **注意:** 「起動時に最後のファイルを開く」オプションを使用すると、起動時にすべての接続されたユニットにDADmanが保存された設定をすぐに書き込むことができます。 異なるユーザーがリアルタイムの変更を行っているマルチオペレータ環境では、このオプションを有効にすると、前回の保存時から行われた変更が上書きされます。

自動ロードを有効または無効にするには: **DADman > Preferences** (macOS) または **Settings > Options** (Windows) を選択し、**起動時に最後のファイルを開く** 。

### 7.1.3 ファイルメニューリファレンス

| メニュー項目               | アクション                                                                                                                                                                  |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **新しい**              | DADmanの現在の設定をクリアします。 接続されたユニットの設定は変更されません。                                                                                                                             |
| **Open…**            | DADman Settings File (`.dms`) を開き、保存されている設定を接続されているユニットに適用します。                                                                                      |
| **保存**               | 接続されているすべてのユニットの現在の状態を、現在開いている `.dms` ファイルに保存します。                                                                                                                      |
| **Save As…**         | 現在の状態を指定した場所の新しい `.dms` ファイルに保存します。                                                                                                                                    |
| **Open Profile…**    | モニタープロファイル(`.dmprof`)ファイルをディスクから開き、format@@0タブにロードします。                                                                    |
| **インポートプロファイル…**     | 現在接続されているすべてのユニットからモニタープロファイルをインポートし、現在のユニットのI/Oに最適なマッピングを実行します。 ハードウェア構成が異なるユニット間でプロファイルを移行する場合に便利です。 _(v5.6.2以降)_ |
| **プロファイルを保存**        | 現在ロードされているモニタープロファイルを既存の`.dmprof`ファイルに保存します。                                                                                                                           |
| **Save Profile As…** | モニタープロファイルを指定した場所に新しい`.dmprof`ファイルに保存します。                                                                                                                              |
| **プロフィールを閉じる**       | 現在のモニタープロファイルをアンロードします。 format@@0タブには、新しいプロファイルがロードされるまでアクティブなコントロールは表示されません。                                                                |
| **最近のプロフィールを開く**     | 最近使用した `.dmprof` ファイルのサブメニューを開いて素早くアクセスできます。 _(v5.7.2以降)_                                                           |

> **ヒント:** セッションの最後に設定が変更されていない場合でも、**ファイル > 名前を付けて保存**を使用してください。 `.dms`ファイルは、ユニットの工場出荷時のリセットまたはファームウェアの更新後の唯一の回復パスです。

## 7.2 ウィンドウレイアウトとナビゲーション

DADmanのメインウィンドウは、上から下に積み上げられた4つの水平ゾーンに分かれています。

| ゾーン                                               | 内容                                                   |
| ------------------------------------------------- | ---------------------------------------------------- |
| **メニューバー**                                        | **ファイル** と **設定** メニュー （そして macOSでは **DADman** メニュー） |
| **デバイスリスト**                                       | 接続されたユニットごとに1行、それぞれが色付きの境界線にあります                     |
| **タブ行**                                           | **AD · DA · Con · Conf · Mon** tab selectors         |
| **チャンネルストリップ領域**                                  | 選択したタブのパラメータ表示、接続されているすべての単位にまたがります。                 |
| **コントロール\|パックストリップ** _(オプション)_ | ルーティングプリセットが設定されている場合、チャンネルストリップ領域の下に表示されます          |

タブをクリックすると、チャンネルストリップ領域全体が切り替わり、すべての接続ユニットのタブコントロールが同時に表示されます。 各ユニットのコントロールは、どのタブがアクティブであるかに関係なく、色付きの境界線内にグループ化されます。

単位表示内の個々のサブセクションは、**セクションヘッダーボタン** (AD、DA、Con、Conf、Mon) _(v5) をクリックすることで折りたたんだり展開したりできます。 (2以降)_。 セクションヘッダボタンにカーソルを合わせると、ツールチップが表示されます。 これは、垂直スクロールを減らすために多数のユニットを扱う場合に便利です。

### 7.2.1 5つのメインタブ

| Tab      | フルネーム                                        | 表示されるもの                                             |
| -------- | -------------------------------------------- | --------------------------------------------------- |
| **AD**   | アナログ対デジタル                                    | すべてのアナログ入力の計測と制御：ゲイン、ファントムパワー、ミュート、フェーズ、ラベル         |
| **DA**   | デジタル対アナログformat@@0 | すべてのアナログ出力の計測と制御: レベル、ミュート、ラベル、出力範囲 |
| **Con**  | コネクション                                       | ルーティングcrosspoint matrix — 入力、列として出力                 |
| **Conf** | 設定                                           | クロックソース、サンプルレート、Adapt To、Dante、およびデジタルI/Oポート設定      |
| **Mon**  | モニター                                         | アクティブなモニタープロファイル：ソース、出力、fold-downs、遅延、talkback      |

### 7.2.2 マルチユニットビュー

複数のユニットが接続されている場合、DADman はすべてのユニットを同じウィンドウ内に表示します。 タブはグローバルに適用されます。**AD** を選択すると、接続されているすべてのユニットのアナログ入力コントロールが同時に表示されます。 これにより、単一のオペレータは、別々のアプリケーションウィンドウを切り替えることなく、1つのビューから複雑なマルチユニットシステムを管理することができます。

### 7.2.3 カラースキーム

3 つの配色は **Settings > Options** (Windows) または **DADman > Preferences** (macOS) で利用できます。 このマニュアルのすべての例では、デフォルトのスキームが使用されます。 スキーム選択は、コンピュータに保存されているローカル環境設定であり、接続されているユニットには影響しません。

### 7.2.4 設定メニューリファレンス

| メニュー項目                                                                                  | アクション                                                                                                                                                                               |
| --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **オプション…** (Windows) / **DADman > 環境設定…** (macOS) | 環境設定ウィンドウを開きます                                                                                                                                                                      |
| **モニタープロファイル**                                                                          | モニタープロファイルエディターを開きます。[Section 7.8] と [Chapter 8] を参照してください。 |
| **ルーティングプリセット**                                                                         | Control\|Pack Routing プリセット設定ウィンドウを開きます (v5.8.0 以降)\*                                                                            |
| **EuCon** を有効にする                                                                        | Avid コントロールサーフェス接続のための EuControl 統合を有効にする                                                                                                                                           |
| **デバイスリスト**                                                                             | デバイス リスト管理ウィンドウを開きます                                                                                                                                                                |

## 7.3 デバイス リスト

デバイスリストは、検出されたすべてのハードウェアユニットを示すDADman ウィンドウの上部にある水平ストリップです。 単位は、**左から右へ昇順の単位ID**で現れます。

_[Placeholder: annotated Device List screenteed with two units with colored borders, unit ID fields, unit name fields, and connection status indicators]_

### 7.3.1 デバイスリスト列

| 要素               | 説明                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------ |
| **ユニット ID**      | デバイス リスト内のユニットの位置を決定する数値(左から右)。 Editable — IDフィールドをクリックして変更します。 IDは単位に格納されます。             |
| **ユニット名**        | ユニットのユーザー割り当て名称。 Editable : 名前を変更するには、名前フィールドをクリックします。 ユニットに格納され、フロントパネルが表示されているユニットに表示されます。 |
| **接続状態**         | DADman がユニットにアクティブな接続を持っているかどうかを示します。 切断されたユニットが灰色で表示されます。                                                   |
| **ファームウェアバージョン** | ユニットで実行されている現在のファームウェアバージョンを表示します。                                                                           |

> **ヒント(v5.8.1.6, macOSのみ):** デバイスリストは、カラムヘッダー(ユニット名、ID、ファームウェアのバージョン、その他のカラム)をクリックすることでソートできます。 これは多数のユニットを管理する場合に便利です。 並べ替えは表示環境設定のみで、単位IDは変更されません。

### 7.3.2 デバイスリストコンテキストメニュー

単位行(Windows)を右クリックするか、**アクション** ボタン(macOS)を使用すると、次のオプションを含むコンテキストメニューが開きます。

| Option          | アクション                                       |
| --------------- | ------------------------------------------- |
| **ネットワーク設定**    | 選択したユニットの IP アドレスとネットワーク構成ダイアログを開きます。       |
| **Clone from…** | 同じハードウェアファミリ内の別のユニットからこのユニットにすべての設定をコピーします。 |
| **ファームウェアの更新**  | 選択したユニットのファームウェアアップデートを開始します                |
| **工場出荷時のリセット**  | ユニットのすべての設定を工場出荷時の設定にリセット                   |
| **切断**          | アクティブなデバイスリストからユニットを削除します。                  |

> **注意:** **工場出荷時リセット** と **ファームウェアアップデート** 両方とも、ユニットに保存されているすべての設定をクリアします。 いずれかのオプションを使用する前に `.dms` ファイルを保存します。

### 7.3.3 チャンネル名

ADタブとDAタブにはチャンネル名(個別の入力チャンネルと出力チャンネルのラベル)が割り当てられています。

> **Note: 重要：** チャンネル名はコンピュータの**DADman Settings File (`.dms`)**に保存されています。ハードウェアの単位には**保存されていません**。 これは、`.dms`ファイルを読み込まずにDADmanが使用されている場合、または別のコンピュータがユニットに接続されている場合にチャンネル名が失われることを意味します。 設定ファイルを保存するときは、常にチャンネル名を含めます。

## 7.4 AD タブ — アナログ入力

**AD** タブには、すべてのアナログ入力チャンネル(マイク、DI、およびラインレベル)の計量と制御が接続されたユニットに表示されます。 ユニットにアナログ入力カードがインストールされていない場合、このタブは存在しますが、そのユニットについては空です。

_[Placeholder: 注釈付きADタブのスクリーンショットでマイクチャンネルをゲインスライダー、ファンド、ミュート、クリップ/シグナルインジケータ付きで表示されます]_

### 7.4.1 チャンネルストリップコントロール

各アナログ入力チャンネルには、以下のコントロールが上から下に表示されます。

| コントロール                                  | 説明                                                                                                                                                                                                                                                    |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **入力タイプセレクター**                          | 入力を **MIC** (マイクプリアンプ) と **LINE** (ラインレベル) 間で切り替えます。 マイクプリアンプハードウェアのあるチャンネルでのみ利用できます。                                                                                                                           |
| \*\*幻の力 (+48 V) \*\* | 選択したチャンネルで48Vのファントム電源を有効にします。 MICモードでのみ利用できます。 コンデンサーマイクのみに適用する — リボンマイクでは、メーカーが互換性を指定しない限り、有効にしないでください。                                                                                                                                              |
| **フェーズ反転 (Ø)**       | 入力信号の極性を180°反転します。                                                                                                                                                                                                                                    |
| **Mono / stereo link**                  | ステレオ操作のために隣接するオッズ/偶数チャンネルペアをリンクします。 ペアのコントロールはリンクされたときにギャングされます。                                                                                                                                                                                      |
| **MICゲインスライダー**                         | マイクロホンプリアンプのゲインを設定します。 増分を調整するには [7.4.2] を参照してください。                                                                                                               |
| **ミュート**                                | 入力チャンネルをミュートします。 ミュート状態はユニットに格納されます。                                                                                                                                                                                                                  |
| **シグナル LED**                            | 入力信号が-42 dBFSを超えると照明されます。 信号の存在を示します。信号が有用なレベルであることを示しません。                                                                                                                                                                                            |
| **LEDをクリップ**                            | 入力信号が-0.5 dBFSを超えた場合に点灯します。 差し迫ったまたは実際のデジタルクリッピングを示します。 通常の動作中にこのLEDが点灯している場合、即座にゲインを下げます。                                                                                                                                            |
| **ピークホールド**                             | 到達した最高の信号レベルは、メーターバーに保持され、ゆっくりと減衰します。 継続的なモニタリングなしで、過渡的なピークの視覚的な記録を提供します。 AX32、Penta、およびMTRXハードウェアで利用可能 _(DADman v5.4.3からファームウェアv2.3.2.1以降が必要です_)。 |
| **チャネルラベル**                             | チャンネルのユーザー割り当て名称。 `.dms`ファイルに保存されます。 クリックして編集                                                                                                                                                                                                         |

### 7.4.2 ゲイン調整

MICゲインスライダーは、以下の方法で調整できます。

| 方法                                                 | 増分                            |
| -------------------------------------------------- | ----------------------------- |
| マウスドラッグ                                            | ステップあたり0.5 dB |
| キーボード \*\*<unk> \*\* (チャンネルを選択) | ステップあたり0.1dB  |
| キーボード **Page Up / Page Down**                      | 大きなステップ（DADエンジニアリングで確認する値）    |

> **ヒント:** チャンネルストリップをクリックして選択してください キーボードの矢印を使ってセッション中に マウスに手を動かすことなく

### 7.4.3 マイクゲイングループ \*(v5.8.1.6 以降) \*

[Mic Gain Groups]では複数の入力チャンネルを同時に調整できます — ドラムのマルチマイク設定に便利です。 オーケストラ・セッション、またはグループ全体で一貫した相対的な関係を必要とする状況。

**マイクゲイングループを作成するには:**

1. チャンネルのゲインコントロールを右クリックします(またはチャンネルのコンテキストメニューを使用します)。
2. **グループに追加**を選択し、グループ番号を割り当てます。
3. グループに含めるチャンネルごとに繰り返します。

**グループ行動:**

- グループ化された任意のチャンネルにゲインコントロールを移動すると、グループ内のすべてのチャンネルが同じ金額で移動します。
- **Alt / Option key + drag** はカーソルの下のチャンネルのみを調整し、グループを壊すことなく個々の微調整を行います。
- ミュートは、修飾キーに関係なく、すべてのグループチャンネルに同時に適用されます。

> **注意:** DADman が EuControl でコントロールされている場合、ミック・ゲイン・グループは期待通りに機能します — Avid サーフェスのスライダーとノブをゲインすると、グループ化されたすべてのチャンネルに影響します。 コントロールサーフェスからミュートすると、グループ化されたすべてのチャンネルが同時にミュートされます。

> **注意:** MTRXスタジオではマイクゲイングループはサポートされていません。 _(v5.8.1.6)_

### 7.5.2 出力レベル範囲と配置

出力レベルフェーダーは、0dBFSデジタルフルスケールに対応する\*\*アナログ出力レベルを設定します。 これは、ディジタルドメイン(dBFS)とアナログドメイン(dBu)の間の変換因子を決定する利得構造アライメント設定です。

**出力レベル範囲:** 2 つの範囲があり、**6 dB ゲイン** ボタンで選択できます:

| モード         | Range              | 最大出力             |
| ----------- | ------------------ | ---------------- |
| 標準          | -66 dBu から +18 dBu | 0 dBFS で +18 dBu |
| +6 dB ゲイン有効 | -60 dBu から +24 dBu | 0 dBFS で +24 dBu |

> **注意:** 高い出力レベルを設定することは、必ずしも適切ではありません。 ダウンストリーム機器の入力レベルが、DADman 出力レベルの設定よりも低い場合。 DADman信号がきれいになっても、下流機器はクリップします。 出力レベルの設定が供給される機器の最大入力仕様を超えないことを常に確認してください。 例: +24 dBu 出力を +18 dBu の最大入力で装置に設定すると、DADman 信号の -6 dBFS のクリッピングが発生します。

> **ヒント:** 下流機器の公称入力レベルと出力レベルを一致させ、最高のゲイン構造を実現します。 たとえば、モニターアンプの入力感度が+4dBuの場合。 DADman出力レベルを+18 dBuに設定すると、公称値よりも約14dBのヘッドルームが得られます。これは、ほとんどのモニタリングワークフローにとって快適なマージンです。

## 7.6 Conタブ — ルーティングマトリクス

**Con** タブには、接続されたハードウェアの完全な信号ルーティングエンジンであるルーティング クロスポイント行列が表示されます。 各入力は任意の出力にルーティングすることができ、任意の数の出力は同じ入力を同時に受信することができます。

### 7.6.1 マトリクスレイアウト

ルーティング マトリクスは、並べて2つのパネルに表示されます:

| パネル      | 内容                                                                    | 目的                                       |
| -------- | --------------------------------------------------------------------- | ---------------------------------------- |
| **概要行列** | すべての入力 (行) × すべての出力 (列)、小さなスケール | マトリクスのセクションに移動します; 全体的なルーティング状態を一目で表示します |
| **詳細行列** | 概要で選択した領域の拡大表示                                                        | 個々のクロスポイント接続を作成または削除する                   |

両方のパネルでは、\*\*入力は左に行として表示され、**出力はトップ**に列として表示されます。 入力行と出力列の交点(クロスポイント)で接続が行われます。

> **注意:** マトリックスに表示されている入出力は、実際にインストールされているハードウェアオプションと現在のサンプリングレートで利用可能なチャンネル数を反映しています。 より高いサンプリングレートでは、いくつかの形式(MADI、ADAT)がより少ないチャネルを運ぶため、表示される行数と列数を減らすことができます。

### 7.6.2 接続の作成と削除

| アクション                       | 結果                                                             |
| --------------------------- | -------------------------------------------------------------- |
| クロスポイントで **シングルクリック**       | その入力をその出力に接続します（すでに接続されている場合は切断します）                            |
| **Shift + click**           | クリックしたチャンネルと次の連続したチャンネルを同時に接続します(1つのステレオペア) |
| \*\*Ctrl / Cmd + crosspoint | 完全な対角線を接続 — クリックされたポイントからの同じ番号の出力に入力されたマップを作成します。              |

接続されたクロスポイントは、**塗りつぶされた青い正方形**として表示されます。

### 7.6.3 接続状態インジケーター：

**出力カラムのヘッダ（一番上の行）:**

| インジケーター：   | 意味                                    |
| ---------- | ------------------------------------- |
| マークなし      | 出力がどの入力にも接続されていません                    |
| ライトブルースクエア | 詳細なマトリクスビューでは現在表示されていない入力に出力が接続されています |
| ダークブルースクエア | 出力は、現在の詳細マトリクスビューで表示されている入力に接続されています  |

> **注意:** 同じ出力カラムで新しいクロスポイントをクリックすると、既存の接続が常に上書きされます。 出力が新しい入力に再割り当てられ、前の接続が削除されます。

**入力行のラベル（詳細行列の左側）:**

| 色      | 意味                                                        |
| ------ | --------------------------------------------------------- |
| **緑**  | 入力に有効なデジタルキャリアが存在します（またはアナログカードがインストールされ、アナログチャンネルでアクティブ） |
| **黄色** | この入力の損失またはサンプルレートの不一致を同期                                  |
| **赤**  | エラー — 有効な入力信号が検出されませんでした                                  |

> **ヒント:** デジタル入力の黄色のステータスは通常、ソースとユニットの現在のクロック設定の間のサンプルレートの不一致を示します。 **Conf**タブを確認し、ユニットのサンプルレートがソースと一致するか、**Adapt To**を有効にして入力します。

**参照レベルを設定するには:**

1. テストトーンと較正済みのSPLメーターを使用して、監視出力レベルを所望のリファレンスSPLに設定します。

3. モニタープロファイルエディター(**設定>モニタープロファイル**)で、スピーカーセットの**リファレンスレベル**としてこの値を入力します。

| 色     | 都道府県：        | 意味                                                                 |
| ----- | ------------ | ------------------------------------------------------------------ |
| **青** | アクティブ（マニュアル） | このバケツは現在ルートされています。 プリセットはマニュアルモードです — 自動切り替えはありません。                |
| **緑** | 武装（自動）       | このバケットは現在のアクティブなルートです。 プリセットは自動モードで、トリガーの状態に基づいて切り替える準備ができています。    |
| **赤** | トリガーエラー      | このバケットに割り当てられた信号検出器は、エラーを報告しました(信号損失、AE6整合性障害)。 |

**手動モードと自動モードを切り替えます:**

- **ダブルクリック** 緑色の (自動) バケットボタンをクリックして手動モードに切り替えます — ボタンは青になります。
- **ダブルクリック** 青い（マニュアル）バケツボタンをクリックして再アームの自動化 — ボタンは緑色になります。

> **ヒント:** ライブイベントまたはブロードキャスト、ラインチェック中のアーム自動化。 入力に失敗すると、プリセットはオペレータの介入なしに自動的に切り替わります。 必要なバケットボタンをダブルクリックすることで、いつでも自動切り替えを上書きできます。
