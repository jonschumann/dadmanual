# 第 10 章 — 技術仕様

> **製品:** Digital Audio Denmark Core 256

---

## 10.1 デジタルI/O

| パラメータ         | 値                      | 条件 / メモ           |
| ------------- | ---------------------- | ----------------- |
| Thunderbolt 3 | 256 ch in / 256 ch out | 48 kHz と 96 kHz で |
| ダンテAoIP       | 256 ch in / 256 ch out | 48 kHz            |
| ダンテAoIP       | 128 ch in / 128 ch out | 96 kHz            |
| MADI          | 64 ch in / 64 ch out   | 48 kHz            |
| ADAT / SMUX   | 16 ch in / 16 ch out   |                   |
| S/PDIF        | 2 ch input             | ADATコネクタ経由で       |
| DADリンク（SFP経由） | 最大 256×256 ch          | 48 kHz            |
