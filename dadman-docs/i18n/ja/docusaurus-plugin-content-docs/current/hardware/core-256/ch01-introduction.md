# 第 1 章 — はじめに

> **製品:** Digital Audio Denmark Core 256

---

## 1.1 製品概要

Core 256はコンパクトなハーフラックThunderbolt 3オーディオインターフェースで、同じリアパネルコネクタを共有することでAXセンターと補完できますが、フロントパネルのI/Oはありません。 これは、高チャネル数 Thunderbolt コアがスペースに制約されたラックに必要とされるインストール用に設計されています。

**ホストへの接続:** Thunderbolt 3
**フォームファクタ:** ハーフラック (1U with shelf/bracket)
**オーディオチャンネル:** 48 kHz で最大256×256 チャンネル

---

## 1.2 主な機能

![Core 256 — front](/img/panel-core256-front-clean.png)
_Core 256 — front_

![Core 256 — rear](/img/panel-core256-rear-clean.png)
_Core 256 — rear_

- **フォームファクタ:** ハーフラックデスクトップ; 1U rack-mountable with optional C256-2MOUNT-BRACKET
- **拡張スロットはありません** — すべてのI/Oは内蔵インターフェイスを介しています
- **Thunderbolt 3:** 2 × USB-C — 256 チャンネル 48/96 kHz; 1 ポートあたり 15 W バス電力
- **Dante AoIP:** 内蔵の — 256 チャンネル 48 kHz, 128 チャンネル 96 kHz
- **MADI:** 内蔵同軸MADI I/O — 48 kHz の64 チャンネル
- **ADAT / S/PDIF:** 内蔵ADAT/SMUX (16 ch) および S/PDIF (2 ch)
- **DADlink:** 2 × SFP ケージ — DADlink (最大 256×256 ch) または MADI 光学系
- **同期:** Word Clock I/O (BNC, 75 Ω), ビデオブラックバースト入力
- **ルーティング：** 848×848行列; 512×64合算プロセッサ; 1,024フィルタSPQイコライザ; 28ビット浮動小数点数
- **緯度:** 7つのサンプル内部遅延、調整可能な3~31サンプル。すべての出力時間と位相に合わせて調整されます。
- **コントロール:** DADmanソフトウェア(macOSおよびWindows); Avid EuCon互換; ギガビットイーサネット
- **電源:** DC 入力 (12 V); 外部PSUが含まれています — ユニットに IEC メインコネクタがありません
- **重量/深さ:** 1.3 kg / 2.9 ポンド; シャーシ深さ23.1 cm / 9.1"
