# チャプター3 — インストール

> **製品:** Digital Audio Denmark Core 256

> **始める前に** このユニットを設置する前に[Front Matter — Safety & Conventions](./fm-safety) を読んでください。

## 3.2 ラックマウント

\*[プレースホルダー — ラック取付手順 ラッキングハードウェア部品番号とトルク仕様を含めます。] \*

Core 256はハーフラックユニットです。 標準の19インチラックにマウントするには、1Uラックシェルフ(別売)またはCore 256 Racking Hardware アクセサリが必要です。

1. 付属のネジを使用してラック耳をユニットに取り付けます。
2. 必要な場所にラック内にユニットを配置します。
3. ケージナットやネジラックストリップにラックネジで固定します。

> **注意:** 4つのラックネジをすべて使ってください。 添付ファイルの4点未満に依存しないでください。

---

## 3.3 電源接続

\*[プレースホルダー — 電源接続手順] \*

外部。 12 V DC バレルコネクタ 外部PSUを供給しました。

1. 適切なIEC C13電源ケーブルをIEC C14インレットに接続します。
2. もう一方の端を接地された電源コンセントに接続します。
3. フロントパネルの電源ボタンを使用してユニットをオンにします。

> **警告:** 正しくアースされたメインアウトレットにのみ接続してください。 接地接続を破らないでください。

---

## 3.4 Thunderbolt ドライバのインストール

DAD Thunderbolt ドライバは、DADman によって検出される前にホストコンピュータにインストールする必要があります。

_[プレースホルダー — ドライバのインストール手順 DADman manual Ch. 3.へのクロスリファレンス_

1. DAD Thunderbolt ドライバパッケージを [digitalaudio.dk](https://digitalaudio.dk/support) からダウンロードします。
2. インストーラを実行し、画面の指示に従います。
3. プロンプトが表示されたらコンピュータを再起動します。
4. ユニットに電源を入れ、Thunderbolt ケーブルを接続します。
5. Open DADman — ユニットはデバイスリストに表示されます。

> **注意:** macOS のThunderboltセキュリティ設定では、初回接続時に新しいThunderboltデバイスの承認が必要になる場合があります。 詳細は DADman Installation の章を参照してください。

---

## 3.5 初期起動

\*[プレースホルダー — 最初の電源手順と検証手順] \*

1. 最初の電源投入前にすべての信号ケーブルが切断されていることを確認します。
2. 電源を入れます。
3. フロントパネルの LED の監視 — [Ch. 2 — Panel Description](./ch02-panel-description) for expected LED states.
4. ユニットをホストコンピュータ(Thunderbolt 3)に接続します。
5. DADman を開き、デバイス リストにユニットが表示されていることを確認します。
