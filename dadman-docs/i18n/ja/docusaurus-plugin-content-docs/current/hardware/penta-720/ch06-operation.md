## 6.1 電源オン/オフ

_[Placeholder — パワーオンおよびシャットダウン手順 via front panel Power button]_

### 通常電源オン

1. すべての信号ケーブルが接続されていることを確認します。
2. フロントパネルの **電源** ボタンを押します。
3. このユニットは起動シーケンスを実行します。完了までに30秒かかります。
4. **Int.** LEDはユニットの準備ができたら点灯します。

### 通常の停止

1. DADmanでは、セッションを閉じてユニットを取り外します。
2. フロントパネルの **電源** ボタンを押します。
3. ボタンはシャットダウンシーケンス中にゆっくりとパルスを発生させます。
4. ボタンが点滅している間は電源を切らないでください。

> **注意:** ファームウェアの更新時にユニットの電源を入れないでください。 format@@0ボタンはアップデート中にゆっくり点滅します。アップデートが完了するまでお待ちください。
