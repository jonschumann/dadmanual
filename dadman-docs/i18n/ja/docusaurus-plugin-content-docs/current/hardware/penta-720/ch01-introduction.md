# 第 1 章 — はじめに

> **製品:** Digital Audio Denmark Penta 720

---

## 1.1 製品概要

Penta 720は、モジュラー2UラックマウントオーディオインターフェースとNTPテクノロジーからのフォーマット変換プラットフォームです。 イーサネット経由でのみコンピュータに接続し、ルーティングと構成のためにDADmanによって管理されます。 これは、高チャネルカウントのAES/EBUおよびMADI I/O、フォーマット変換、およびネットワークオーディオ配布に使用されます。

**ホストへの接続:** イーサネット(サンダーボルトなし)
**フォームファクタ:** 2U rackmount (モジュラーシャーシ)
**オーディオチャンネル:** 最大720チャンネル (カードに依存)

---

## 1.2 主な機能

![Penta 720 — front panel](/img/panel-penta720-clean.png)
_Penta 720 — front panel_

- **フォームファクタ:** 2Uラックマウント、19"; フロントアクセスカードベイ
- **拡張機能:** 8 ホットプラグ拡張カードスロット — 最大 1,024×1,024 チャンネル I/O
- **MADI:** 内蔵同軸MADI I/O — 48 kHz の64 チャンネル
- **AES3:** 内蔵のAES3 I/O — 16 channels via 2 × DB25 (Tascam pinout)
- **ダンテ (オプション):** MOD-DANTE-BK3モジュール経由で — 48kHz の64チャンネル
- **DADlink (任意):** MOD-MADI-DADLNKモジュール+ SFP経由で — 最大256×256チャンネル
- **同期:** ワードクロックI/O(BNC、75Ω)、ビデオブラックバースト入力、AES11入力
- **ルーティング:** 1,424×1,424 行列; 256×32 加算プロセッサ; 28 bit 浮動小数点数
- **緯度:** 7つのサンプル内部遅延、調整可能な3~31サンプル。すべての出力時間と位相に合わせて調整されます。
- **コントロール:** DADmanソフトウェア(macOSおよびWindows); Avid EuCon互換; ギガビットイーサネット
- **パワー:** デュアルPSU; デュアル電源入力
- **冷却：** 2 × 内部ファン
- **重量/深さ:** 5.0 kg / 11.0 ポンド; シャーシ深さ35 cm / 13.8"
