# 第 1 章 — はじめに

> **製品:** Digital Audio Denmark AX64

---

## 1.1 製品概要

AX64は、2UラックマウントThunderbolt 3またはEthernetオーディオインターフェースで、最大8つのDB25アナログ拡張カードスロットを備えています。 これは、ステージボックス、衛星I/Oユニット、または分散システム内のスタンドアロンイーサネットオーディオエンドポイントとして一般的に使用されます。

**ホストへの接続:** Thunderbolt 3 または Ethernet
**フォームファクタ:** 2U ラックマウント
**オーディオチャンネル:** 最大64×64 アナログチャンネル (カードに依存)

---

## 1.2 主な機能

![AX64 — front panel](/img/panel-ax64-front-clean.png)
_AX64 — front panel_

![AX64 — rear panel](/img/panel-ax64-rear-clean.png)
_AX64 — rear panel_

- **フォームファクタ:** 2U rackmount, 19"
- **拡張機能:** 8 ホットプラグ拡張カードスロット — 最大 1,024×1,024 チャンネル I/O
- **Thunderbolt 3:** 2 × USB-C — 256 チャンネル 48/96 kHz; 1 ポートあたり 15 W バス電力
- **Dante AoIP:** 内蔵の — 256 チャンネル 48 kHz, 128 チャンネル 96 kHz
- **MADI:** 内蔵同軸MADI I/O — 48 kHz の64 チャンネル
- **ADAT / S/PDIF:** 内蔵ADAT/SMUX (16 ch) および S/PDIF (2 ch)
- **DADlink:** 2 × SFP ケージ — DADlink (最大 256×256 ch) または MADI 光学系
- **同期:** Word Clock I/O (BNC, 75 Ω), ビデオブラックバースト入力
- **ルーティング:** 1,872×1,872行列; 512×64 加算プロセッサ; 1,024フィルタSPQイコライザ; 28ビット浮動小数点数
- **緯度:** 7つのサンプル内部遅延、調整可能な3~31サンプル。すべての出力時間と位相に合わせて調整されます。
- **コントロール:** DADmanソフトウェア(macOSおよびWindows); Avid EuCon互換; ギガビットイーサネット
- **パワー:** デュアルPSU標準; オプションの冗長電源入力(AX64-BASE-RPS)
- **重量/深さ：** 5.5 kg / 12.2 ポンド; シャーシ深さ34.5 cm / 13.6"
