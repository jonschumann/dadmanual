## 安全に関する説明

### 電気安全

**警告 - 電気ショックハザード** このユニットは主電源で動作します。 カバーを外さないでください。 内部にはユーザー・パーツはありません。 資格のあるサービス担当者にすべてのサービスを参照してください。

- 機器を操作する前にすべての手順をお読みください。
- 今後の参照のためにこのマニュアルを保管してください。
- 機器とマニュアルですべての警告を確認してください。
- 水の近くでこの機器を使用しないでください。
- 換気開口部をブロックしないでください。 メーカーの指示に従ってインストールします。
- ラジエーターやアンプなどの熱源の近くに設置しないでください。
- 電源コードが歩かれたりつまんだりするのを防ぎます。
- メーカーが指定した添付ファイルとアクセサリのみを使用します。
- 雷雨時または長期間使用されていない場合、この装置を取り外します。
- 資格のあるサービス担当者にすべてのサービスを参照してください。 装置が何らかの方法で損傷した場合には、サービスが必要です。

### ESD上の注意

> **CAUTION — 静電放電** ユニットと拡張カードを注意深く取り扱いましょう。 静電気放電は内部部品を損傷する可能性があります。 内部コンポーネントや拡張カードを扱う前に自分自身を地面に敷きます。

### ラックマウント

> **CAUTION — ラック安定性**ユニットを設置する前に、ラックまたはエンクロージャが安定していることを確認してください。 ラックをオーバーロードすると、チップが発生します。 ラックメーカーの指示に従って、安全な実装と負荷分布を確認してください。

### Thunderbolt ケーブル

> **注意:** Thunderbolt 3 対応ケーブルと Thunderbolt 4 対応ケーブルのみを使用してください。 標準の USB-C ケーブルは、Thunderbolt 3 速度に対応しておらず、信頼性の高い動作を提供しません。 付属のケーブルまたは認証済みの交換を使用してください。

## コンベンション

### タイポグラフィー（文法）

| 書式                                  | 使用先                          |
| ----------------------------------- | ---------------------------- |
| **Bold**                            | 制御名、コネクタのラベル、メニュー項目          |
| `Monospace`                         | ファイル名、コマンドライン入力、ソフトウェアパラメータ値 |
| _Italic_                            | ドキュメントタイトル、新しい用語を最初に使用する     |
| format@@0 | 他の章またはセクションへの相互参照            |

### コネクタのラベル

このマニュアルのコネクタラベルは、実際の単位のシルクスクリーニングラベルと一致します。 パネルダイアグラムが提供されているところ、呼び出し番号 (1, 2, 3…) テキストにはダイアグラムの番号付き吹き出しが表示されます。
