# 第8章 — メンテナンスとファームウェア

> **製品:** Digital Audio Denmark AX64

---

## 8.1 ファームウェア更新手順

ファームウェアは、DADman 内から更新されます。 個別のファームウェアツールは必要ありません。

1. ユニットが接続され、DADman デバイス リストに表示されていることを確認します。
2. DADman で**設定 → ファームウェア**を開きます。
3. DADmanは利用可能なファームウェアのアップデートを表示します。 AX64 で使用可能なアップデートがある場合、現在のバージョン番号と使用可能なバージョン番号が表示されます。
4. **更新**をクリックして確認します。
5. アップデート中は、ユニットのフロントパネル電源ボタンがゆっくり点滅します。 **アップデート中はユニットの電源を切ったり切断したりしないでください。**
6. アップデートが完了すると、ユニットは自動的に再起動します。
7. デバイスリストで新しいファームウェアのバージョンを確認します。

> **注意:** 失敗したファームウェアのアップデートは、ユニットを起動できない状態にすることがあります。 ファームウェアの更新を開始する前に、電源と接続が安定していることを確認してください。 ファームウェアの更新後にユニットが再起動しない場合は、DADサポートにお問い合わせください。

## 8.2 クリーニング

\*[プレースホルダー — 洗浄指示: 承認済み資料、回避方法、ESD対策] \*

- 乾燥または軽く湿らせた糸くず布で外装をきれいにしなさい。
- 溶剤、研磨剤、エアロゾルスプレーは使用しないでください。
- ユニットに直接洗浄液をスプレーしないでください。
- 清掃前に電源を切断します。
