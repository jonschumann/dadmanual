## 概要

CARD-8AESは、互換性のあるDADシャーシ用に8チャンネルのAES3デジタルI/Oを提供します。 AES3 (AES/EBU)接続のバランスをとったデジタル機器とのインタフェースを目的としています。コンソール、デジタルテープマシン、アウトボードコンバータ、および放送機器です。

## インストール

> **警告:** 拡張カードをインストールまたは削除する前に、常にシャーシの電源を切り、メインケーブルを取り外します。

1. シャーシをパワーダウンし、メインケーブルを取り外します。
2. ターゲットスロットからブランキングパネルを取り外します(ネジを留めます)。
3. エッジコネクタが完全に座るまでスロットガイドにCARD-8AESをスライドさせます。
4. 固定ネジでフロントブラケットを固定します。
5. 主電源ケーブルと電源をシャーシに再接続します。
6. Open DADman — カードは、I/OルーティングビューにAES3 I/Oインターフェイスとして表示されます。
