# CARD-L8 — 8チャンネルプリスティンADライン入力カード

> **SKU:** CARD-L8  
> **ソース:** Spec Sheet CARD-L8, Issue 2026

---

## 概要

CARD-L8は、互換性のあるDADシャーシに対応する8チャネルの高性能アナログ-デジタル変換をラインレベルで提供します。 すべての入力はバランスがとれており、標準のTascam ピンアウトを使用して単一のDB25コネクタ上で提供されます。

変換は、32ビットの処理深度でFPGAベースのフィルタリングを備えたデュアル5ビットデルタシグマ変調器を使用します。 入力ゲインステージングは、アクティブ電子部品なしでリレーベースであり、全利得範囲にわたってクラス最高のノイズと直線性を提供します。

このカードは、44.1kHz~DXD(352.8/384 kHz)、およびDSD 64およびDSD 128のすべてのPCMサンプルレートをサポートしています。

## インストール

> **警告:** 拡張カードをインストールまたは削除する前に、常にシャーシの電源を切り、メインケーブルを取り外します。

1. シャーシをパワーダウンし、メインケーブルを取り外します。
2. ターゲットスロットからブランキングパネルを取り外します(ネジを留めます)。
3. エッジコネクタが完全に座るまで、カードガイド、ラベル側にカーソルを移動します。
4. 固定ネジでフロントブラケットを固定します。
5. 主電源ケーブルと電源をシャーシに再接続します。
6. Open DADman — カードは I/O ルーティング ビューでライン入力として自動的に表示されます。
