# 拡張カード

互換性のあるシャーシ上のカードベイにDAD拡張カードスロットを挿入し、I/O機能を拡張します。 各カードは1スロットを占め、ホットプラグ対応です。 同じまたは異なるタイプの複数のカードを同時に取り付けることができます, ホストシャーシの総電力予算に応じて.

## 互換性のあるシャーシ

| Chassis    | 利用可能なスロット |
| ---------- | --------- |
| AX64       | 8         |
| Penta 720  | 8         |
| AXセンター     | 2         |
| Penta 721S | 1         |
| AX32       | 8         |

> Core 256には拡張スロットがありません。 MOMには拡張スロットがありません。

## スロットパワー予算

各シャーシは、拡張カードスロットに最大電力予算を備えています。 設置されたカードの消費電力がシャーシ制限を超えないことを確認します。

| Chassis    | カードスロット電源予算            |
| ---------- | ---------------------- |
| AX64       | 合計70Wの8スロット            |
| Penta 720  | Penta 720 仕様を参照してください。 |
| AXセンター     | AX Centerの仕様を参照してください  |
| Penta 721S | ペンタ721Sの仕様を参照のこと。      |
| AX32       | AX32仕様を参照。             |

> **注意:** スロット電源の予算を超えると動作が不安定になったり、サーマルシャットダウンする可能性があります。 同じシャーシに複数の高出力カード (CARD-DA8, CARD-M8) をインストールする前に、総カード出力を計算します。

## インストールの概要

すべての拡張カードは、同じインストール手順を共有します。 詳細な手順については、各カードのページの「インストール」セクションを参照してください。

1. シャーシを完全にパワーダウンし、メインケーブルを取り外します。
2. ターゲットスロットからブランキングパネルを取り外します(ネジを留めます)。
3. エッジコネクタが完全に座るまでスロットガイドにカードをスライドさせます。
4. 保持ネジでカードのフロントブラケットを固定します。
5. 主電源ケーブルと電源をシャーシに再接続します。
6. Open DADman — カードは I/O 設定で自動的に表示されます。
