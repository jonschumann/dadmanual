# CARD-DA8 — 8チャンネルプリスティンDA出力カード

> **SKU:** CARD-DA8  
> **ソース:** Spec Sheet CARD-DA8, Issue 2026

---

## 概要

CARD-DA8は、互換性のあるDADシャーシに高性能なデジタル/アナログ変換を8チャネル提供します。 すべての出力はバランシングされ、標準のTascam ピンアウトを使用して単一のDB25コネクタに配信されます。

32ビットの処理深度でのFPGAベースのフィルタリングを備えた32ビットのオーバーサンプリング32ビットバーブラウンDACを使用します。 出力ゲインステージングは、アクティブな電子利得コンポーネントがないリレーベースであり、最大のダイナミックレンジと下流のアナログシステムとの正確なレベルマッチングを保証します。

このカードは、44.1kHz~DXD(352.8/384 kHz)、およびDSD 64およびDSD 128のすべてのPCMサンプルレートをサポートしています。

## インストール

> **警告:** 拡張カードをインストールまたは削除する前に、常にシャーシの電源を切り、メインケーブルを取り外します。 強力なシャーシにカードを挿入すると、カードとシャーシが損傷する可能性があります。

1. シャーシをパワーダウンし、メインケーブルを取り外します。
2. ターゲットスロットからブランキングパネルを取り外します(ネジを留めます)。
3. エッジコネクタが完全に座るまで、CARD-DA8をスロットガイド、ラベル側にスライドさせます。
4. 固定ネジでフロントブラケットを固定します。 フィンガータイトで十分です。
5. 主電源ケーブルと電源をシャーシに再接続します。
6. Open DADman — カードは I/O ルーティング ビューで DA 出力として自動的に表示されます。
