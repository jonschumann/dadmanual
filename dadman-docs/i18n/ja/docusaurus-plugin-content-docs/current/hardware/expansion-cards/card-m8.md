# CARD-M8 — 8チャンネルプリスティンADマイク/ライン入力カード

> **SKU:** CARD-M8  
> **ソース:** Spec Sheet CARD-M8, Issue 2026

---

## 概要

CARD-M8は、互換性のあるDADシャーシ用にスイッチ可能なマイクとラインレベル入力を備えた高性能アナログ-デジタル変換の8チャネルを提供します。 各チャンネルは、マイクモードまたはラインモードに個別に設定できます。 すべての入力はバランスがとれており、標準のTascam ピンアウトを使用して単一のDB25コネクタ上で提供されます。

変換は、32ビットの処理深度でFPGAベースのフィルタリングを備えたデュアル5ビットデルタシグマ変調器を使用します。 マイクとラインゲインステージングは、アクティブな電子ゲインコンポーネントがないリレーベースです。 最大利得で優れたノイズ性能と-131 dBu(A重み)のEINを提供します。

48Vファントム電源はチャネルごとにコンデンサーマイク用に利用可能です。

## インストール

> **警告:** 拡張カードをインストールまたは削除する前に、常にシャーシの電源を切り、メインケーブルを取り外します。

> **注意:** いずれかのチャンネルで 48 V ファントム電源が有効になっている場合。 マイクカプセルに損傷を与える可能性のあるトランジェントを避けるために、マイクやケーブルを接続または切断する前にDADmanで無効にしてください。

1. シャーシをパワーダウンし、メインケーブルを取り外します。
2. ターゲットスロットからブランキングパネルを取り外します(ネジを留めます)。
3. エッジコネクタが完全に座るまで、CARD-M8をスロットガイド、ラベル側にスライドさせます。
4. 固定ネジでフロントブラケットを固定します。
5. 主電源ケーブルと電源をシャーシに再接続します。
6. Open DADman — カードは I/O ルーティング ビューにマイク/ライン入力として表示されます。 必要に応じて、各チャンネルをマイクまたはラインモードに設定します。
