# CARD-DANTE — 128チャネルダンテ / AES67 インターフェイス カード

> **SKU:** CARD-DANTE  
> **ソース:** Spec Sheet CARD-DANTE, Issue 2026

---

## 概要

CARD-DANTEは、互換性のあるDADシャーシに128チャネルの双方向ダンテとAES67オーディオをIP接続経由で提供します。 2つのRJ45ネットワークポートは、スイッチングネットワーク(デイジーチェーン)または独立したプライマリおよびセカンダリ接続を備えた冗長ダンテネットワークとして構成することができます。

このカードは、Dante Domain Managerを含むAudinateが開発したDanteエコシステムと完全に互換性があります。 入力パスと出力パスでは、SRC(Sample Rate Conversion)を個別に有効にできます。 カードをホストシャーシのサンプリングレートから非同期に動作させることができます

## ネットワーク設定

CARD-DANTEの2つのRJ45ポートは、以下の2つのモードで設定できます。

**Switched mode** — 2つのポートは、2ポートのスイッチとして機能し、外部スイッチなしでデイジーチェーンネットワークトポロジを可能にします。 両方のポートは、同じダンテネットワークに接続します。

**冗長モード** — 各ポートは独立したダンテネットワーク(プライマリとセカンダリ)に接続します。 主要なパスが失敗した場合、Danteは自動的にセカンダリネットワークに失敗します。 冗長モードでは、各ネットワーク上のスイッチが必要です。

Dante ControllerまたはDADmanを使用してネットワークモードを設定します。

## インストール

> **警告:** 拡張カードをインストールまたは削除する前に、常にシャーシの電源を切り、メインケーブルを取り外します。

1. シャーシをパワーダウンし、メインケーブルを取り外します。
2. ターゲットスロットからブランキングパネルを取り外します(ネジを留めます)。
3. エッジコネクタが完全に座るまでスロットガイドにCARD-DANTEをスライドさせます。
4. 固定ネジでフロントブラケットを固定します。
5. 必要に応じてイーサネットケーブルをRJ45ポートに接続します。
6. 主電源ケーブルと電源をシャーシに再接続します。
7. DADman と Dante コントローラーを開きます。カードはネットワーク上で Dante デバイスとして表示されます。
