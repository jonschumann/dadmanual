# CARD-RAVENNA — 128-Channel Ravenna / AES67 / ST 2110-30 インターフェイス カード

> **SKU:** CARD-RAVENNA  
> **ソース:** Spec Sheet CARD-RAVENNA, Issue 2026

---

## 概要

CARD-RAVENNAは、互換性のあるDADシャーシに128チャネルの双方向Ravenna、AES67、およびSMPTE ST 2110-30オーディオ接続を提供します。 2つのRJ45ネットワークポートは、デュアルネットワークの設置におけるhitless冗長性のために、ST2022-7シームレス保護スイッチング(SPS)を使用してスイッチングネットワークとして構成することができます。

このカードはRavenna、AES67と完全に相互運用可能です ST2110-30エコシステムと、WebUI、NMOS IS-04/IS-05、SAP、ANEMAN、およびJSONAPIを介した業界標準の検出および制御をサポートします。 PTPv2 (IEEE 1588-2008) はマスターモードとスレーブモードの両方でサポートされています。

入力パスと出力パスでは、SRC(Sample Rate変換)を同時に有効にすることができ、ホストシャーシのサンプリングレートから非同期に動作させることができます。

## ネットワーク設定

**スイッチモード** — 両方のポートは内蔵スイッチとして動作し、外部スイッチなしでデイジーチェーントポロジを有効にします。

**ST 2022-7 SPS モード** — 各ポートは独立したネットワークに接続します。 ST 2022-7 シームレスな保護スイッチングは、一方のネットワークパスに障害が発生した場合、オーディオはもう一方を介して中断することなく継続します。 このモードには、各ネットワーク上の専用スイッチが必要です。

カードのWebUIまたはNMOSコントローラを介してネットワークモードとPTPロール(マスター/スレーブ)を設定します。

## 発見とコントロール

CARD-RAVENNAは、複数の検出および制御インターフェイスをサポートします。

| インターフェイス   | 目的                               |
| ---------- | -------------------------------- |
| WebUI      | ブラウザベースの構成と状態                    |
| NMOS IS-04 | デバイスとリソースの検出                     |
| NMOS IS-05 | 接続管理 (ルーティング) |
| Ravenna    | ネイティブRavennaの発見と制御               |
| SAP        | セッションアナウンス（AES67 / SDP）          |
| ANEMAN     | ANEMANネットワークマネージャの統合             |
| JSON API   | プログラム構成                          |

## インストール

> **警告:** 拡張カードをインストールまたは削除する前に、常にシャーシの電源を切り、メインケーブルを取り外します。

1. シャーシをパワーダウンし、メインケーブルを取り外します。
2. ターゲットスロットからブランキングパネルを取り外します(ネジを留めます)。
3. エッジコネクタが完全に座るまでスロットガイドにCARD-RAVENNAをスライドさせます。
4. 固定ネジでフロントブラケットを固定します。
5. ネットワークトポロジに必要に応じてイーサネットケーブルをRJ45ポートに接続します。
6. 主電源ケーブルと電源をシャーシに再接続します。
7. Open DADman — カードは I/O ルーティング ビューで AoIP インターフェイスとして表示されます。
8. 高度なネットワークとPTP設定のためにカードのWebUIにアクセスします。
