# CARD-2MADI-SO — SRC付きデュアルMADIインターフェースカード

> **SKU:** CARD-2MADI-SO  
> **Source:** Spec Sheet CARD-MADI-SO, Issue June 2026

---

## 概要

CARD-2MADI-SOは、互換性のあるDADシャーシ用に、SFPモジュールを介して2つの独立した双方向MADI接続を提供します。 各MADIポートは、48kHzで64チャンネルと64チャンネルを提供し、カードごとに各方向に合計128チャンネルを提供します。

SFPモジュールは個別に販売されており、光学(LC、シングルモードまたはマルチモード)または電気(HD-BNC同軸)することができます。 この柔軟性により、カードは既存のMADIインフラストラクチャに事実上接続することができます。 各ポートの入力と出力に対して、SRC(Sample Rate Conversion)を個別に有効にできます。

## SFP モジュール

SFP モジュールは **含まれていません** 、別途注文する必要があります。 DADから2つのタイプがあります:

| SKU                  | 説明                                                              |
| -------------------- | --------------------------------------------------------------- |
| MOD-SFP-COAX         | MADI - HD-BNC コネクタ                                              |
| MOD-SFP-1300-LD      | MADI用SFP光トランシーバ-1310 nm、100BASE マルチモードLC                        |
| CON-2BNC-HD/STD-0,5M | HD-BNCからBNCアダプタケーブルセット(0.5m) |

> **注意:** MOD-SFP-COAXはHD-BNCコネクタを使用します。 CON-2BNC-HD/STD-0,5Mアダプタケーブルを使用して、標準の75ΩのBNC MADI装置に接続します。

## インストール

> **警告:** 拡張カードをインストールまたは削除する前に、常にシャーシの電源を切り、メインケーブルを取り外します。

> **注意:** SFPモジュールはカードの電源が入っている状態で挿入および削除できます。 しかし、SFPケージに損傷を与えないように、常にモジュールをストレートで圧力で挿入します。 容易に座らないモジュールを強制しないでください。

1. シャーシをパワーダウンし、メインケーブルを取り外します。
2. ターゲットスロットからブランキングパネルを取り外します(ネジを留めます)。
3. エッジコネクタが完全に座るまでスロットガイドにCARD-2MADI-SOをスライドさせます。
4. 固定ネジでフロントブラケットを固定します。
5. 主電源ケーブルと電源をシャーシに再接続します。
6. SFPケージに適切なSFPモジュールを挿入し、MADIケーブルを接続します。
7. Open DADman — 両方のMADIポートがI/Oルーティングビューに表示されます。
