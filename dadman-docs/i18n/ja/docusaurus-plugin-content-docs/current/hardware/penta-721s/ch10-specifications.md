# 第 10 章 — 技術仕様

> **製品:** Digital Audio Denmark Penta 721S  
> **SKU:** PENTA721S-BASE  
> **ソース:** Spec Sheet PENTA721S-BASE, Issue 2026

---

## 10.1 デジタルI/O

| パラメータ    | 値                    | 条件 / メモ                                        |
| -------- | -------------------- | ---------------------------------------------- |
| MADI     | 64 ch in / 64 ch out | 48 kHz; 同軸BNCとSFP経由光学で                         |
| AES3（内蔵） | 16 ch in / 16 ch out | 2 × DB25 (Tascam pinout)    |
| ダンテAoIP  | 64 ch in / 64 ch out | 48 kHz                                         |
| 拡張カード経由で | 1 スロット               | 互換性のあるカードについては 10.5 節 をご覧ください。 |

---

## 10.2 サポートされているサンプル レート

| 書式            | サンプルレート                                                                                                        |
| ------------- | -------------------------------------------------------------------------------------------------------------- |
| MADI          | 44.1, 48, 88.2, 96, 176.4, 192, 352.8, 384 kHz |
| AES3          | 44.1, 48, 88.2, 96, 176.4, 192 kHz                             |
| Dante / AES67 | 44.1, 48, 88.2, 96 kHz                                                         |

## 10.3 ルーティングと処理

| パラメータ       | 値                  |
| ----------- | ------------------ |
| ルーティングマトリクス | 528×528            |
| 処理中の単語長     | 28ビット浮動小数点数        |
| 出力の配置       | すべての出力時間と位相を揃えています |

---

## 10.4 Synchronisation

| ソース              | メモ             |
| ---------------- | -------------- |
| 単語時計             | BNC 入力と出力      |
| ビデオブラックバースト（VBB） | Input          |
| MADI             | MADIポート経由で     |
| AES3             | Via AES3 input |
| ダンテ              | ネットワーク経由で      |
