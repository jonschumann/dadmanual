# 第 1 章 — はじめに

> **製品:** Digital Audio Denmark Penta 721s

---

## 1.1 製品概要

ペンタ721は、同じモジュラーアーキテクチャとイーサネット専用の接続性を共有する、Penta 720の1Uスリムなバリアントです。 これにより、統合されたサンプルレートコンバータが追加され、DADman セッション内で異なるサンプルレートで実行されるオーディオストリームをブリッジすることができます。

**ホストへの接続:** イーサネット(Thunderboltなし)
**フォームファクタ:** 1U rackmount (スリムなモジュラーシャーシ)
**オーディオチャンネル:** SRC(カードに依存)搭載最大720チャンネル

---

## 1.2 主な機能

![Penta 721S — front panel](/img/panel-penta721s-front-clean.png)
_Penta 721S — front panel_

![Penta 721S — rear panel](/img/panel-penta721s-rear-clean.png)
_Penta 721S — rear panel_

- **フォームファクタ:** 2U rackmount, 19"
- **拡張機能:** ホットプラグ拡張カードスロット
- **MADI:** 内蔵同軸MADI I/O — 48 kHz の64 チャンネル
- **AES3:** 内蔵のAES3 I/O — 16 channels via 2 × DB25 (Tascam pinout)
- **Dante AoIP:** 内蔵の - 48 kHz の 64 チャンネル
- **DADlink:** 2 × SFP ケージ — DADlink (最大 256×256 ch) または MADI 光学系
- **同期**ワードクロックI/O(BNC、75Ω)、ビデオブラックバースト入力、AES11入力、ダンテ同期
- **ルーティング：** 528×528 行列; 256×32 加算プロセッサ; 28 bit 浮動小数点数
- **緯度:** 7つのサンプル内部遅延、調整可能な3~31サンプル。すべての出力時間と位相に合わせて調整されます。
- **コントロール:** DADmanソフトウェア(macOSおよびWindows); Avid EuCon互換; ギガビットイーサネット
- **パワー:** デュアルPSU; デュアル電源入力
- **冷却:** 1 × 低ノイズの内部ファン
- **Weight / depth:** 3.3 kg / 7.3 lbs; shassis depth 32 cm / 12.6"
