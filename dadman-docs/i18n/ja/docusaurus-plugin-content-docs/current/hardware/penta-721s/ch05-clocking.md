# チャプター5 — 時計と同期

> **製品:** Digital Audio Denmark Penta 721s

---

## 5.1 概要

ペンタ721sは、複数のクロックリファレンスソースをサポートしています。 アクティブなクロックソースは、DADman で選択されます。 DADman セッション内の 1 つのデバイスのみがクロックマスターである必要があります。他のすべてのデバイスはそのデバイスにスレーブする必要があります。

## 5.6 統合サンプルレートコンバータ (SRC)

\*[プレースホルダー — Penta 721sのみ。 SRC機能の説明、サポートされているレート変換、およびDADmanの設定。

ペンタ721には、異なるサンプルレートで実行されるオーディオストリームをブリッジすることができる統合SRCが含まれています。 これにより、例えば48kHzのオーディオネットワークと96kHzのセッションの境界デバイスとして機能することができます。

---

## 5.7 DADman におけるクロック設定

\*[プレイスホルダー — DADman でクロックソースを選択しロックを検証する方法。 相互参照DADman manual Ch. 5.] \*

1. DADman で、Penta 721 のデバイス設定を開きます。
2. **時計** セクションに移動します。
3. ドロップダウンから任意のクロックソースを選択します。
4. フロントパネルの **Ext.** LED が外部参照用または **Int.** LED (内部用)を点灯していることを確認します。
