# 第 7 章 — DADman ソフトウェア統合

> **製品:** Digital Audio Denmark Penta 721s

> 完全な DADman 操作については、 [docs.evangelaudio.com](https://docs.evangelaudio.com) の **DADman ユーザマニュアル** を参照してください。

---

## 7.1 ペンタ721sがDADmanにどのように現れるか

\*[プレースホルダー — Penta 721 が接続されたときの DADman デバイスリストでユーザーが見たものを記述します。 スクリーンショットのプレースホルダを含めます。

Penta 721sが接続され電源がオンになると、DADmanの**Device List**パネルに表示されます。 DADman は、デバイスの種類とシリアル番号によってそれを識別します。 ユーザーはセッション間で持続するラベルを割り当てます。

Penta 721sのデバイスリストのエントリには以下が表示されています。

| フィールド         | コンテンツ            |
| ------------- | ---------------- |
| 端末の種類         | Penta 721s       |
| シリアル番号        | 一意の単位識別子         |
| 接続状態          | オンライン / オフライン    |
| ファームウェアのバージョン | 現在のファームウェアのリビジョン |
| 時計の状態         | 状態と選択した参照をロックする  |
| I/Oチャンネルマップ   | 割り当てられたチャンネル範囲   |
