# チャプター3 — インストール

> **製品:** Digital Audio Denmark AX32  
> **SKU:** AX32-BASE2

---

## 3.1 始める前

> **警告 - 電気ショックハザード** すべての接続が完了し、ユニットがラックまたはエンクロージャに正しくインストールされるまで電源を供給しないでください。

> **注意** - 静電放電\*\*拡張カードを設置または取り外す前に、ユニットをパワーダウンさせ、自分自身でグランドします。

---

## 3.2 ラックマウント

\*[プレースホルダー — 2U ラック実装手順を記述してください。 機械設計に対するラックの深さと耳の要件を確認します。

AX32は標準の19インチラックで2U(88.9 mm)を占めています。 ユニットの上と下の換気クリアランスの少なくとも1Uを許可してください。

---

## 3.3 拡張カードのインストール

> **警告:** 拡張カードをインストールまたは削除する前に、常にシャーシの電源を切り、メインケーブルを取り外します。

1. ユニットをパワーダウンし、IECメインケーブルを取り外します。
2. ターゲットスロットからブランキングパネルを取り外します(ネジを留めます)。
3. エッジコネクタが完全に座るまでスロットガイドにカードをスライドさせます。
4. 固定ネジでフロントブラケットを固定します。
5. メインケーブルを再接続します。
6. 電源をオンにし、カードがDADmanに表示されていることを確認します。

カード固有のインストールノートについては、「拡張カード」(../../expansion-cards/)を参照してください。
