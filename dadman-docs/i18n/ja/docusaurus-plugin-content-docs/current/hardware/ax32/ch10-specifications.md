# 第 10 章 — 技術仕様

> **製品:** Digital Audio Denmark AX32  
> **SKU:** AX32-BASE2  
> **ソース:** Spec Sheet AX32-BASE, Issue 2026

---

## 10.1 デジタルI/O

| パラメータ                                                 | 値                    | 条件 / メモ                                     |
| ----------------------------------------------------- | -------------------- | ------------------------------------------- |
| MADI                                                  | 64 ch in / 64 ch out | 48 kHz; 同軸BNC                               |
| AES3（内蔵）                                              | 16 ch in / 16 ch out | 2 × DB25 (Tascam pinout) |
| DADlink (オプションの MOD-MADI-DADLNK経由) | 最大 256×256 ch        | 48kHz; SFP経由で                               |
| 拡張カード経由で                                              | 最大1,024×1,024ch      | オプションのカード                                   |

---

## 10.2 サポートされているサンプル レート

| 書式                                              | サンプルレート                                                                                                        |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| MADI                                            | 44.1, 48, 88.2, 96, 176.4, 192, 352.8, 384 kHz |
| AES3                                            | 44.1, 48, 88.2, 96, 176.4, 192, 352.8, 384 kHz |
| DADlink                                         | 44.1, 48, 88.2, 96, 176.4, 192, 352.8, 384 kHz |
| ダンテ (オプションの MOD-DANTE-BK3経由) | 44.1, 48, 88.2, 96, 176.4, 192 kHz                             |
| 拡張カード                                           | カードの種類に依存する                                                                                                    |

---

## 10.3 ルーティングと処理

| パラメータ             | 値                                                         |
| ----------------- | --------------------------------------------------------- |
| ルーティングマトリクス       | 1,424×1,424                                               |
| Summing processor | 256×32チャンネル                                               |
| 処理中の単語長           | 28ビット浮動小数点数                                               |
| 内部システムの遅延         | 7つのサンプル (3~31サンプル調整可能) |
| 出力の配置             | すべての出力時間と位相を揃えています                                        |

---

## 10.4 DADlink

| パラメータ  | 値                                |
| ------ | -------------------------------- |
| 書式     | 28ビット浮動小数点数                      |
| レイテンシー | 0 サンプル                           |
| 必須     | オプションのMOD-MADI-DADLNKモジュール + SFP |

---

## 10.5 Synchronisation

| ソース                                 | メモ                         |
| ----------------------------------- | -------------------------- |
| 単語時計                                | BNC 入力と出力                  |
| ビデオブラックバースト（VBB）                    | Input                      |
| AES11                               | Input                      |
| MADI                                | MADIポート経由で                 |
| AES3                                | 組み込みの AES3 入力によるもの         |
| format@@0 | オプションのカードを介して。             |
| ダンテ                                 | MOD-DANTE-BK3モジュールによるオプション |
| DADlink                             | MOD-MADI-DADLNKモジュールを使用する  |

---

## 10.6 ネットワークインターフェース

| パラメータ | 値                                         |
| ----- | ----------------------------------------- |
| 標準    | 1000BASE-T                                |
| コネクタ  | RJ45, 4-pair                              |
| 目的    | DADman コントロール; 拡張カードを介したオプションのネットワークオーディオ |

## 10.7 拡張スロット
