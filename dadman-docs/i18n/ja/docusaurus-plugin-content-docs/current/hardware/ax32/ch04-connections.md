# チャプター4 — シグナル接続

> **製品:** Digital Audio Denmark AX32  
> **SKU:** AX32-BASE2

---

## 4.1 Thunderbolt 3 ホスト接続

Thunderbolt 3定格のケーブルを使用して、AX32をホストコンピュータに接続します。 このユニットは、Thunderbolt オーディオデバイスとして DADman に表示されます。

> **注意:** Thunderbolt 3 対応ケーブルのみを使用してください。 標準のUSB-Cケーブルは信頼性の高い動作を提供しません。

---

## 4.2 アナログ接続 (拡張カード経由)

アナログI/Oは拡張カード(CARD-L8, CARD-M8, CARD-DA8)によって提供されます。 各カードには、Tascam ピンアウト規格を使用した 8 チャンネル DB25 コネクタが用意されています。

コネクタのピン配置の詳細については、以下を参照してください:

- [CARD-L8 — DB25 Input Pinout](../../expansion-cards/card-l8#db25-input-pinout-tascam)
- [CARD-M8 — DB25 Input Pinout](../../expansion-cards/card-m8#db25-input-pinout-tascam)
- [CARD-DA8 — DB25 Output Pinout](../../expansion-cards/card-da8#db25-output-pinout-tascam)
