# 第 1 章 — はじめに

> **製品:** Digital Audio Denmark AX32  
> **SKU:** AX32-BASE2

---

## 1.1 製品概要

AX32は、2UラックマウントモジュラーI/Oおよびフォーマット変換プラットフォームです。 8つのホットプラグ拡張カードスロットを介して最大32チャンネルのアナログI/O(16インチ/16アウト)を提供します。 内蔵の同軸MADI I/OとAES3 I/Oと一緒に。 AX32 には、Thunderbolt ホストインターフェイスは含まれていません。ネットワークに接続し、ギガビット イーサネット経由で DADman によって管理されています。 AX32-BASE2は現在の出荷バリアントです。

**Connection to host:** Gigabit Ethernet (DADman control and network audio)
**Form factor:** 2U full-rack, 19"
**Audio channels:** Up to 32 analogue channels (via expansion cards); 64 ch MADI; 16 ch AES3 built-in; additional channels via optional network audio expansion cards

---

## 1.2 主な機能

![AX32 — front panel](/img/panel-ax32-front-clean.png)
_AX32 — front panel_

- **フォームファクタ:** 2U rackmount, 19"
- **拡張機能:** 8 ホットプラグ拡張カードスロット — 最大 1,024×1,024 チャンネル I/O
- **MADI:** 内蔵同軸MADI I/O — 48 kHz の64 チャンネル
- **AES3:** 内蔵のAES3 I/O — 16 channels via 2 × DB25 (Tascam pinout)
- **ダンテ (オプション):** MOD-DANTE-BK3モジュール経由で
- **DADlink (任意):** MOD-MADI-DADLNKモジュール+ SFP経由で — 最大256×256チャンネル
- **同期:** ワードクロックI/O(BNC、75Ω)、ビデオブラックバースト入力、AES11入力
- **ルーティング:** 1,424×1,424 行列; 256×32 加算プロセッサ; 28 bit 浮動小数点数
- **緯度:** 7つのサンプル内部遅延、調整可能な3~31サンプル。すべての出力時間と位相に合わせて調整されます。
- **コントロール:** DADmanソフトウェア(macOSおよびWindows); Avid EuCon互換; ギガビットイーサネット
- **パワー:** シングルメイン入力; デュアルPSU標準; オプションの冗長入力(AX32-RPS)
- **冷却：** 2 × 超低ノイズの内部ファン
- **重量/深さ:** 5.0 kg / 11.0 ポンド; シャーシ深さ35 cm / 13.8"
