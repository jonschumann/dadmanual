# チャプター9 — トラブルシューティング

> **製品:** Digital Audio Denmark AX32  
> **SKU:** AX32-BASE2

---

## 9.1 一般的なトラブルシューティング

\*[プレースホルダー — 症状 → 可能性のある原因 → 救済表 ドキュメンテーション標準で必要な3列形式に従ってください。

| 症状                                    | 推定可能な原因                                     | Remedy                           |
| ------------------------------------- | ------------------------------------------- | -------------------------------- |
| DADman でユニットが検出されませんでした               | イーサネットが接続されていません。サブネットが間違っています              | イーサネット接続とIP設定を確認                 |
| アナログ出力にオーディオがありません                    | 拡張カードがインストールされていません。DADman でのルーティングが間違っています | カードのインストールとDADmanルーティングを確認       |
| 同期エラー                                 | 同期ソースが正しくありません                              | DADman で同期ソースを確認し、ワードクロック接続を確認する |
| DADman には拡張カードが表示されません                | カードが完全に着席していません                             | パワーダウン、カードの座標を変更する               |
| _format@@0_ | —                                           | —                                |

## 9.4 サポートに連絡

上記の手順で問題が解決しない場合は、ローカルの Digital Audio Denmark ディストリビューターまたはDAD サポートにお問い合わせください。 プロビデオ:

- 単位シリアル番号（背面パネルラベル）
- ファームウェアのバージョン（DADmanで表示）
- DADman バージョン
- 症状と手順の説明はすでに行われています
