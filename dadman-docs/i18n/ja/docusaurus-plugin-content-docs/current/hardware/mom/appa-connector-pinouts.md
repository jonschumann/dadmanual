# 付録 A — コネクタのピンアウト

> **製品:** Digital Audio Denmark MOM

> \*[プレースホルダー — エンジニアリングの検証済みピンデータにすべての TBC 値を置き換えます。 ] \*

---

## A.1 BNC (MADI、ワードクロック)

BNCコネクタは、75Ωの同軸ケーブルのバランスがとれていません。 信号は中央のピンに運ばれ、外側のシェルにシールドされます。 コネクタ規格を超えて追加のピンアウトテーブルは必要ありません。

---

## A.2 DB25 — AES/EBU I/O (Tascam Pinout)

\*[プレースホルダー — DAD 拡張カードと Penta AES コネクタで使用されるタスカム/ELCO 規格の 25 ピンD-sub ピンアウト。] \*

| ピン留めする | シグナル   | 方向         | メモ            |
| ------ | ------ | ---------- | ------------- |
| 1      | Ch 1 + | _TBCの入/出力_ |               |
| 14     | Ch 1 − | _TBCの入/出力_ |               |
| 2      | Ch 2 + | _TBCの入/出力_ |               |
| 15     | Ch 2 − | _TBCの入/出力_ |               |
| _…_    | _…_    | _…_        | _…_           |
| 12     | Ground | —          | シャーシ/ケーブルシールド |
| 25     | Ground | —          | シャーシ/ケーブルシールド |

---

## A.3 XLR — AES11 リファレンス入力

| ピン留めする | シグナル                        |
| ------ | --------------------------- |
| 1      | グラウンド/シールド                  |
| 2      | ホット (+)  |
| 3      | Cold (-) |

---

## A.4 TOSLINK (ADAT / Optical MADI)

TOSLINK コネクタは光デジタルオーディオを搭載します。 ピン割り当てがありません: パネルで送信(Tx) / 受信(Rx)の向きを確認します。

---

## A.5 RJ45 (Ethernet)

標準 1000BASE-T イーサネット。 TIA-568Bあたりの有線。

| ピン留めする | シグナル |
| ------ | ---- |
| 1      | Tx + |
| 2      | Tx − |
| 3      | Rx + |
| 4      | —    |
| 5      | —    |
| 6      | Rx − |
| 7      | —    |
| 8      | —    |
