# チャプター4 — コネクション

> **製品:** Digital Audio Denmark MOM

MOMは制御面です。 これは、オーディオ回路が含まれておらず、オーディオ接続を行いません。 唯一の物理的な接続は、ホストAXセンターまたはAX64へのUSB-Cケーブルです。

---

## 4.1 USB-C ホストユニットへの接続

MOMはホストAXセンターまたはAX64の背面にあるUSB-Cポートに接続します。 コンピュータに直接接続しません。

\*[プレースホルダー — MOM → AX センター USB-C パスを示す接続ダイアグラム。] \*

1. AXセンターまたはAX64の背面にあるUSB-Cポートを探します。
2. MOMの後部USB-CポートからそのポートにUSB-Cケーブルを接続します。
3. ホストユニットに電源を入れます。
4. MOMの統計。 LEDは、DADmanが動いていてユニットが認識されているときに緑色に点灯する必要があります。

> **注意:** MOMはDADmanが実行される必要があります。 スタンドアロンでは機能しません。
