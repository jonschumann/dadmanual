# 第 1 章 — はじめに

> **製品:** Digital Audio Denmark MOM

---

## 1.1 製品概要

MOM(Monitor Operating Module)は、Ethernet経由ですべてのDADユニットに接続し、PoE(Power over Ethernet)を使用して同じ接続で給電される物理的なモニタコントローラです。 スピーカー選択、ソース選択、マスターレベル、dim、カット、Talkback、リファレンスレベルの直接アクセスコントロールを提供します。 MOMはオーディオ回路を内蔵しておらず、すべての信号処理はホストDADユニットで行われます。

**ホストへの接続:** Gigabit Ethernet; PoE-powered (IEEE 802. af, Class 0)
**Form factor:** Desktop (rackmountable with optional bracket)
**Audio channels:** 表面のみを制御する — ユニット内のオーディオ回路はありません

---

## 1.2 主な機能

![MOM — overview](/img/panel-mom-clean.png)
_MOM — overview_

- **フォームファクタ:** デスクトップ; ラックマウント可能 (オプション)
- **音量コントロール:** 27-LEDリングを備えた大型ロータリーエンコーダ-0.5dBの解像度
- **キー:** 10 direct-access keys × 4 layers = 40 assignable function
- **モニターコントロール:** 3つのスピーカーセット; 3つのソース; talkback; dim; cut; reference level
- **接続:** ギガビット イーサネット (RJ45) — powered via PoE (IEEEE 802.3af, Class 0) ;個別の PSUは必要ありません
- **フットスイッチ入力:** 3.5 mm TRS ジャック
- **消費電力:** 最大5 W
- **オーディオ回路がありません** — すべての信号処理は接続されたDADユニットによって処理されます。
- **DADman integration:** DADman ソフトウェアを介して設定および運用されています
- **重量/寸法:** 1.0 kg / 2.2 lbs; 17.2 × 11.0 × 5.0 cm (W × D × H)
