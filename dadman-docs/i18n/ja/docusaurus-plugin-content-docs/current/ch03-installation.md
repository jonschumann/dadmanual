## 3.1 インストールの概要

### 3.1.1 ソフトウェアコンポーネント

DADman と DAD Thunderbolt 3 ドライバは **2 つの独立したアプリケーション** です。 両方が必要であろうと、DADman だけが必要であろうと、ハードウェアがどのようにコンピュータに接続するかによって異なります。

| コンポーネント                    | 目的                                                                                                                       | 必須項目                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------- |
| **DADman**                 | イーサネット経由で接続されたすべてのDAD、NTP、およびAvid ハードウェアユニットを設定および制御します                                                                  | サポートされているすべてのハードウェア             |
| **DAD Thunderbolt 3 ドライバ** | サンダー\|コアインターフェースをコアオーディオデバイス(macOS)またはASIOデバイス(Windows)としてDAWおよびオーディオアプリケーションで使用する | AX64、AXセンター、コア256、Avid MTRX製品のみ |

> **注意:** Thunderbolt 3 ドライバは、お使いのコンピュータとハードウェアの間のオーディオ_トランスポート_を提供します。DAWはオーディオインターフェースとして認識します。 DADman は _control_ レイヤー、ルーティング、ゲイン、モニタリング、設定を提供します。 両方が競合せずに、同時に同じコンピュータにインストールして実行することができます。

ハードウェアがイーサネット経由でコンピュータに接続されている場合(AX32、DX32R、Pentaユニットなど)、DADmanのみが必要です。

### 3.1.2 接続トポジー

DADman は、Thunderbolt 3 経由でも接続されているかどうかにかかわらず、イーサネット(IP)プロトコルを使用してコンピュータのネットワーク上に接続されたすべてのユニットと通信します。 インストール前のガイダンスについては、[3.7 — ネットワーク接続の設定]を参照してください。

## 3.2 ソフトウェアの取得

### 3.2.1 DADおよびNTPハードウェアユーザー

DADサポート ポータルから DADman と Thunderbolt 3 ドライバをダウンロードしてください。

**[https://www.digitalaudiosupport.com](https://www.digitalaudiosupport.com)**

ダウンロードセンターにアクセスするには、無料のDAD/NTPテクノロジアカウントが必要です。 アカウントをお持ちでない場合:

1. サポート ポータルに移動し、**アカウントを作成**を選択します。
2. 登録フォームに記入してください。
3. メールアドレスを確認したら、ログインして **ダウンロードセンター** に移動します。
4. お使いのオペレーティングシステムの DADman エントリを見つけて、インストーラをダウンロードします。
5. お使いのハードウェアが Thunderbolt 3 対応の Thunderbolt 3 ドライバをダウンロードしてください。お使いのハードウェアが Thunderbolt 3 対応製品(AX64、AX センター、Core 256)の場合も同様です。

> **注意:** インストールする前に必ずダウンロードセンターでリリースノートを確認してください。 リリースノートでは、テスト済みの OS バージョン、新しい OS リリースに関する既知の問題、その DADman バージョンのファームウェア互換性要件について説明します。

### 3.2.2 Avid Hardware Users

Avid MTRX、MTRX II、MTRX Studioを使用している場合:

1. [https://avid.com](https://avid.com)で**Avid Master Account** にログインします。
2. ダウンロードに移動し、Avid ハードウェア用に承認された DADman バージョンを探します。
3. Avid アカウントからインストーラをダウンロードします。

> **注意:** Avid-approved DADman バージョンは、DAD サポートポータルで利用可能な最新バージョンと異なる場合があります。 互換性を確保するために常にAvid MasterアカウントのバージョンをAvidハードウェアに使用してください。

## 3.3 DADman のインストール

### 3.3.1 macOS

**始める前に:** 管理者権限でアカウントにログインしていることを確認してください。 実行されている可能性のあるオーディオアプリケーションを終了します。

1. ダウンロードした DADman インストーラファイル (`.pkg` 形式) を見つけてダブルクリックしてインストーラを起動します。
2. ライセンス契約を読んで**続ける**をクリックし、**同意する**をクリックして承認します。
3. Click **Install**. プロンプトが表示されたら、管理者パスワードを入力し、**ソフトウェアをインストール**をクリックします。
4. インストールが完了したら、**閉じる**をクリックしてください。
5. **Applications** フォルダに移動し、**DADman.app** が存在していることを確認します。

DADman がインストールされました。 Thunderbolt 3 ドライバをインストールする必要がある場合は、まだ起動しないでください。[3.4](#34-installing-the-thunderbolt-3-driver-thundercore-products-only)に進んでください。

ハードウェアがイーサネット経由のみに接続されている場合は、今すぐDADmanを起動できます。 [3.7 — ネットワーク接続の設定](#37-configuring-the-network-connection)に進みます。

### 3.3.2 Windows

**始める前に:** 管理者権限でアカウントにログインしていることを確認してください。 実行されている可能性のあるオーディオアプリケーションを終了します。

1. ダウンロードした DADman インストーラーファイル (`.exe` または `.msi` 形式) を見つけてダブルクリックします。
2. ユーザーアカウント制御プロンプトが表示されたら、**はい** をクリックしてインストーラの実行を許可します。
3. インストーラのプロンプトに従って、各ステップで **次へ** をクリックします。
4. **インストール**をクリックしてインストールを開始します。
5. インストールが完了したら、**完了**をクリックします。
6. DADman がスタートメニューに表示されていることを確認します。

ハードウェアがイーサネットのみで接続されている場合は、[3.7](#37-configuring-the-network-connection)に進んでください。 Thunderbolt 3 ドライバが必要な場合は、[3.4](#34-installing-the-thunderbolt-3-driver-thundercore-products-only)に進んでください。

## 3.4 Thunderbolt 3 ドライバのインストール(Thunderbolt|コア製品のみ)

> **注意:** このセクションはハードウェアがAX64、AXセンター、Core 256、またはAvid MTRX製品の場合にのみ適用されます。 ハードウェアがイーサネット経由でコンピュータに接続されている場合は、[3.7](#37-configuring-the-network-connection)にスキップしてください。

DAD Thunderbolt 3 ドライバを使用すると、Thunderbolt 3 対応の Thunderbolt 3 対応のインターフェイスを、macOS Core Audio (**Audio MIDI Setup** に表示されます) または Windows の ASIO デバイスとして表示できます。 DAWやその他のオーディオアプリケーションで利用できるようにします。 ドライバをインストールすることは、ユニットをイーサネット経由で通信するDADmanの能力に影響を与えません — これらは独立した接続パスです。

> **注意:** ドライバのインストール手順が指示されるまで、Thunderbolt ポートにコアハードウェアを接続しないでください。

### 3.4.1 macOS

**始める前に** macOS 11 Big Sur 以降を実行していることを確認してください。 DADman v5.6.7.1 以降が既にインストールされていることを確認する ([3.3.1](#331-macos)を参照)。

1. ダウンロードした Thunderbolt 3 ドライバインストーラ(`.pkg`形式)を探し、デスクトップにコピーします。
2. `.pkg`ファイルをダブルクリックしてインストーラを起動します。
3. 画面上のプロンプトに従ってください。 **次へ**をクリックし、**インストール**をクリックします。
4. 管理者パスワードを入力し、**ソフトウェアをインストール**をクリックします。
5. このコンピュータにドライバがインストールされたのが初めての場合、macOSは\*\*"System Extension Blocked"\*\*の通知を表示します。
   - **セキュリティ設定を開く** (または macOS の Ventura 以降でシステム設定を開く) をクリックします。
6. **プライバシーとセキュリティ**ペイン内:
   - ウィンドウの下部にあるロックアイコンをクリックし、パスワードを入力してロックを解除します。
   - Digital Audio Denmark / NTPテクノロジーのブロックされた拡張機能の横にある**許可**をクリックします。
7. プロンプトが表示されたら、**再起動**をクリックしてコンピュータを再起動します。

> **注意:** "System Extension Blocked" 通知は macOS での初回インストールの通常の一部です。 それはエラーではありません。 ドライバが機能する前に拡張機能を許可する必要があります。

8. 再起動後、Applicationsフォルダから**DADDriverSetup**を開きます。
9. Thunderbolt 3 ポートまたは USB-C ポートにコアハードウェアを接続するには、20 Gbps定格ケーブルを使用します。

ドライバがインストールされました。 [3.5.1](#351-macos-daddriversetup)に進み、ドライバの設定を行います。

> **注意 — macOS Sequoia (15) 以降:** Apple は macOS Sequoia で始まる、Thunderbolt アクセサリのセキュリティ権限を大幅に強化しました。 追加の手順が必要です。 続行する前に、[セクション 3.6 — macOS Sequoia: 追加のセキュリティ設定](#36-macos-sequoia-additional-security-configuration) を参照してください。

### 3.4.2 Windows

**始める前に** Windows 10 または Windows 11 (64 ビット) を実行していることを確認してください。 DADman v5.6.7.1 以降が既にインストールされていることを確認する ([3.3.2](#332-windows)を参照)。

1. ダウンロードした Thunderbolt 3 ドライバインストーラ(`.msi` 形式)を探し、デスクトップにコピーします。
2. `.msi`ファイルをダブルクリックしてインストーラを起動します。
3. ユーザーアカウント制御プロンプトが表示されたら、**はい**をクリックします。
4. 画面上のプロンプトに従ってください。 **次へ**をクリックし、**インストール**をクリックします。
5. インストールが完了したら、**完了**をクリックします。
6. Thunderbolt 3 ポートまたは USB-C ポートにコアハードウェアを接続するには、20 Gbps定格ケーブルを使用します。

ドライバがインストールされました。 オーディオアプリケーションでドライバを設定するには、[3.5.2](#352-windows-asio-configuration)に進みます。

## 3.5 Thunderbolt 3 ドライバの設定

### 3.5.1 macOS — DADDriverSetup {#351-macos-daddriversetup}

**DADDriverSetup** アプリケーションは、macOS 上の Thunderbolt 3 オーディオドライバのチャンネル数とデバイス選択を制御します。 ここで行った変更はすぐに **オーディオ MIDI セットアップ** に反映され、コンピュータ上のCore Audio互換アプリケーションに表示されます。

> **注意:** Thunderbolt オーディオドライバのサンプルレートは、DADDriverSetup 内とDADman から直接設定できます。 通常の操作では、サンプルレートを変更するためにDADDriverSetupを開く必要はありません。

\*\*macOS では、DADDriverSetup を開く唯一の理由は、ホストに表示される Thunderbolt チャンネル数を変更することです。 \* 他のすべてのパラメータは、DADman 内から設定できます。

> **ご注意 — Intel vs. Apple Silicon Mac:** Apple M1 以降のコンピュータは、256の双方向Thunderboltチャンネルを問題なく処理できます。 IntelベースのMacの場合 特にサンプルレートが高い場合やCPU負荷が大きい場合には、ワークフローで256チャンネルが必要でない場合には、システムのパフォーマンスが低下する可能性があります。

**チャンネル数を変更するには:**

1. アプリケーションフォルダから **DADDriverSetup** を開きます。
2. サンダー\|コアハードウェアが接続され電源がオンになっていることを確認してください。
3. 以下の設定を行います。

| パラメータ       | オプション                                                                                                          | メモ                                                                                                                                 |
| ----------- | -------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **デバイス選択**  | 接続されたThunderbirdのドロップダウンリスト\|コアユニット                                                                            | Thunderbolt 3 バス上で複数のユニットがデイジーチェーン接続されている場合、それぞれのユニットを個別に選択できます。                                                                   |
| **サンプルレート** | 44.1, 48, 88.2, 96, 176.4, 192, 352.8, 384 kHz | DADman からも設定可能です。ここでの変更は、Core Audio に反映されます。                                                                                       |
| **チャンネル**   | 16, 64, 128, 256 (双方向)                                                                      | すべてのThunderbird\|コアインターフェースは、ハードウェア内の256の双方向チャネルをサポートしています。 M1以降のMacは256チャンネルを問題なく処理します。 Intel Mac では、この値を減らすと、CPU オーバーヘッドが低くなります。 |

> **注意:** チャンネル設定はコアオーディオと DAW に表示されるチャンネル数を制御します。 これは、DADman のルーティング マトリクス内で内部的に利用可能なチャネル数には影響しません。

4. 変更後 **Audio MIDI Setup** (**Applications > Utilities > Audio MIDI Setup**)を開いて、DAD Thunderb\|Core インターフェイスが正しいフォーマットで表示されていることを確認します。 表示される形式は、DADDriverSetupで設定されたチャネル数とサンプルレートと一致する必要があります。

> **ヒント:** DADDriverSetupが開き、接続されているThunderboltユニットがデバイス選択のドロップダウンに表示された場合、Thunderboltドライバが正しくインストールされ、正しく機能します。 これは、DAWを開かなくてもmacOSでドライバ操作を確認する最も迅速な方法です。

### 3.5.2 Windows — ASIO 設定 {#352-windows-asio-configuration}

Thunderbolt 3 ASIOドライバは、オーディオアプリケーションのASIO設定ダイアログから構成されます。

**ドライバを設定するには:**

1. DAWまたはオーディオアプリケーションを開きます。
2. オーディオデバイスの設定で、ASIOドライバとして**Digital Audio Denmark**を選択します。
3. ASIO 設定ダイアログを開きます。 次のパラメータを設定します。

| パラメータ        | オプション                                                                                                          | メモ                                                                                                          |
| ------------ | -------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **デバイス選択**   | 接続されたThunderbirdのドロップダウンリスト\|コアユニット                                                                            | プライマリASIOデバイスとして使用するユニットを選択してください                                                                           |
| **バッファーサイズ** | 16, 32, 64, 256, 512, 1024                                                                                     | 安定したオーディオパスを確保するために、大きな値(512または1024)から開始します。システムが安定していることを確認したら減らします                     |
| **サンプルレート**  | 44.1, 48, 88.2, 96, 176.4, 192, 352.8, 384 kHz | オーディオアプリケーションによって制御されます。参照のためにここにリストされています                                                                  |
| **チャンネル**    | 16, 64, 128 (双方向)                                                                           | Windows Thunderbolt ASIO ドライバーは、最大 128 の双方向チャンネルに対応しています。 システムのパフォーマンスを向上させるためにすべてのチャネルが必要でない場合は、最大から削減します。 |

> **ヒント:** ASIO設定ダイアログが開き、デバイス選択ドロップダウンにあなたのThunderbird\|コアユニットが表示された場合 Thunderbolt ASIOドライバが正しくインストールされ、正常に機能しています。 これは、オーディオ再生を開始する必要がなく、Windows上でドライバ操作を確認する最も迅速な方法です。

**ドライバの診断 — Windowsのみ:**

ASIOドライバ構成ウィンドウには、3つのリアルタイム性能指標が含まれています。 初期設定時やオーディオの問題が発生した場合は、これらを監視してください。

| インジケーター：                                      | 許容可能な値                                                                      | 範囲外の場合                                                                                                                   |
| --------------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **不在のIRS** (不在のオーディオ中断)    | 0                                                                           | 競合するWindowsシステムプロセスによってオーディオ割込みが削除されています。 バッファサイズを大きくするか、バックグラウンドCPU負荷を軽減します。                                            |
| **PCIe Load**                                 | 低い割合; チャンネル数のスケール                                                           | 高い値は、PCIe バスが飽和していることを示します。 チャンネル数を減らすか、他のPCIe帯域幅の消費者を調査します。                                                             |
| **DPC Latency** (遅延手順呼び出し) | Low (< ~500 μs) | Windows OSの割込みスケジュールが遅延をもたらしています。 DPCのレイテンシー解析ツールを使用して、問題のあるドライバを特定します。 最初のステップとして、Wi-Fi、USB電源管理、またはその他の中断発生ドライバを無効にします。 |

> **注意:** ASIOドライバを最初に設定するときは、大きなバッファサイズ(512または1024サンプル)から開始します。 システムが割り込みを逃さずに実行されていることが確認されると、ワークフローのバッファサイズを最小の安定値に下げることができます。

## 3.6 macOS Sequoia: 追加のセキュリティ設定

> **以下に適用されます:** macOS 15 (Sequoia) とそれに続くmacOSリリース  
> **ソース:** DAD Technical Support Bulletin, January 2026

macOS Sequoia を皮切りに、Apple は Thunderbolt と USB アクセサリの接続に関するセキュリティコントロールを大幅に強化しました。 この変更は、すべてのメーカーのすべての Thunderbolt インターフェースに影響します。これは、DAD ハードウェアまたはソフトウェアに固有のものではありません。

macOS Sequoia 以降にインストールしている場合は、[3.4.1](#341-macos)の標準ドライバインストールに**加えて**以下の手順を実行してください。

### 3.6.1 付属品権限の設定

1. **システム設定** を開きます (Appleメニュー > システム設定)。
2. **プライバシーとセキュリティ**に移動します。
3. **アクセサリー** セクションまでスクロールします。
4. アクセサリ接続の権限を以下に設定します:
   - **新しいアクセサリを自動的に接続できるようにする** — 制御された環境を残さないスタジオコンピュータにお勧めします
   - **Always Allow** — 最大許容; 複数の Thunderbolt デバイスを接続する場合に適切です
5. プロンプトが表示されたら、パスワードまたはTouch IDで変更を承認してください。

### 3.6.2 Sequoia でドライバを再インストールする

Thunderbolt 3 ドライバの以前のバージョンがあり、macOS Sequoia で新しいバージョンにアップグレードしている場合:

> **注意:** Appleのセキュリティモデルでは、新しいドライバをインストールする前に古いドライバを削除する必要があります。 既存のインストールで新しいインストーラを実行するだけでは、Sequoia のドライバが正しく機能しません。

1. アプリケーションフォルダの**DADDriverSetup.app**を探します。
2. ゴミ箱に移動します（**右クリック>ゴミ箱に移動**またはゴミ箱にドラッグ）。
3. macOS はシステム拡張機能が削除されることを示す警告を表示します。 これは期待され望ましい結果です。クリックして削除を確認します。
4. [https://www.digitalaudiosupport.com](https://www.digitalaudiosupport.com)から最新の Thunderbolt 3 ドライバをダウンロードしてください。
5. [3.4.1](#341-macos)の手順に従って、新しいドライバをインストールします。
6. インストーラが完了すると、macOS に新しいThunderbolt 接続の承認を求めるダイアログが表示されます。 **許可** (または同等) をクリックし、コンピューターを再起動させます。

再起動後、サンダー\|コアハードウェアが正しく接続されているはずです。

### 3.6.3 macOS Sequoia — 既知のネットワーク接続の問題

> **影響:** macOS Sequoiaのすべての DADman バージョン; 将来の DADman アップデート  
> **バージョンが記載されています:** DADman v5.8.1.6 の時点で

macOS Sequoia では、アプリケーションが最初に起動すると、ネットワーク上のデバイスに DADman が接続できないことがあります。 Thunderbolt 3 経由で接続されたオーディオデバイスは、この問題の影響を受けません。

**回避策:**

1. デバイス一覧にデバイスが表示されていなくても、DADman を起動し、実行したままにします。
2. macOS ユーザーアカウントからログアウトします(**アップルメニュー > ログアウト**)。
3. macOS ユーザアカウントにログインし直します。
4. DADmanはネットワークデバイスに正常に接続します。

> **注意:** DADman をログイン時に自動的に起動させるように設定すると、起動時に手動で回避する必要がなくなります。 [チャプター8 — 高度な機能、セクション8.X — システム起動時に起動する DADman の設定]を参照してください。

## 3.7 ネットワーク接続の設定

### 3.7.1 ネットワーク概要

DADman は、IP プロトコルを使用してイーサネット経由ですべての接続されたユニットと通信します。 これには、Thunderbolt 3 経由でコンピュータに接続できるユニットが含まれています。両方の接続パスは同時にアクティブで、異なる目的で使用されます。 イーサネットは制御データを搭載しています。

DADmanはコンピュータのネットワークを使用してハードウェアユニットを発見し、通信します。 各ユニットの設定はユニット自体に保存されます。DADman はこれらの設定をネットワーク接続上で読み書きします。 ネットワーク接続が失われた場合、DADman はユニットの制御を失いますが、オーディオはユニットを通過します。

### 3.7.2 強くお勧めの専用ネットワーク

> **注意事項: ネットワーク分離:** 信頼性の高い動作のために、DADは DADman 制御のための **専用イーサネットネットワーク** を使用することを強くお勧めします。 一般的なスタジオや施設のネットワークとは別にね Audio over IPトラフィック(Dante、AES67)、EuControl、または一般的なオフィス/インターネットトラフィックと制御ネットワークを共有すると、オーディオと制御のドロップアウトのリスクが生じます。

典型的なスタジオ設置で推奨されるネットワークトポロジ:

| ネットワーク             | 目的                   | コンピュータへの接続                  |
| ------------------ | -------------------- | --------------------------- |
| 専用制御ネットワーク         | DADman ↔️ ハードウェアユニット | 専用イーサネットポート/USB-イーサネットアダプター |
| スタジオ/IPオーディオネットワーク | ダンテ/AES67 オーディオ転送    | 専用イーサネットポート                 |
| オフィス/インターネットネットワーク | 一般的なコンピューターの使用       | Wi-Fiまたは3番目のイーサネットポート       |

単純な2ユニットシステム(1台のコンピュータ+1台のハードウェアユニット)は、コンピュータのイーサネットポートとユニットのネットワークポートとの間の単一のケーブルで直接イーサネット接続を使用することができます — 両方が同じサブネット上で設定されている場合、スイッチは必要ありません。

### 3.7.3 IP アドレスの設定

DADman は IP アドレスでユニットを発見します。 ユニットは、ネットワーク環境に応じて、静的なIPアドレスまたはDHCP割り当てられたアドレスのいずれかで構成できます。

**シンプルな専用ネットワーク設定**（制御ネットワーク上にDHCPサーバーがありません）には、静的IPアドレスを設定してください：

| デバイス                                   | IPアドレスの例                                                     | サブネットマスク                                                      |
| -------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------- |
| コンピューター (コントロールNIC) | 192.168.1.1  | 255.255.255.0 |
| ハードウェアユニット 1                           | 192.168.1.10 | 255.255.255.0 |
| ハードウェアユニット 2                           | 192.168.1.11 | 255.255.255.0 |

IPアドレスは、ハードウェアモデルに応じて、DADman、ユニットのフロントパネルディスプレイ、またはWebブラウザインタフェースを使用してハードウェアユニットに設定されます。 IPアドレスの設定方法については、特定のハードウェアユニットのインストールガイドを参照してください。

> **注意:** ハードウェアユニットの IP アドレスを変更した後 接続が再確立される前に、新しいアドレスを反映するように DADman のデバイスリストを更新する必要があります。

**DHCPサーバーを備えた施設ネットワークの場合:** DHCPを使用するユニットを設定できます。 ただし、DHCP リースが変更されると、DADman は以前のアドレスでユニットの追跡を失います。 スイッチまたはルーター上でDHCP予約(固定MAC-IPマッピング)を割り当てることは、これを防ぐために推奨されます。

## 3.8 インストールの確認

DADman がインストールされて(該当する場合)、Thunderbolt 3 ドライバがインストールされ、ネットワークが設定されています [Chapter 6 — Getting Started] に進む前に、インストールが正しいことを確認するために、以下のチェックを行います。

### 3.8.1 DADman の検証

1. アプリケーションフォルダ(macOS)またはスタートメニュー(Windows)から**DADman**を起動します。
2. デバイスの検出が完了するまで最大30秒待機します。
3. DADman ウィンドウの上部の **Device List** にハードウェアユニットが表示されていることを確認します。
4. ユニットの現在のファームウェアバージョンが表示され、あなたの期待に合うことを確認してください。

デバイスが表示されない場合は、[第9章 — トラブルシューティング、9.2 — ネットワークと接続の問題]を参照してください。

### 3.8.2 Thunderbolt 3 ドライバ(macOS)の確認

1. **Audio MIDI Setup** (**Applications > Utilities > Audio MIDI Setup**)を開きます。
2. **DAD Thunderbird\|Core** インターフェイスが左側のデバイスリストに表示されていることを確認してください。
3. 表示されるフォーマット(例えば、"256 ch, 48000 Hz")が、DADDriverSetupで設定された設定と一致することを確認します。

インターフェイスが表示されない場合は、確認:

- このユニットは電源をオンにし、20 Gbps定格のThunderboltケーブルを介して接続されています。
- システム拡張は**プライバシーとセキュリティ** ([3.4.1](#341-macos)ステップ6を参照) で許可されています。
- macOS Sequoia であれば、Accessories パーミッションが正しく設定されています ([3.6.1](#361-setting-accessory-permissions)を参照)。

### 3.8.3 Thunderbolt 3 ドライバの確認中(Windows)

1. DAWまたはオーディオアプリケーションを開きます。
2. オーディオデバイスの設定で、**Digital Audio Denmark** がASIOドライバとして選択可能であることを確認します。
3. ASIO構成ダイアログを開き、デバイス選択ドロップダウンにデバイスが表示されていることを確認します。
4. **Missed IRs** カウンタがアイドル操作の数秒後に**0**を読み込むことを確認します。
