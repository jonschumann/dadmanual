# DADman Brugermanual

**Software version:** DADman v5.8.2 build 2  
**Udgivet:** June 2026  
**Maintained by:** NTP Technology A/S / Digital Audio Denmark

---

Denne manual dækker komplet installation, konfiguration og drift af **DADman styresoftware** til alle kompatible DAD og NTP-teknologihardware, herunder AX Center, Core 256, AX64, AX32, DX32R, MOM og Penta-serien.

## Sådan skal du bruge denne manual

- \*\*Ny på DADman? \* Start med [Kapitel 3 — Installation](/installation) for at få softwaren installeret, følg derefter [Kapitel 6 — Kom i gang](/getting-started) for en trin-for-trin første session walkthrough.
- **Leder du efter en bestemt funktion?** Brug sidebjælken eller søgningen (tryk på **Ctrl+K** / **¤ K**).
- **Fejlfinding af et problem?** Gå direkte til [Kapitel 9 — Fejlfinding](/troubleshooting).
- **Leder du et udtryk?** Se [Tillæg G — Ordliste](/appendices#appendix-g--glossary).

## Kompatibel hardware

DADman v5.8.2 styrer følgende hardware:

| Hardware                        | Familie                                    |
| ------------------------------- | ------------------------------------------ |
| DAD AX Center · Core 256 · AX64 | Tordenkerne (familie 2) |
| DAD AX32 · DX32R · MOM          | Familie 1                                  |
| NTP Penta 720 · Penta 721s      | Familie 1                                  |
| Avid MTRX · MTRX II             | Familie 1 / 2                              |
| Avid MTRX Studio                | Familie 3                                  |
| Dynaudio Control 01 / 02        | Tilbehør                                   |
