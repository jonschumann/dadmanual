# Kapitel 1 — Indledning

> **Produkt:** Digital Audio Denmark Penta 720

---

## 1.1 Produktoversigt

Penta 720 er en modulopbygget 2U rackmount audio lydkort og format-konvertering platform fra NTP-teknologi. Det forbinder til computeren over Ethernet kun og forvaltes af DADman for routing og konfiguration. Det bruges til high-channel-count AES/EBU og MADI I/O, format konvertering, og netværk audio distribution.

**Forbindelse til værten:** Ethernet (ingen Thunderbolt)
**Form factor:** 2U rackmount (modulært chassis)
**Lydkanaler:** Op til 720 kanaler (kortafhængig)

---

## 1.2 Nøglefunktioner

![Penta 720 — frontpanel](/img/panel-penta720-clean.png)
_Penta 720 — frontpanel_

- **Form factor:** 2U rackmount, 19"; front-access card bays
- **Udvidelse:** 8 hot-plug udvidelseskortpladser — op til 1.024×1,024 kanaler I/O
- **MADI:** Indbygget koaksial MADI I/O — 64 kanaler ved 48 kHz
- **AES3:** Indbygget AES3 I/O — 16 kanaler via 2 × DB25 (Tascam pinout)
- **Dante (valgfri):** Via MOD-DANTE-BK3 modul — 64 kanaler ved 48 kHz
- **DADlink (valgfri):** Via MOD-MADI-DADLNK modul + SFP — op til 256×256 kanaler
- **Synkronisering:** Word ur I/O (BNC, 75 Ω), Video Black Burst input, AES11 input
- **Routing:** 1,424×1,424 matrix; 256×32 summing processor; 28-bit floating-point
- **Latency:** 7 prøver intern delay, justerbar 3–31 prøver; alle udgange tid- og fase-justeret
- **Kontrol:** DADman software (macOS og Windows); Avid EuCon kompatibel; Gigabit Ethernet
- **Strøm:** Dobbelt PSU; dobbelt lysnet-indgange
- **Køling:** 2 × interne ventilatorer
- \*\*Vægt / dybde: \*\* 5,0 kg / 11,0 lbs; chassis dybde 35 cm / 13,8"
