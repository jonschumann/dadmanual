# Kapitel 1 — Indledning

> **Produkt:** Digital Audio Denmark Core 256

---

## 1.1 Produktoversigt

Core 256 er en kompakt halv-rack Thunderbolt 3 audio lydkort deler den samme bagpanel stik supplerer som AX Center men uden front-panel I/O. Den er konstrueret til installationer, hvor der er behov for en Thunderboltkerne med høj kanaltælling.

**Tilslutning til vært:** Thunderbolt 3
**Formfaktor:** Halv-rack (1U med hylde/beslag)
**Lydkanaler:** Op til 256 × 256 kanaler ved 48 kHz

---

## 1.2 Nøglefunktioner

![Core 256 — front](/img/panel-core256-front-clean.png)
_Core 256 — front_

![Core 256 — bag](/img/panel-core256-rear-clean.png)
_Core 256 — bag_

- **Form factor:** Halvrack desktop; 1U rack-monterbar med valgfri C256-2MOUNT-BRACKET
- **Ingen udvidelsespladser** — alle I/O er via indbyggede grænseflader
- **Thunderbolt 3:** 2 × USB-C — 256 kanaler ved 48/96 kHz; 15 W buseffekt pr. port
- **Dante AoIP:** Indbygget — 256 kanaler ved 48 kHz, 128 kanaler ved 96 kHz
- **MADI:** Indbygget koaksial MADI I/O — 64 kanaler ved 48 kHz
- **ADAT / S/PDIF:** Indbygget ADAT/SMUX (16 ch) og S/PDIF (2 ch)
- **DADlink:** 2 × SFP-bure — DADlink (op til 256×256 ch) eller MADI optisk
- **Synkronisering:** Word ur I/O (BNC, 75 Ω), Video Black Burst input
- **Routing:** 848×848 matrix; 512×64 summing processor; 1,024-filter SPQ equaliser; 28-bit floating-point
- **Latency:** 7 prøver intern delay, justerbar 3–31 prøver; alle udgange tid- og fase-justeret
- **Kontrol:** DADman software (macOS og Windows); Avid EuCon kompatibel; Gigabit Ethernet
- **Strøm:** DC-indgang (12 V); ekstern PSU inkluderet — ingen IEC-netstik på enhed
- \*\*Vægt / dybde: \*\* 1,3 kg / 2,9 lbs; chassisdybde 23,1 cm / 9,1"
