# Kapitel 1 — Indledning

> **Produkt:** Digital Audio Danmark AX64

---

## 1.1 Produktoversigt

AX64 er en 2U rackmount Thunderbolt 3 eller Ethernet audio interface med op til otte DB25 analoge ekspansion kortpladser. Det er almindeligt anvendt som en fase boks, satellit I/O-enhed, eller standalone Ethernet audio endpoint i distribuerede systemer.

**Forbindelse til værten:** Thunderbolt 3 eller Ethernet
**Formfaktor:** 2U rackmount
**Lydkanaler:** Op til 64×64 analoge kanaler (kortafhængig)

---

## 1.2 Nøglefunktioner

![AX64 — frontpanel](/img/panel-ax64-front-clean.png)
_AX64 — frontpanel_

![AX64 — bagpanel](/img/panel-ax64-rear-clean.png)
_AX64 — bagpanel_

- **Form factor:** 2U rackmount, 19"
- **Udvidelse:** 8 hot-plug udvidelseskortpladser — op til 1.024×1,024 kanaler I/O
- **Thunderbolt 3:** 2 × USB-C — 256 kanaler ved 48/96 kHz; 15 W buseffekt pr. port
- **Dante AoIP:** Indbygget — 256 kanaler ved 48 kHz, 128 kanaler ved 96 kHz
- **MADI:** Indbygget koaksial MADI I/O — 64 kanaler ved 48 kHz
- **ADAT / S/PDIF:** Indbygget ADAT/SMUX (16 ch) og S/PDIF (2 ch)
- **DADlink:** 2 × SFP-bure — DADlink (op til 256×256 ch) eller MADI optisk
- **Synkronisering:** Word ur I/O (BNC, 75 Ω), Video Black Burst input
- **Routing:** 1,872×1,872 matrix; 512×64 summing processor; 1,024-filter SPQ equaliser; 28-bit floating-point
- **Latency:** 7 prøver intern delay, justerbar 3–31 prøver; alle udgange tid- og fase-justeret
- **Kontrol:** DADman software (macOS og Windows); Avid EuCon kompatibel; Gigabit Ethernet
- **Strøm:** Dobbelt PSU standard; valgfri redundant lysnettet input (AX64-BASE-RPS)
- \*\*Vægt / dybde: \*\* 5, 5 kg / 12, 2 lbs; chassisdybde 34, 5 cm / 13, 6"
