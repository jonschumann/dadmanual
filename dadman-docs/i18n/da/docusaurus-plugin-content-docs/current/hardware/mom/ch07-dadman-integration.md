# Kapitel 7 — Integration Af DADman-software

> **Produkt:** Digital Audio Denmark MOM

> For fuld DADman operation, se **DADman User Manual** på [docs.evangelaudio.com](https://docs.evangelaudio.com).

---

## 7.1 Hvordan MOM vises i DADman

_[Pladsholder — beskriv hvad brugeren ser i DADman- enhedslisten, når MOM er tilsluttet. Inkludér skærmfotopladsholder.]_

Når MOM er tilsluttet og tændt, vises det i **Enhedsliste**-panelet i DADman. DADman identificerer det ved dets enhedstype og serienummer. Brugeren tildeler en etiket, der fortsætter på tværs af sessioner.

Enhedslisten for MOM visninger:

| Felt                   | Indhold                         |
| ---------------------- | ------------------------------- |
| Enheds type            | MOM                             |
| Serienummer            | Entydig enhedsidentifikator     |
| Status for forbindelse | Online / Offline                |
| Firmware version       | Nuværende firmware-version      |
| Ur status              | Lås tilstand og valgt reference |
| I/O kanalkort          | Tildelte kanalintervaller       |
