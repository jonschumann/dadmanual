# Kapitel 5 — Ure Og Synkronisering

> **Produkt:** Digital Audio Denmark MOM

MOM indeholder ingen lyd kredsløb og har ingen ur funktion. Uret udføres af værten AX Center eller AX64. Se **AX Center Hardware Manual** eller **AX64 Hardware Manual** for klokkeslæt.
