# Kapitel 4 — Signalforbindelser

> **Produkt:** Digital Lyd Danmark AX32  
> \*\*Varenummer: \*\* AX32-BASE2

---

## 4.1 Thunderbolt 3 Host Tilslutning

Tilslut AX32 til værtscomputeren ved hjælp af et ratet Thunderbolt 3 kabel. Enheden vises i DADman som en Thunderbolt lydenhed.

> **BEMÆRK:** Brug kun Thunderbolt 3 ratede kabler. Standard-USB-C-kabler giver ikke pålidelig drift.

---

## 4.2 analoge forbindelser (via udvidelseskort)

Analog I/O leveres af installerede ekspansionskort (CARD-L8, CARD-M8, CARD-DA8). Hvert kort giver en 8-kanals DB25 stik ved hjælp af Tascam pinout standard.

For stikkontakter angives detaljer, se:

- [CARD-L8 — DB25 Input Pinout](../../expansion-cards/card-l8#db25-input-pinout-tascam)
- [CARD-M8 — DB25 Input Pinout](../../expansion-cards/card-m8#db25-input-pinout-tascam)
- [CARD-DA8 — DB25 Output Pinout](../../expansion-cards/card-da8#db25-output-pinout-tascam)
