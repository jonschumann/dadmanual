# Kapitel 7 — Integration Af DADman-software

> **Produkt:** Digital Lyd Danmark AX32  
> \*\*Varenummer: \*\* AX32-BASE2

---

## 7.1 Oversigt

AX32 forvaltes fuldt ud af DADman. Alle routing, få kontrol, clocking, og ekspansionskort konfiguration udføres via DADman software interface. Enheden bliver opdaget automatisk på det lokale netværk, når den er tilsluttet via Ethernet.
