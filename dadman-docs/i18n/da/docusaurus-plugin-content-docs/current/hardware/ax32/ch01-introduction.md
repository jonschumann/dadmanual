# Kapitel 1 — Indledning

> **Produkt:** Digital Lyd Danmark AX32  
> \*\*Varenummer: \*\* AX32-BASE2

---

## 1.1 Produktoversigt

AX32 er en 2U rackmount modulopbygget I/O og format-konvertering platform. Det giver op til 32 kanaler af analoge I / O (16 i / 16 ud) via sine otte hot-plug ekspansionskort slots, sammen med indbygget koaksial MADI I/O og AES3 I/O. AX32 omfatter ikke en Thunderbolt host interface; den forbinder til netværket og forvaltes af DADman over Gigabit Ethernet. AX32-BASE2 er den nuværende shipping variant.

**Forbindelse til værten:** Gigabit Ethernet (DADman kontrol og netværkslyd)
**Form factor:** 2U full-rack, 19"
**Lydkanaler:** Op til 32 analoge kanaler (via udvidelseskort) 64 ch MADI; 16 ch AES3 indbygget; yderligere kanaler via valgfri netværk audio udvidelseskort

---

## 1.2 Nøglefunktioner

![AX32 — frontpanel](/img/panel-ax32-front-clean.png)
_AX32 — frontpanel_

- **Form factor:** 2U rackmount, 19"
- **Udvidelse:** 8 hot-plug udvidelseskortpladser — op til 1.024×1,024 kanaler I/O
- **MADI:** Indbygget koaksial MADI I/O — 64 kanaler ved 48 kHz
- **AES3:** Indbygget AES3 I/O — 16 kanaler via 2 × DB25 (Tascam pinout)
- **Dante (valgfri):** Via MOD-DANTE-BK3 modul
- **DADlink (valgfri):** Via MOD-MADI-DADLNK modul + SFP — op til 256×256 kanaler
- **Synkronisering:** Word ur I/O (BNC, 75 Ω), Video Black Burst input, AES11 input
- **Routing:** 1,424×1,424 matrix; 256×32 summing processor; 28-bit floating-point
- **Latency:** 7 prøver intern delay, justerbar 3–31 prøver; alle udgange tid- og fase-justeret
- **Kontrol:** DADman software (macOS og Windows); Avid EuCon kompatibel; Gigabit Ethernet
- **Strøm:** Single mains input; dual PSU standard; valgfri redundant input (AX32-RPS)
- **Køling:** 2 × super støjsvage interne ventilatorer
- \*\*Vægt / dybde: \*\* 5,0 kg / 11,0 lbs; chassis dybde 35 cm / 13,8"
