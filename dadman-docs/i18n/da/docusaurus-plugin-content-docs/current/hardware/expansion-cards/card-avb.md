# CARD-AVB — AVB / Milano Network Audio Interface Card

> \*\*Varenummer: \*\* CARD-AVB  
> **Status:** Kommer snart — endnu ikke tilgængelig

:::caution Kommer snart
CARD-AVB er endnu ikke blevet frigivet. Denne side er en pladsholder. Specifikationer, tilgængelighed og priser vil blive offentliggjort, når produktet lanceres. Kontakt din DAD-distributør eller Digital Audio Danmark for seneste information.
:::

---

## Oversigt

CARD-AVB vil give Audio Video Bridging (AVB) og Milano netværk audio connectivity for kompatible DAD chassis. AVB er en IEEE 802.1Q-baseret deterministisk netværk standard almindeligt anvendt i installerede lyd og live produktion applikationer.

---

## Forventede Funktioner

_Følgende oplysninger er kun vejledende og kan ændres før udgivelse._

- IEEE 802.1Qav (Credit-Based Shaper) og IEEE 802.1Qat (Stream Reservation Protocol)
- Milano interoperabilitet til plug-and-play netværk lyd
- 2 × RJ45 netværksporte
- Kompatibel med standard Gigabit Ethernet switches understøtter AVB/Milan

---

## Forenelighed

CARD-AVB vil være kompatibel med alle DAD chassis, der understøtter ekspansionskort.

| Chassiser    | Kompatibel                       |
| ------------ | -------------------------------- |
| AX64         | Ja (planlagt) |
| AX Centreret | Ja (planlagt) |
| Penta 720    | Ja (planlagt) |
| Penta 721S   | Ja (planlagt) |
| AX32         | Ja (planlagt) |
| Hovednet 256 | Nej — ingen udvidelses felter    |
| MOM          | Nej — ingen udvidelses felter    |
