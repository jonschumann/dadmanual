Laden Sie diese Version von Ihrem Avid Master Account herunter, nicht vom DAD Support-Portal. Die Verwendung einer nicht genehmigten Version kann zu Kompatibilitätsproblemen mit Ihrer Avid-Hardware führen.

## 2.2 DAD-Thunderbolt 3 Treibersystemvoraussetzungen

> **HINWEIS:** Dieser Abschnitt gilt nur, wenn Ihre Hardware ein AX64, AX Center, Core 256 oder ein Avid MTRX Produkt ist. Wenn Ihre Hardware nur über Ethernet mit dem Computer verbunden ist (z.B. AX32, DX32R, Penta Serie), wird der Thunderbolt 3 Treiber nicht benötigt.

| Anforderung                   | macOS                                                                                     | Fenster                                                              |
| ----------------------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **Unterstützte OS-Versionen** | macOS 11 Big Sur und später (Intel und Apple Silicon)                  | Windows 10, Windows 11                                               |
| **Minimale DADman Version**   | 5.6.7.1 oder höher                        | 5.6.7.1 oder höher   |
| **Donnerblitzkabel**          | Thunderbolt 3 oder USB-C Kabel auf mindestens 20 Gbit/s bewertet                          | Thunderbolt 3 oder USB-C Kabel auf mindestens 20 Gbit/s bewertet     |
| **Kompatible Hardware**       | AX64, AX Center, Core 256, Avid MTRX, Avid MTRX II, Avid MTRX Studio, Dynaudio Control 01 | AX64, AX Center, Core 256, Avid MTRX, Avid MTRX II, Avid MTRX Studio |

> **KAU — Kabelspezifikation:** Verwenden eines Kabels, das nicht auf mindestens 20 Gbps bewertet ist, kann zu instabilen oder fehlgeschlagenen Thunderbolt-Verbindungen führen. Standard USB-C-Kabel ohne Thunderbolt-Zertifizierung sind nicht ausreichend. Überprüfen Sie Ihr Kabel vor der Installation.
