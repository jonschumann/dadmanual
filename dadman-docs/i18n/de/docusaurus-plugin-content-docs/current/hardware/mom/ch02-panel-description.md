# Kapitel 2 — Steuerungsreferenz

> **Produkt:** Digital Audio Denmark MOM (Monitor Operating Module)

> **Wie man dieses Kapitel nutzt:** Dieses Kapitel identifiziert jede Steuerung auf der MOM-Frontseite. Das MOM enthält keine Audioschaltung – Audiosignale werden nicht durch ihn geleitet. Für Konfigurationsvorgänge siehe [Ch. 6 — Operation](ch06-operation.

---

> **NOTICE — MOM und Monitor Profiles:** Die Funktionen der Spkr-, Src- und Layer-Tasten werden durch das in DADman geladene Monitorprofil bestimmt. Konfigurieren Sie Monitorprofile vor Verwendung des MOM in einer Sitzung. Siehe [Ch. 8 — Erweiterte Funktionen, Abschnitt 8.1 — Profile überwachen].

> **NOTICE — MOM-Anbindung:** Der MOM verbindet sich mit dem AX Center oder AX 64 über USB-C auf der Rückseite der Host-Einheit. Es ist nicht direkt an den USB-Port des Computers angeschlossen. DADman muss laufen, damit das MOM funktioniert.

## 2,3 LED Status Referenz

### MOM Status LEDs

| Stat. LED                 | Bedeutung                                                         |
| ----------------------------------------- | ----------------------------------------------------------------- |
| Stetig grün                               | MOM ist verbunden und kommuniziert mit dem Host AX Center / AX 64 |
| Langsamer Blitz (grün) | MOM initialisiert oder wartet auf DADman zu antworten             |
| Aus                                       | MOM ist nicht verbunden oder die Hosteinheit ist ausgeschaltet    |

> **NOTICE:** MOM Button Beleuchtungszustände (Cut = rot, Dim = Amber, Spkr./Src./Layer = weiß) werden in [Ch. 6 — Betrieb].
