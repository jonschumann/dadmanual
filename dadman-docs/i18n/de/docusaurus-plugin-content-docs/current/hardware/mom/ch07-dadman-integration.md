## 7.1 Wie das MOM in DADman erscheint

_[Placeholder — beschreiben, was der Benutzer in der DADman Device List sieht, wenn das MOM verbunden ist. Screenshot-Platzhalter einschließen.]_

Wenn das MOM angeschlossen und eingeschaltet ist, erscheint es in der Tabelle **Geräteliste** im DADman. DADman identifiziert es anhand des Gerätetyps und der Seriennummer. Der Benutzer weist eine Beschriftung zu, die über Sitzungen hinweg fortbesteht.

Der Eintrag der Geräteliste für die MOM zeigt:

| Feld              | Inhalt                                  |
| ----------------- | --------------------------------------- |
| Gerätetyp         | MM                                      |
| Seriennummer      | Eindeutige Einheiten-Kennung            |
| Verbindungsstatus | Online / Offline                        |
| Firmware-Version  | Aktuelle Firmware-Revision              |
| Uhr-Status        | Status und ausgewählte Referenz sperren |
| I/O-Kanalkarte    | Zugewiesene Kanalbereiche               |
