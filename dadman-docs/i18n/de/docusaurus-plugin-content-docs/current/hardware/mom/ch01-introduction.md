# Kapitel 1 — Einführung

> **Produkt:** Digital Audio Denmark MOM

---

## 1.1 Produktübersicht

Das MOM (Monitor Operating Module) ist ein physikalischer Monitor-Controller, der über Ethernet mit jedem DAD-Gerät verbunden ist und dieselbe Verbindung über PoE (Power over Ethernet) versorgt wird — es wird keine separate Stromversorgung benötigt. Es bietet direkte Zugriffssteuerungen für Lautsprecherauswahl, Quellenauswahl, Master-Ebene, Dim, Schnitt, Talkback und Referenzstufe. Das MOM enthält keine Audio-Schaltungen, die gesamte Signalverarbeitung erfolgt in der Host DAD-Einheit.

**Verbindung zum Host:** Gigabit Ethernet; PoE-powered (IEEE 802. af, Klasse 0)
**Formfaktor:** Desktop (rackmountable mit optionaler Klammer)
**Audiokanäle:** Kontrollfläche — keine Audioschaltung in Einheit

---

## 1.2 Schlüsselfunktionen

![MOM — Überblick] (/img/panel-mom-clean.png)
_MOM — Überblick_

- **Formfaktor:** Desktop; rackmountable mit optionaler Klammer
- **Lautstärke-Steuerung:** Rotationsgeber im großen Format mit 27 LED-Ring — Auflösung von 0,5 dB
- **Tasten:** 10 Direktzugriff Schlüssel × 4 Ebenen = 40 zuweisbare Funktionen
- **Kontrolle überwachen:** 3 Lautsprechersätze; 3 Quellen; Talkback; Dimm; Schnitt; Referenzlevel
- **Verbindung:** Gigabit Ethernet (RJ45) — powered via PoE (IEEE 802.3af, Klasse 0); keine separate PSU erforderlich
- **Footswitch Eingang:** 3,5 mm TRS
- **Stromverbrauch:** maximal 5 W
- **Keine Audioschaltung** — alle Signalverarbeitung wird von der angeschlossenen DAD-Einheit abgewickelt
- **DADman Integration:** Konfiguriert und betrieben über DADman Software
- **Gewicht / Abmessungen:** 1,0 kg / 2,2 lbs; 17.2 × 11.0 × 5.0 cm (W × D × H)
