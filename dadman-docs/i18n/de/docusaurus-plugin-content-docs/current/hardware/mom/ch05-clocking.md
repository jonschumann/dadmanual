# Kapitel 5 — Uhren & Synchronisierung

> **Produkt:** Digital Audio Denmark MOM

Das MOM enthält keine Audio-Schaltungen und hat keine Uhr-Funktion. Die Uhr wird vom Host AX Center oder AX64 durchgeführt. Lesen Sie im **AX Center Hardware Manual** oder **AX64 Hardware Manual** , um Informationen zu erhalten.
