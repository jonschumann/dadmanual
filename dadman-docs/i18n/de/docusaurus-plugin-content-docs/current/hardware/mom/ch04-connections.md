# Kapitel 4 — Verbindungen

> **Produkt:** Digital Audio Denmark MOM

Der MOM ist eine Kontrolloberfläche. Es enthält keine Audio-Schaltungen und keine Audio-Verbindungen. Die einzige physikalische Verbindung ist das USB-C-Kabel zum Host AX Center oder AX64.

---

## 4.1 USB-C-Verbindung zur Host Unit

Das MOM wird an den USB-C-Anschluss auf der Rückseite des Host-AX Centers oder AX64 angeschlossen. Es verbindet sich nicht direkt mit dem Computer.

_[Placeholder — Verbindungsdiagramm mit MOM → AX Center USB-C-Pfad.]_

1. Suchen Sie den USB-C-Anschluss auf der Rückseite des AX Centers oder der AX64.
2. Schließen Sie ein USB-C-Kabel vom MOM-Anschluss an diesen Anschluss an.
3. Schalte die Hosteinheit ein.
4. Der MOM-Stat. LED sollte grün leuchten, wenn DADman läuft und die Einheit erkannt wird.

> **HINWEIS:** Das MOM benötigt DADman zum Laufen. Sie wird nicht allein funktionieren.
