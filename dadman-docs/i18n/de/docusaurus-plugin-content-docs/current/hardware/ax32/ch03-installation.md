# Kapitel 3 — Installation

> **Produkt:** Digital Audio Dänemark AX32  
> **SKU:** AX32-BASE2

---

## 3.1 Bevor Sie beginnen

> **WARNUNG – Elektrischer Schockgefahr.** Benutzen Sie keine Kraft, bis alle Verbindungen vollständig sind und die Einheit ordnungsgemäß in einem Rack oder Gehäuse installiert ist.

> **KAU — elektrostatische Entladung.** Vor dem Installieren oder Entfernen von Erweiterungskarten schalten Sie die Einheit aus und verlegen sich selbst.

---

## 3.3 Installation der Erweiterungskarte

> **WARNUNG:** Schalten Sie das Chassis immer aus und trennen Sie das Netzkabel bevor Sie Erweiterungskarten installieren oder entfernen.

1. Schalten Sie das Gerät ab und trennen Sie das IEC-Netzkabel ab.
2. Entfernen Sie die Platte aus dem Zielfeld (halten Sie die Schraube).
3. Schieben Sie die Karte in die Schlitzführer, bis der Kantenverbinder voll sitzt.
4. Sichern Sie die vordere Halterung mit der befestigten Schraube.
5. Verbinden Sie das Netzkabel erneut.
6. Einschalten und verifizieren, dass die Karte im DADman erscheint.

Für Kartenspezifische Installationshinweise siehe [Erweiterungskarten](../../expansion-cards/).
