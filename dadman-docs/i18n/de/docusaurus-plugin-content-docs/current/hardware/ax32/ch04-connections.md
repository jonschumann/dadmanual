# Kapitel 4 — Signalverbindungen

> **Produkt:** Digital Audio Dänemark AX32  
> **SKU:** AX32-BASE2

---

## 4.1 Thunderbolt 3 Host-Verbindung

Verbinden Sie den AX32 mit einem Thunderbolt 3 mit dem Host-Computer. Das Gerät erscheint in DADman als Thunderbolt Audio-Gerät.

> **HINWEIS:** Benutze nur Thunderbolt 3 bewertete Kabel. Standard USB-C-Kabel bieten keinen zuverlässigen Betrieb.

---

## 4.2 Analogverbindungen (über Erweiterungskarten)

Analog-I/O wird von installierten Erweiterungskarten (CARD-L8, CARD-M8, CARD-DA8) bereitgestellt. Jede Karte verfügt über einen 8-Kanal-DB25-Anschluss unter Verwendung des Tascam-Pinout-Standard.

Für Konnektor-Details siehe:

- [CARD-L8 — DB25 Input Pinout](../../expansion-cards/card-l8#db25-input-pinout-tascam)
- [CARD-M8 — DB25 Input Pinout](../../expansion-cards/card-m8#db25-input-pinout-tascam)
- [CARD-DA8 — DB25 Ausgabe-Pinout](../../expansion-cards/card-da8#db25-output-pinout-tascam)
