# Kapitel 7 — DADman Software Integration

> **Produkt:** Digital Audio Dänemark AX32  
> **SKU:** AX32-BASE2

---

## 7.1 Übersicht

Der AX32 wird vollständig von DADman verwaltet. Die Konfiguration aller Routing-, Gain-Controlling- und Erweiterungskarten erfolgt über die DADman Software-Schnittstelle. Die Einheit wird automatisch im lokalen Netzwerk entdeckt, wenn sie über Ethernet verbunden ist.
