## 6.1 Ein-/Ausschalten

_[Placeholder — Ein- und Ausschaltungsvorgang über den Power-Knopf.]_

### Normaler Power-An

1. Stellen Sie sicher, dass alle Signalkabel angeschlossen sind.
2. Drücke die Vorderseite **Power** Taste.
3. Die Einheit führt eine Start-Sequenz aus — erlauben Sie 30 Sekunden für die Fertigstellung.
4. Die **Int.** LED leuchtet, wenn die Einheit fertig ist.

### Normaler Herunterfahren

1. Schließen Sie in DADman die Sitzung und trennen Sie die Einheit.
2. Drücke die Vorderseite **Power** Taste.
3. Während der Abschaltsequenz wird der Knopf verlangsamt.
4. Energie nicht entfernen, während der Knopf pulsiert.

> **WARNUNG:** Power-Cycle die Einheit während eines Firmware-Updates. Die Ein/Aus-Taste wird während des Updates langsam gepulsiert; warten Sie, bis das Update abgeschlossen ist.
