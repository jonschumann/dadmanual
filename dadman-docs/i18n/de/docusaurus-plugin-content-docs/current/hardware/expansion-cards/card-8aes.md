## Übersicht

Das CARD-8AES verfügt über 8 Kanäle mit AES3-Digital-I/O für kompatibles DAD-Chassis. Es ist für die Anbindung an digitale Geräte mit ausgewogenen AES3 (AES/EBU) Anschlüssen gedacht – Konsolen, digitale Bandmaschinen, Außenbordwandler und Rundfunkgeräte.

## Installation

> **WARNUNG:** Schalten Sie das Chassis immer aus und trennen Sie das Netzkabel bevor Sie Erweiterungskarten installieren oder entfernen.

1. Schalten Sie das Chassis ab und trennen Sie das Netzkabel vom Netz.
2. Entfernen Sie die Platte aus dem Zielfeld (halten Sie die Schraube).
3. Schieben Sie die CARD-8AES in die Schlitzführer, bis der Kantenverbinder voll sitzt.
4. Sichern Sie die vordere Halterung mit der befestigten Schraube.
5. Schließen Sie das Netzkabel wieder an und schalten Sie das Chassis an.
6. DADman öffnen — die Karte erscheint als AES3-I/O-Schnittstelle in der I/O-Routingansicht.
