## 7.1 Wie die Penta 721s im DADman erscheinen

_[Placeholder — beschreiben, was der Benutzer in der DADman Device List sieht, wenn die Penta 721s angeschlossen ist. Screenshot-Platzhalter einschließen.]_

Wenn die Penta 721s angeschlossen und eingeschaltet ist, erscheint sie im Bedienfeld **Geräteliste** im DADman. DADman identifiziert es anhand des Gerätetyps und der Seriennummer. Der Benutzer weist eine Beschriftung zu, die über Sitzungen hinweg fortbesteht.

Der Gerätelisteneintrag für die Penta 721s zeigt:

| Feld              | Inhalt                                  |
| ----------------- | --------------------------------------- |
| Gerätetyp         | Penta 721s                              |
| Seriennummer      | Eindeutige Einheiten-Kennung            |
| Verbindungsstatus | Online / Offline                        |
| Firmware-Version  | Aktuelle Firmware-Revision              |
| Uhr-Status        | Status und ausgewählte Referenz sperren |
| I/O-Kanalkarte    | Zugewiesene Kanalbereiche               |
