# Penta 720 Hardware Manual

![Penta 720 — front panel](/img/panel-penta720-clean.png)

The Penta 720 is a modular 2U rackmount audio interface and format-conversion platform. It connects to the computer over Ethernet and is managed by DADman for routing and configuration. It is used for high-channel-count AES/EBU and MADI I/O, format conversion, and network audio distribution.
