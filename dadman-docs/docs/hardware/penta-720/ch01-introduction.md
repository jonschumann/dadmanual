# Chapter 1 — Introduction

> **Product:** Digital Audio Denmark Penta 720

---

## 1.1 Product Overview

The Penta 720 is a modular 2U rackmount audio interface and format-conversion platform from NTP Technology. It connects to the computer over Ethernet only and is managed by DADman for routing and configuration. It is used for high-channel-count AES/EBU and MADI I/O, format conversion, and network audio distribution.

**Connection to host:** Ethernet (no Thunderbolt)
**Form factor:** 2U rackmount (modular chassis)
**Audio channels:** Up to 720 channels (card-dependent)
