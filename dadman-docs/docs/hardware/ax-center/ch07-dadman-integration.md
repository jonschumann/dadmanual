## 7.1 How the AX Center Appears in DADman

*[Placeholder — describe what the user sees in the DADman Device List when the AX Center is connected. Include screenshot placeholder.]*

When the AX Center is connected and powered on, it appears in the **Device List** panel in DADman. DADman identifies it by its device type and serial number. The user assigns a label that persists across sessions.

The Device List entry for the AX Center shows:

| Field | Content |
|-------|---------|
| Device type | AX Center |
| Serial number | Unique unit identifier |
| Connection status | Online / Offline |
| Firmware version | Current firmware revision |
| Clock status | Lock state and selected reference |
| I/O channel map | Assigned channel ranges |
