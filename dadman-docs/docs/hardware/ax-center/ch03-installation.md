## 3.2 Rack Mounting

*[Placeholder — rack mounting procedure. Include racking hardware part numbers and torque specifications.]*

The AX Center is a 1U rackmount unit that mounts directly in a standard 19-inch rack with the supplied rack ears.

1. Attach the rack ears to the unit using the supplied screws.
2. Position the unit in the rack at the desired location.
3. Secure with rack screws into cage nuts or threaded rack strips.

> **CAUTION:** Use all four rack screws. Do not rely on fewer than four points of attachment.

---

## 3.3 Power Connection

*[Placeholder — power connection procedure.]*

Internal. IEC C14 inlet. 100–240 V AC, 50/60 Hz, auto-ranging.

1. Connect a suitable IEC C13 power cable to the unit's IEC C14 inlet.
2. Connect the other end to a grounded mains outlet.
3. Switch on the unit using the front-panel Power button.

> **WARNING:** Only connect to a correctly earthed/grounded mains outlet. Do not defeat the ground connection.

---


## 3.4 Thunderbolt Driver Installation

The DAD Thunderbolt driver must be installed on the host computer before the unit will be detected by DADman.

*[Placeholder — driver installation procedure. Cross-reference to DADman manual Ch. 3.]*

1. Download the DAD Thunderbolt driver package from [digitalaudio.dk](https://digitalaudio.dk/support).
2. Run the installer and follow the on-screen instructions.
3. Restart the computer when prompted.
4. Power on the unit and connect the Thunderbolt cable.
5. Open DADman — the unit should appear in the Device List.

> **NOTICE:** Thunderbolt security settings on macOS may require the user to approve the new Thunderbolt device on first connection. See the DADman Installation chapter for details.

---


## 3.5 Initial Startup

*[Placeholder — first-power procedure and verification steps.]*

1. Confirm all signal cables are disconnected before first power-on.
2. Apply power.
3. Observe front-panel LEDs — see [Ch. 2 — Panel Description](./ch02-panel-description) for expected LED states.
4. Connect the unit to the host computer (Thunderbolt 3).
5. Open DADman and confirm the unit appears in the Device List.
