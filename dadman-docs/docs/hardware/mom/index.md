# MOM Hardware Manual

![MOM — overview](/img/panel-mom-clean.png)

The MOM (Monitor Operating Module) is a physical monitor controller that connects to any DAD unit via Ethernet and is powered over that same connection using PoE. It provides direct-access controls for speaker selection, source selection, master level, dim, cut, talkback, and reference level. The MOM contains no audio circuitry; all signal processing occurs in the host DAD unit.
