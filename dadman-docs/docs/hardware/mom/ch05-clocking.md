# Chapter 5 — Clocking & Synchronisation

> **Product:** Digital Audio Denmark MOM

The MOM contains no audio circuitry and has no clock function. Clocking is performed by the host AX Center or AX64. See the **AX Center Hardware Manual** or **AX64 Hardware Manual** for clocking information.
