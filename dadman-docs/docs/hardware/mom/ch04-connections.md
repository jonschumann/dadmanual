# Chapter 4 — Connections

> **Product:** Digital Audio Denmark MOM

The MOM is a control surface. It contains no audio circuitry and makes no audio connections. The only physical connection is the USB-C cable to the host AX Center or AX64.

---

## 4.1 USB-C Connection to Host Unit

The MOM connects to the USB-C port on the rear of the host AX Center or AX64. It does not connect directly to the computer.

*[Placeholder — connection diagram showing MOM → AX Center USB-C path.]*

1. Locate the USB-C port on the rear of the AX Center or AX64.
2. Connect a USB-C cable from the MOM's rear USB-C port to that port.
3. Power on the host unit.
4. The MOM Stat. LED should illuminate green when DADman is running and the unit is recognised.

> **NOTICE:** The MOM requires DADman to be running. It will not function standalone.
