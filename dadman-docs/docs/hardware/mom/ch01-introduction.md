# Chapter 1 — Introduction

> **Product:** Digital Audio Denmark MOM

---

## 1.1 Product Overview

The MOM (Monitor Operating Module) is a physical monitor controller that connects to any DAD unit via Ethernet and is powered over that same connection using PoE (Power over Ethernet) — no separate power supply is required. It provides direct-access controls for speaker selection, source selection, master level, dim, cut, talkback, and reference level. The MOM contains no audio circuitry; all signal processing occurs in the host DAD unit.

**Connection to host:** Gigabit Ethernet; PoE-powered (IEEE 802.3af, Class 0)
**Form factor:** Desktop (rackmountable with optional bracket)
**Audio channels:** Control surface only — no audio circuitry in unit

---

## 1.2 Key Features

![MOM — overview](/img/panel-mom.png)
*MOM — overview*

- **Form factor:** Desktop; rackmountable with optional bracket
- **Volume control:** Large-format rotary encoder with 27-LED ring — 0.5 dB resolution
- **Keys:** 10 direct-access keys × 4 layers = 40 assignable functions
- **Monitor control:** 3 speaker sets; 3 sources; talkback; dim; cut; reference level
- **Connection:** Gigabit Ethernet (RJ45) — powered via PoE (IEEE 802.3af, Class 0); no separate PSU required
- **Footswitch input:** 3.5 mm TRS jack
- **Power consumption:** 5 W maximum
- **No audio circuitry** — all signal processing is handled by the connected DAD unit
- **DADman integration:** Configured and operated via DADman software
- **Weight / dimensions:** 1.0 kg / 2.2 lbs; 17.2 × 11.0 × 5.0 cm (W × D × H)
