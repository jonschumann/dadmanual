# Chapter 1 — Introduction

> **Product:** Digital Audio Denmark AX64

---

## 1.1 Product Overview

The AX64 is a 2U rackmount Thunderbolt 3 or Ethernet audio interface with up to eight DB25 analogue expansion card slots. It is commonly used as a stage box, satellite I/O unit, or standalone Ethernet audio endpoint in distributed systems.

**Connection to host:** Thunderbolt 3 or Ethernet
**Form factor:** 2U rackmount
**Audio channels:** Up to 64×64 analogue channels (card-dependent)
