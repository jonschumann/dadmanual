# AX64 Hardware Manual

![AX64 — front panel](/img/panel-ax64-front-clean.png)

![AX64 — rear panel](/img/panel-ax64-rear-clean.png)

The AX64 is a 2U rackmount Thunderbolt 3 or Ethernet audio interface with up to eight hot-plug DB25 analogue expansion card slots. It is commonly used as a stage box, satellite I/O unit, or standalone Ethernet audio endpoint in distributed systems.
