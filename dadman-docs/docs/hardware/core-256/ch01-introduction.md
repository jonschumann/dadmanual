# Chapter 1 — Introduction

> **Product:** Digital Audio Denmark Core 256

---

## 1.1 Product Overview

The Core 256 is a compact half-rack Thunderbolt 3 audio interface sharing the same rear-panel connector complement as the AX Center but without front-panel I/O. It is designed for installations where a high-channel-count Thunderbolt core is needed in a space-constrained rack.

**Connection to host:** Thunderbolt 3
**Form factor:** Half-rack (1U with shelf/bracket)
**Audio channels:** Up to 256×256 channels at 48 kHz
