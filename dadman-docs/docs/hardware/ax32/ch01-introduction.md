# Chapter 1 — Introduction

> **Product:** Digital Audio Denmark AX32  
> **SKU:** AX32-BASE2

---

## 1.1 Product Overview

The AX32 is a 2U rackmount modular I/O and format-conversion platform. It provides up to 32 channels of analogue I/O (16 in / 16 out) via its eight hot-plug expansion card slots, along with built-in coaxial MADI I/O and AES3 I/O. The AX32 does not include a Thunderbolt host interface; it connects to the network and is managed by DADman over Gigabit Ethernet. The AX32-BASE2 is the current shipping variant.

**Connection to host:** Gigabit Ethernet (DADman control and network audio)
**Form factor:** 2U full-rack, 19"
**Audio channels:** Up to 32 analogue channels (via expansion cards); 64 ch MADI; 16 ch AES3 built-in; additional channels via optional network audio expansion cards

## 1.2 Key Features

*[Panel images to be added — photography pending.]*

- **Form factor:** 2U rackmount, 19"
- **Expansion:** 8 hot-plug expansion card slots — up to 1,024×1,024 channels of I/O
- **MADI:** Built-in coaxial MADI I/O — 64 channels at 48 kHz
- **AES3:** Built-in AES3 I/O — 16 channels via 2 × DB25 (Tascam pinout)
- **Dante (optional):** Via MOD-DANTE-BK3 module
- **DADlink (optional):** Via MOD-MADI-DADLNK module + SFP — up to 256×256 channels
- **Synchronisation:** Word Clock I/O (BNC, 75 Ω), Video Black Burst input, AES11 input
- **Routing:** 1,424×1,424 matrix; 256×32 summing processor; 28-bit floating-point
- **Latency:** 7 samples internal delay, adjustable 3–31 samples; all outputs time- and phase-aligned
- **Control:** DADman software (macOS and Windows); Avid EuCon compatible; Gigabit Ethernet
- **Power:** Single mains input; dual PSU standard; optional redundant input (AX32-RPS)
- **Cooling:** 2 × super low-noise internal fans
- **Weight / depth:** 5.0 kg / 11.0 lbs; chassis depth 35 cm / 13.8"
