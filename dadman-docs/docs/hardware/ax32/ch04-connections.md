# Chapter 4 — Signal Connections

> **Product:** Digital Audio Denmark AX32  
> **SKU:** AX32-BASE2

---

## 4.1 Thunderbolt 3 Host Connection

Connect the AX32 to the host computer using a Thunderbolt 3 rated cable. The unit appears in DADman as a Thunderbolt audio device.

> **NOTICE:** Use only Thunderbolt 3 rated cables. Standard USB-C cables will not provide reliable operation.

---

## 4.2 Analogue Connections (via Expansion Cards)

Analogue I/O is provided by installed expansion cards (CARD-L8, CARD-M8, CARD-DA8). Each card provides an 8-channel DB25 connector using the Tascam pinout standard.

For connector pinout details, see:
- [CARD-L8 — DB25 Input Pinout](../../expansion-cards/card-l8#db25-input-pinout-tascam)
- [CARD-M8 — DB25 Input Pinout](../../expansion-cards/card-m8#db25-input-pinout-tascam)
- [CARD-DA8 — DB25 Output Pinout](../../expansion-cards/card-da8#db25-output-pinout-tascam)
