# AX32 Hardware Manual

![AX32 — front panel](/img/panel-ax32-front-clean.png)

The AX32 is a 2U rackmount modular I/O and format-conversion platform. It provides up to 32 channels of analogue I/O via eight hot-plug expansion card slots, along with built-in coaxial MADI I/O and AES3 I/O. It connects to the network and is managed by DADman over Gigabit Ethernet.
